# 구현 및 검증 기록

검증일: 2026-11-01, UE 5.8.2 / Win64 Development Editor.

## 실제 구현

독립 ProcessUI 플러그인에 한국어 운전·상태, 설정·시퀀스, 장비·수동 화면을 구현했다. 가변 호퍼, 순서 편집, 초기/예약 믹서 투입, 이름을 붙인 저장·불러오기, 정지 확인과 잔량 재개, 테스트 공급원과 상징적 3D 이동/장비 카메라를 제공한다. UI와 공정 제어·계약·공급원을 분리했다.

이번 재개에서는 테스트 보조광 우선순위와 UI/범례의 불투명 배경을 수정했다. 기존 추적 파일의 diff는 없으며 추가 경로는 Plugins/ProcessUI, Content/ProcessUI, Scripts/ProcessUI, Docs/ProcessUI다. 메인 레벨·팀원 소스는 수정하지 않았다. 커밋·푸시는 하지 않았다.

## 실행 결과

- Windows 엔진 빌드 성공. 최신 UI DLL 접미사: 144873. 열린 사용자 에디터는 종료하지 않았다.
- 제어 계층 및 테스트 레벨 검사: 48 PASS, 실패 0. [검사 원문](Validation.txt).
- 초기 투입, 혼합 중 예약 투입, 실제 모의 투입 시작 시각, 혼합 유지, 예약 준비 미완료 정지, 수동 전체 정지와 시계 정지, 잔량 재개, 저장·불러오기 확인.
- 부분 수취 이송/부분 믹서 투입/혼합 명령 대기 중 재개, 이전 명령 응답 배제, 오래된 상태에서 재개 차단, 네 번째 호퍼, 밸브 닫힘 실패와 독립 닫기, 잘못된 원료, 초기화 세대도 확인.
- 전용 테스트 레벨 로드 및 화면 실행 검사: 화면 렌더링, 일시정지·재개, 장비 카메라, 초기화 후 편집 상태 전환 확인. 화면 실행 결과와 이미지는 Saved/ProcessUI에 저장.
- 예약 준비 미완료 정책 확정 후 제어 코드를 다시 빌드하고 48개 검사 및 전용 레벨 로드를 통과했다. 준비 회복 후에도 재개 금지, 명시적 배치 중단 전 초기화 금지, 최신 정지 확인 후 초기화, 자동 재시작 없음까지 확인했다. 화면 실행 검사는 앞선 표시 수정 시 수행한 결과다.

빌드에는 권장 버전보다 새로운 MSVC 경고가 있다. 게임 실행 로그에는 기존 ToolsetRegistry 초기화의 PythonTestRunner 속성 오류가 남는다. UI 실행 검사는 종료 코드 0이지만 전체 로그가 오류 없는 상태라는 의미는 아니다. 엔진 파일은 수정하지 않았다.

## 미연결 및 제한

테스트 공급원은 DEM/CFD나 실제 공압 운전을 구현하지 않는다. 점 이동·모의 질량·예제 입력은 실제 물리 결과/사양이 아니다. 현재 UI 브랜치에 기준 DEM 액터 소스가 없어 실제 장면 연동 시험은 수행하지 못했다. 읽기 전용 DEM 관찰 어댑터는 준비했지만 실제 명령은 거부한다. 실제 장비 질량·밸브 확인·RPM·원료별 위치 등은 공급원 지원 전 미지원/데이터 없음으로 표시한다. 온도·용융·부착 계산은 구현하지 않았다.

## 미확정 사항

사용자가 예약 준비 미완료 시 배치 중단·초기화만 허용하도록 확정했다. 예약 변경 API를 제거했고, 준비가 회복되어도 해당 배치는 재개할 수 없다. 명시적 배치 중단 및 실제 정지·닫힘 확인 후 초기화해야 한다. 일반 수동 정지의 잔량 재개는 유지한다.

팀원과 장비/밸브 ID, 누적 목표 명령과 중복 처리, 실제 정지·이송 완료 확인, 용량·준비 시간 상한, 데이터 시계/유효성, 초기화 세대를 합의해야 한다. [연동 초안](IntegrationDraft.md)은 합의된 규격이 아니다.
