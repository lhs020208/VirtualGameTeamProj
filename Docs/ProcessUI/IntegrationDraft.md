# 공정 UI 연동 초안 — 팀원 합의 전

## 조사 범위
- 작업 브랜치 UI, HEAD 7b571ec. 조사 시작 시 Git 로컬 변경 없음.
- 설치 엔진 Build.version: UE 5.8.2. 기존 콘텐츠는 L_Main, 소스는 기본 게임 모듈.
- 적용 가능한 AGENTS.md 및 MCP AgentSkill은 발견되지 않음.
- 현재 DEMPrototype 폴더는 빌드 산출물만 있으며 소스·uplugin 없음.
- 기준 브랜치는 사용자 확인한 origin/PowderSimulationOptimization. GitHub ls-remote로 74ac7562b9766bb477de0bb4c18f4e3125eba7b6과 일치함을 확인. 이 기록을 읽었으며 병합하지 않음.
- 해당 기록의 PowderGranularMixer.h에는 Running, RPM, GateOpen, PhysicalSeconds, ChargeMassKg, ReceiverMassKg, ResetSimulation, 입자 상태 복사 등이 있음. 이는 아래 공정 계약 준수나 실제 장치 피드백을 의미하지 않음. 기체·부착 관련 실험 기능도 전체 장비 공정 지원으로 간주하지 않음.
- MCP는 스킬 관리만 공개되어 있어 현재 도구로 테스트 레벨 로드·에디터 상태 확인 불가.

## 구현 배치안
- Plugins/ProcessUI: UI → 공통 계약 → 공정 제어 → 공급원 어댑터. 게임 모듈이나 DEM에 대한 직접 의존 없이 분리.
- Content/ProcessUI/Maps: 전용 테스트 레벨. L_Main과 시작 맵 설정 보존.
- 화면: 공정/3D 관찰, 동적 호퍼 설정, 순서·예약 편집, 예외·복구 패널.
- 테스트 공급원은 화면에 항상 테스트 모드 표시. 시각적 입자 이동은 물리 해석 결과가 아님.
- 개별 입자 선택·추적 제외. 온도는 지원 여부와 값 표시 확장 지점만 제공.

## 공급원 계약
- 장비/밸브: 안정적인 문자열 ID, 장비 종류, 연결 경로, 지원 기능 집합. 공급 호퍼는 가변 목록이며 물질 ID와 원료/첨가제 역할을 별도 지정.
- 스냅샷: 공급원 ID, 초기화 세대, 순번, 공급원 시각, 수신 시각, 실행 상태, 오류 목록.
- 지원 기능 집합 `Capabilities`와 자동 운전 가능 여부를 별도로 제공. 실제 관찰 어댑터는 입자 수·시뮬레이션 시간·오류만 지원한다고 선언.
- 모든 측정값: 데이터 이름, 단위, 선택적 값, 유효성(유효/미지원/없음/오래됨/오류), 측정 시각. 누락을 0으로 치환하지 않음.
- 목표값·적용값·실제값은 별도 필드. 적용 확인만으로 실제 회전·밸브 상태를 추정하지 않음.
- 명령: 요청 ID, 배치/단계 ID, 초기화 세대, 대상 장비 ID, 종류, 매개변수. 결과는 접수/거부/적용/실패와 실제 상태 확인을 구분. 중복 요청 처리 및 이전 세대 응답 폐기는 공급원과 합의 필요.
- 상태: 공급 종료, 밸브 닫힘, 계량 안정, 배출 완료, 배관 이송 완료를 독립적으로 제공. 실제 판정 기준·용량·준비 시간 상한은 공급원이 제공하며 미확정 상태를 통과시키지 않음.
- 완료 조건은 `ConditionsRequest`와 유효성을 함께 전달하여 이전 명령의 완료 상태를 재사용하지 않음. `StopConfirmedRequest`와 장비별 정지/닫힘 값이 함께 현재 정지 요청의 실제 완료를 확인해야 재개/초기화 가능.
- 적용 목표 질량은 명령 결과의 별도 유효값. 설정한 목표를 적용값이나 계량값으로 복사해 표시하지 않음.
- 테스트 공급원의 `timed_charge`는 예약 경계에서 지연 없는 투입 시작을 명시적으로 지원하며 `ChargeStartedAt`을 기록. 실제 어댑터는 장치 지연·예약 실행 지원을 합의하고 실제 시작 확인을 제공하기 전 자동 운전 미지원.
- 질량 kg, 길이 m(입자 지름), 시간 s. 표시/입력 g·mm·µm 변환. 0.1 mm = 100 µm. DEM 반지름 어댑터에서만 지름을 2로 나눔. RPM은 회전수 단위를 명시하고 필요 시 경계에서 rad/s 변환.
- 오류: 확인된 원인, 관련 장비/요청, 필요한 사용자 조치, 재개 가능 여부. 단순 지연을 막힘으로 판정하지 않음.

## 제어 계층 불변 조건
- 모든 물질은 공급 → 칭량 → 수취 → 믹서. 우회 경로 없음.
- 개별 물질 칭량과 수취 이송을 순차 수행. 공압 운전 절차는 어댑터 내부 합의 대상으로 남김.
- 초기 투입과 혼합 후 0초 예약은 별개. 예약 시각은 믹서 투입 시작 기준.
- 수취호퍼는 한 투입 시점에만 점유. 같은 시점의 물질만 개별 칭량 후 모을 수 있음.
- 공급원이 제공하는 용량/시간 상한으로 일정 검증. 정보가 없으면 실장비 실행 가능 판정 불가. 테스트 공급원의 가정은 테스트에만 유효.
- 예외 시 자동 진행과 혼합 경과 계산 정지, 공급·이송·혼합 정지 및 모든 밸브 닫힘 요청. 요청 결과와 물리 확인을 별도 추적.
- 밸브 닫힘 요청은 전체 정지 확인 전에도 가능. 이동 입자의 즉시 동결을 실제 정지로 표현하지 않음.
- 단계·목표·확인된 진행량·원인·필요 조치 보존. 명시적 재개 시 새 스냅샷과 진행 기록을 대조하고 남은 양만 처리. 질량 신뢰성이나 상태 일치가 확인되지 않으면 재개 불가.
- 잘못된 원료 유입은 배치 중단·초기화 필요. 초기화 요청만으로 물리 장비가 비었다고 판단하지 않음.
- 저장은 이름과 스키마 버전 포함. 불러오기는 검증 후 편집 상태로만 전환하며 자동 실행 금지.

## 사용자와 확정한 사항
- 연동 기준: origin/PowderSimulationOptimization.
- 일시정지: 전체 정지·밸브 닫힘 요청, 진행량 보존, 명시적 재개.
- 정지: 배치 중단, 초기화 필요.
- 별도 그룹 편집 없음. 개별 칭량·수취 이송 단계 다음에 믹서 투입 단계를 배치. 이 단계에서 초기 투입/혼합 후 N초를 지정.

## 예약 준비 미완료 정책 — 사용자 확정
예약 시점까지 준비되지 않으면 자동 순서·혼합 시계를 중단하고 전체 정지·밸브 닫힘을 요청한다. 첨가제를 포함한 예약 투입은 시간을 변경하여 재개하지 않는다. 사용자가 배치를 명시적으로 중단하고 실제 정지·닫힘을 확인한 뒤 초기화해야 한다. 준비 상태가 나중에 회복되어도 재개할 수 없다. 지연 원인이나 배합의 실제 이상 여부를 추정하지 않는다.

## 최신 장비 시험 코드에서 확인한 실제 연결 범위
`Source/VirtualGameTeamProj/PowderPlantTest.h/.cpp`, `PlantVisibilityController.h`, `Docs/ProcessPlantPhysics/README.md`를 기준 커밋에서 확인.

| 원본 | UI 연결 | 제한 |
|---|---|---|
| InWeighingHopper / InReceiver / InMixer | 장비별 입자 개수 | kg로 환산하지 않음. 원료별 위치는 미지원 |
| PhysicalSeconds | 공급원 시뮬레이션 시각 | 혼합 경과 시간으로 대체하지 않음 |
| Error | 공급원 오류 | 확인된 텍스트만 표시 |
| MixerRPM | 설정값 | 실제 RPM으로 표시하지 않음 |
| ToggleSupplier / ToggleWeighingHopper / ToggleReceiver / ToggleMixer | 연결 안 함 | 비멱등 토글이며 요청 ID·실제 확인을 보장할 수 없음 |
| private AppliedSupplierMask / AppliedHopperOpen / AppliedReceiverOpen | 연결 안 함 | 공개 피드백 계약 필요 |
| ResetSimulation | 연결 안 함 | 초기화 세대·잔류량 확인 계약 필요 |

현재 UI 브랜치에는 이 액터 소스가 없으므로 런타임 직접 연결 검증은 불가. 플러그인은 게임 모듈을 참조하지 않는 읽기 전용 반사 어댑터를 제공. 팀 병합 후 전용 테스트 레벨에 ProcessUIRig를 놓고 ObserveDEM 및 DEMSource를 지정해야 함.

실제 시험은 1D 준정상 관로 압력과 GPU 입자 접촉을 결합하며 전체 3D CFD나 실물 검증 결과가 아님. 기존 시험의 압력·RPM·입자 물성 기본값을 이 UI의 실제 공정 사양으로 가져오지 않음.

## 팀원 합의가 필요한 계약 상세
- 안정적인 장비·밸브 ID와 그래프, 물질 ID와 밀도·입자 설정 전달 방식.
- 총량 명령(단계별 누적 목표)과 idempotency 처리. 재개 명령은 추가량 명령이 아님. 공급원이 누적 진척을 확인해 잔량만 수행해야 함.
- 정지 요청과 실제 공급/이송/회전 정지, 밸브 닫힘, 배관 입자 정착의 독립적 확인.
- 용량·준비 시간 상한·계량 안정·이송 완료 기준. 시간 상한이 없으면 일정 보장 불가.
- 갱신 주기·시계·데이터 유효성·허용 오차. 현재 연결 갱신 2초 진단과 수치 비교 오차는 소프트웨어 테스트 정책이며 실제 공정 임계값 아님.
- 초기화 시 물리 장비 비움/수동 확인/세대 변경, 이전 세대 명령 거부.
- 온도는 확장 필드만 있으며 열·용융·부착 추정 없음.

## 최소 검증 계획
UE 빌드와 전용 레벨 로드 후 초기 투입, 혼합 중 예약, 예약 준비 미완료, 수동 전체 정지, 남은 양 재개, 저장·불러오기를 검사한다. 추가로 이송 중/믹서 투입 중/최초 혼합 시작 대기 중 재개, 오래된 상태·이전 명령의 완료 응답, 4번째 공급 호퍼를 확인한다. 최종 실행 결과는 ValidationReport.md에 별도 기록한다.
