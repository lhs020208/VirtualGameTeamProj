# 밀폐 호퍼 시험 압력 제어

1. 기존 준정상 비압축성 1D 관망을 보존하고 새 레벨에만 이상적 압력 조절기 모드를 추가한다. 기체 유량 방향은 압력차 부호를 따르며, 차압을 입자에 직접 강제 가속도로 주지 않는다.
2. 내부 Pa, GUI kPa(g). 기준 대기압 101325Pa, 절대압=101325+게이지압. 공급 공통/칭량 -1.0~+1.0kPa(g), 수취 -1.0~0kPa(g). 최대 차압 2kPa, 시험 모델 범위이며 설비 정격/안전값이 아니다.
3. 공급 공통·칭량·수취 설정값과 실제 적용값/차압/유량을 구분한다. 수취 배출구가 실제 열려 있으면 수취부는 대기압으로 처리하고 설정 진공은 보류한다. 닫힌 밸브의 관로 유량은 0. 칭량 조절기의 보충/배기 유량으로 유량 수지를 표시한다.
4. 단계별 권장 시험 기본값(공급/칭량/수취, kPa(g)): 대기 0/0/0; 충전 +0.5/-0.5/0; 칭량 0/0/0; 이송 0/+0.5/-1.0; 배출 0/0/0; 혼합 0/0/0. 단계 버튼은 압력만 바꾸며 밸브·혼합기는 수동이다. 수동 입력이 우선하며 단계값은 명시적인 재적용으로만 덮어쓴다.
5. 명시적 저장/불러오기/단계 기본값 복원, R 초기화는 압력 설정을 유지하고 밸브를 닫는 동작으로 구현한다. 저장 프로필은 Saved 내 새 레벨 전용이며 시작 시 자동 로드하지 않는다. 잘못된 입력/파일은 현재 상태를 유지하고 이유를 표시한다.
6. CPU 관망·GPU 항력 방향·역류/차단, 반복 변경, 상태 저장/복원, 기존 모드 회귀, UE Play/UI를 검증한다. 실제 설비 검증과 구별한다.
7. 혼합기 단독 A/B 4mm 각 10000개 시험에서 분포·공간 조성·이동량을 비교한다. 전체 공정 이송 후 도달한 입자 시험과 구별하고 0.67L 및 날개-바닥 간격 제약을 기록한다.

범위 보정: 관망의 80m/s 기체 속도 한계를 대조하여 초기 제안 ±1.5kPa를 ±1.0kPa로 축소했다. 최대 차압 2kPa에서 모든 경로가 수치 모델 범위 안에 든다. 설비 안전 인증과 무관하다.
