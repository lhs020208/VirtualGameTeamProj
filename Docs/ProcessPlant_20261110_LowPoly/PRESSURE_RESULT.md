# 밀폐 호퍼 시험 압력 구현 및 4mm 검증

대상은 `/Game/ProcessPlant_20261110_LowPoly/L_ProcessPlant_LowPoly`다. 기존 레벨은 기존 압력 모드를 유지한다. 커밋/푸시는 하지 않았다.

## 입자 크기 정정

이번 대화의 이전 요청을 잘못 이어 받아 기존 `SourceAssets/ProcessPlant_20261104/Simulation/test_charge.csv`를 잠시 지름 18mm로 변경했다. 이후 이번 변경만 복구했다. 복구 SHA-256은 변경 전과 같은 `cc3e9211a4e40a90952cfcafd575d8579d788192eb83a2ca6bb6c6e8ed18b3d6`이다. 확대 재생성 스크립트도 제거했다. 해당 확대 조건으로 시뮬레이션을 실행하지 않았다.

새 저폴리 레벨 CSV는 확대하지 않았다. 반지름 0.002m = 지름 4mm, A/B 각각 10000개, C–F 0개다. 초기 격자 간격은 4.8mm로 표면 사이 간격 0.8mm이며 GPU 벽 투영 이동량은 0이다. 초기 0.00256초 계산 뒤에도 20000개가 모두 유한한 좌표를 유지했다. `particle_size_correction.json`, `charge_recheck.json` 참조. 다른 기존 레벨의 별도 18mm 설정은 수정하지 않았다.

## 조작과 압력 해석 범위

- 좌측 패널의 공급 공통 / 칭량 / 수취 흡입 입력값을 변경하고 Enter로 확정한다. 긴 패널은 스크롤한다.
- 단위는 kPa(g), 기준 대기압은 101.325kPa(abs)다. 내부 계산은 Pa(g)로 변환한다. 공급·칭량 범위는 -1.0~+1.0kPa(g), 수취 범위는 -1.0~0kPa(g)다. 이는 수치 모델 시험 범위이며 설비 정격이 아니다.
- 높은 압력에서 낮은 압력으로 관로 유량을 계산하며 압력차가 역전되면 역류를 계산한다. 입자에는 계산된 공기속도의 항력이 작용한다. 설정압으로 입자 위치나 속도를 강제 지정하지 않는다.
- 이상적 압력 조절기가 지정압을 유지하는 준정상 비압축성 1D 관망이다. 실제 펌프 성능곡선, 유한 용량의 압축성 탱크 과도응답, 3D CFD를 구현한 것은 아니다. 칭량 조절기의 보충/배기 유량도 표시한다.
- 밸브의 실제 열림과 요청 상태를 구분한다. 닫힘 요청 시 해당 유량은 차단하며, 끼인 입자가 있으면 물리 게이트 닫힘은 대기한다.
- 수취→혼합기 출구가 실제 열리면 수취 적용압은 대기압 0으로 전환한다. 요청 진공값은 보관하고 출구가 닫히면 복귀한다. 이는 현재 시험용 배출 경계조건이다.
- 단계 버튼은 압력만 변경한다. 밸브와 혼합기는 기존 수동 버튼으로 제어한다. 수동 입력은 다음 명시적인 단계 버튼/복원/불러오기까지 유지한다.

| 단계 | 공급 | 칭량 | 수취 | 권장 수동 조작 |
|---|---:|---:|---:|---|
| 대기 | 0 | 0 | 0 | 모든 밸브 닫기, 회전 정지 |
| 충전 | +0.5 | -0.5 | 0 | 선택 공급기 열기, 칭량/수취 출구 닫기 |
| 칭량 | 0 | 0 | 0 | 공급기와 칭량 출구 닫기 |
| 이송 | 0 | +0.5 | -1.0 | 공급기 닫기, 칭량 열기, 수취 출구 닫기 |
| 배출 | 0 | 0 | 0 | 칭량 닫기, 수취 출구 열기 |
| 혼합 | 0 | 0 | 0 | 수취 출구 닫기, 혼합기 시작 |

저장 파일은 `Saved/PlantPressure_LowPoly20261110.json`이다. 자동 로드하지 않으며 명시적으로 불러온다. R 초기화는 압력 설정을 유지하면서 입자를 재생성하고 밸브를 닫고 회전을 정지한다. 일시정지 중 입력은 재개 시 적용한다. 잘못된 범위·NaN/Inf·프로필 형식·단계값은 거부한다. 설정값과 적용값은 따로 표시한다.

## 검증

- UE 5.8 Development Editor 빌드 성공.
- CPU 압력/밸브 조합 128건 및 GPU 정방향/역방향/무차압 항력, 30회 반복 변경 통과 (`plant_pressure_tests`).
- 기존 레벨 데이터로 수취/공급/칭량 게이트와 회전, 닫힘 대기/유량 차단 회귀 시험 통과 (`plant_valve_tests`).
- 별도 오프스크린 UE 에디터에서 새 레벨의 PIE를 실제 실행하여 20000개 생성, 압력 적용, 저장/불러오기, 잘못된 파일 거부, 수취 개방 시 대기압, 일시정지/재개, 초기화 후 압력 유지와 20000개 재생성을 확인했다. `pressure_play_validation.json`, `pressure_preview00000.png` 참조.
- GUI 위젯과 연결되는 함수를 UE에서 호출한 검사다. 마우스 클릭 자동화 도구는 초기화 오류로 사용할 수 없어 실제 마우스 조작 시험은 하지 못했다. 화면은 별도 오프스크린 에디터에서 촬영했다.
- 실행 CSV는 `Saved/PlantPressureRuns`에 기록된다. UTC 시각, 물리 시간, 실제 계산/준비 시간, 압력 설정/적용, 밸브 요청/실제, RPM, 구간별 A/B 개수를 포함한다. 구간 개수는 서로 겹치지 않는 공간 영역 분류이며 정확한 메시 내부 판정이나 최초 도착 시간은 아니다.
- 압력 조작 시험은 짧은 기능 시험이다. 전체 이송 완료/도착 시간을 측정한 시험이 아니며, 출발지의 입자 대부분이 남아 있다. `stopped_not_completion` 행은 이송 완료를 뜻하지 않는다. `pressure_run_summary.json`과 원본 CSV를 보관했다.
- 원본 Blender 및 기존 ParticleSetup 레벨 파일의 SHA-256을 재확인했다. 변경하지 않았다. 기존 열린 에디터 프로세스는 보존했고 임시 검증 에디터는 종료했다. 새 C++ 기능은 기존 에디터를 재시작한 뒤 사용해야 한다.

## 혼합 시험

`mixing_20k_4mm.csv`는 동일한 새 레벨 충돌 데이터, 지름 4mm, A/B 각 10000개를 혼합기에 직접 넣은 별도 GPU 시험이다. 전체 공정을 통과해 도착한 입자 시험과 다르다. 모든 밸브를 닫고 공급/칭량/수취 압력을 모두 0Pa(g)로 두었다. 시작은 직접 배치 완료 시점이며 0.2초 정착 후 15RPM으로 회전한다. 목표 종료는 물리 시간 4.2초(회전 1회), 실제 계산 한도는 300초다. 준비 시간을 별도로 기록한다. 한도에 도달하면 미완료로 표시한다.

공간 조성 분산은 고정된 8×4×4 격자에서 입자 수로 가중한 `(A비율-0.5)^2`다. 0에 가까울수록 이 격자 해상도에서 섞이고, 0.25에 가까울수록 분리됐다. 실제 제품 품질 지표나 교정된 혼합 지수는 아니다. 종별 중심 거리, 중앙면을 넘은 입자 수, 초기 대비 RMS 이동량도 기록한다. 중력 낙하만으로 생긴 이동은 혼합 성공으로 해석하지 않는다.

첫 시험은 곡면 바닥 바깥의 초기점을 잘못 포함하여 중단했다. `mixing_invalid_fixture_rejected.csv`는 시험 배치 오류 기록이며 혼합/성능 결론에서 제외한다. 내부 중앙 열로 재배치하고 외부 이탈 발생 시 즉시 실패하도록 보완했다. 크기나 개수, 물성, 설비 형상은 변경하지 않았다.

총 고체 부피는 약 0.670L다. 날개 최저 회전 궤적과 바닥의 기하학적 간격 약 31.6mm 때문에 적은 충전량에서는 충분한 교반 접촉을 기대하기 어렵다. 혼합 결과를 좋게 만들 목적으로 입자를 확대하거나 수를 늘리지 않았다. 최종 수치는 별도 `mixing_summary.json`에 기록한다.

### 최종 계측값

준비 0.621초, 실제 계산 300.014초에 물리 시간 3.31984초 진행했다. 300초 제한으로 종료했으므로 목표 4.2초/1회전은 미완료다. 정착 후 회전량은 0.781회전이다. 평균 처리율은 0.01107배이며 이 단독 시험의 수치로 전체 공정 성능을 보장하지 않는다.

A/B 각 10000/10000개 유지, 혼합기 경계 상자 밖 입자 0개. 정착 직후→종료 조성 분산 0.245171→0.245667, 종별 중심 거리 0.337822→0.337971m. 종료 시 중앙면 반대쪽 입자 57개. 유의미한 A/B 혼합을 관찰하지 못했다. 단순 회전 작동은 혼합 성공과 다르다. GPU 관찰 온도는 약 42~49°C였으며 시험은 자동 종료했다.
