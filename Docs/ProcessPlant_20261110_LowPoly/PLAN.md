# 로우폴리 공정 설비 통합 — 2026-11-10

대상: hoper_lowpoly.blend. 기존 모델·레벨·데이터를 보존하고 새 레벨과 독립 데이터에만 적용한다. 커밋/푸시는 하지 않는다.

1. 원본 해시·단위·객체/포트/충돌 형상·MX301 축소 치수를 조사한다.
2. 새 FBX와 SI 충돌 원본을 내보내고 새 치수에 맞는 유동 경로, 밸브, 혼합기 축을 구성한다.
3. 정밀 관 메시와 호퍼/혼합기 OBB 평면 패치를 조합한 하이브리드 충돌 및 공간 인덱스를 생성한다.
4. 새 레벨에 설비, 표시 UI, 수동 밸브, 혼합기 회전, 압력 이송과 카메라를 연결한다.
5. A/B 지름 4mm, 각 10,000개(총 20,000개)를 독립 CSV로 생성하고 초기 간격·벽 여유를 확인한다.
6. 스케일/충돌 정렬·수동 제어·렌더 모드·GPU 계산과 제한된 이송/회전 테스트를 수행하고 실제 검증 범위와 한계를 기록한다.

압력 모델은 기존의 준정상 1차원 관망 해석과 3차원 입자 항력의 단방향 결합을 유지한다. 새로운 정밀 CFD 또는 실측 검증을 완료했다고 주장하지 않는다.

진행 상태: 작업 1~6 완료. 실제 검증 범위와 장시간 혼합 미검증 사항은 RESULT.md 및 개별 JSON에 기록했다.
