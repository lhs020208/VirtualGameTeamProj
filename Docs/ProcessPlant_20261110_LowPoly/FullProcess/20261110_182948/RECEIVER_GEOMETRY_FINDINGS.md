# 수취→혼합 미분류 입자 확인

기존 분류기는 공기 이송용 runtime.plant 경로만 읽었으므로, 중력 배출 구간을 미분류로 남겼다. 물리 계산에서 통로가 없다는 의미가 아니다.

원본 저폴리 모델에서 추출한 Intermediate/PlantLowPoly20261110/Physics의 실제 정점 단면을 확인했다. 중심축은 (x,y)=(3,0)m이다.

| 구간 | 높이 z(m) | 내반지름(m) |
|---|---|---|
| BV272 몸체 | 2.133~2.163 | 0.139 |
| BV272 목 | 2.110~2.133 | 0.136 |
| DP_110 | 1.890~2.110 | 0.136 |
| DP_120 | 1.790~1.890 | 0.136 |
| DP_130 | 1.710~1.790 | 0.136 |
| P202 축소관 상부 | 1.685~1.710 | 0.136 |
| P202 원뿔부 | 1.350~1.685 | 0.022→0.136 |
| P202 출구 | 1.310~1.350 | 0.022 |

초기 단면 분석에서 밸브 단차를 경사로 보간해 136개를 경계 허용오차 안으로 분류했으나, 실제 정점의 단차 반영 후 해당 스냅샷의 연결 구간 17987개 모두 내반지름 안에 있었다. 입자 중심의 최소 반경 여유는 약 2.0048mm였다. 지름4mm 입자의 경로 이탈을 뒷받침하는 결과가 아니다. 원형 단면 근사이며 정확한 삼각형 메시 내부 판정이나 누출 없음의 전역 증명은 아니다.

물리 t=10.17616s에서 연결구간18563개 중18395개는 P202 축소관에 있었고168개는 BV272 몸체 높이2.13466~2.13895m에 있었다. 두 스냅샷 끝점 비교에서18388개는10um 이상 이동했다.168개는 정지 관찰 대상이다. 정체/누출을 확정하지 않고 실제 도착 증가를 계속 검사한다.

자세한 좌표범위와 원시 측정은 receiver_drop_geometry_check.json, 입자별 기록은 classified/에 보존한다. 분류 수정만 했으며 시뮬레이션의 충돌, 압력, 입자 위치는 변경하지 않았다.
