# 전체 공정 시험 판정 기준 (실행 전)

새 저폴리 레벨, 원래 공급기 A/B에서 시작하는 지름 4mm 각 10000개를 사용한다. 직접 혼합기 투입/텔레포트/입자 크기·개수 변경은 금지한다. 기존 에디터와 미저장 작업은 건드리지 않고 최신 빌드의 별도 UE PIE로 실행한다. 단위는 m, s, Pa(g); 절대압=101325+게이지압이다. 시험 압력은 실설비 안전값이 아니다.

1. A 충전: 공급 +500, 칭량 -500, 수취 0Pa(g). A만 열고 칭량/수취 출구 닫기. A 10000개가 칭량 영역에 모두 들어와 0.5물리초 유지하면 완료.
2. B 충전: A 닫고 B만 열기. 나머지 동일. B 10000개가 칭량 영역에 들어와 0.5물리초 유지하면 완료.
3. 칭량→수취: 모든 공급기 닫고 칭량 출구 열기, 수취 출구 닫기. 공급 0, 칭량 +500, 수취 -1000Pa(g). A/B 각 10000개가 수취 영역에 들어와 0.5물리초 유지하면 완료.
4. 수취→혼합: 칭량 출구 닫고 수취 출구 열기. 모든 압력 0Pa(g). A/B 각 10000개가 혼합기 영역에 들어와 0.5물리초 유지하면 완료.
5. 혼합: 수취 출구 닫고 15RPM으로 최소 12물리초(3회전) 실행한다. 출발은 이송된 실제 입자이며 잔류는 그대로 남긴다. 고정 8×4×4 격자 가중 조성 분산, 종별 중심거리, 수량과 위치를 초기/종료에 기록한다. 시험상 혼합 통과 기준은 각 종의 99% 이상이 혼합기 안에 있고 조성 분산 ≤0.025이며 마지막 4초 유지하는 것. 제품 품질 인증 기준이 아니다.

이송 단계는 적어도 10물리초 실행한다. 이후 5물리초 동안 목적지 개수의 최고값이 10개 이상 늘지 않으면 정체 후보로 기록하고, 추가 5물리초를 같은 조건으로 더 관찰한다. 총 10물리초 정체가 확인되면 해당 단계는 잔류/정체 실패이며 절대 완료로 표시하지 않는다. 계속 유입되는 동안은 기다린다. 120물리초에도 전량 도달하지 않으면 장기 잔류 미완료로 기록한다. 실제 시간 제한만으로 성공 처리하지 않는다.

한 단계가 실패해도 그때 도착한 입자로 다음 경로를 검사한다. 이는 전체 공정 성공이 아니며 공급/상류 잔류를 그대로 기록한다. 혼합기에 도달한 입자가 0개면 혼합은 시험 불가로 기록하고 회전만을 혼합 성공이라고 하지 않는다.

30실제초 또는 0.5물리초마다 위치 스냅샷/진행 현황을 저장하고, 압력/밸브 요청·실제 상태는 런타임 CSV에 보관한다. 시작·종료·전환 스냅샷, 단계 물리/실제 시간, 준비/중단 시간, 출발/도착/잔류/영역 밖 개수를 기록한다. 영역 밖은 누락으로 간주하지 않고 좌표를 따로 남긴다. 개수/ID 유실이나 비유한 좌표는 즉시 수치 실패다. 정확한 벽 관통 여부와 단순 영역 판정의 한계는 구분한다.
