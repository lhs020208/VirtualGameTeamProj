# 전력·입자 부하 기반 혼합기 구동

적용 레벨: `/Game/ProcessPlant_20261111_LowPoly/L_ProcessPlant_LowPoly_1111`

기존 목표 RPM을 시간에 곱해 날개를 돌리는 방식 대신, OpenCL에서 모터 토크·입자 반력·관성으로 실제 회전을 적분한다. 원본 혼합기 하이브리드/삼각형 충돌 형상과 회전 부품 47개를 사용한다. 기존 전동 밸브, 단순 머티리얼, 배경의 표시 전용 처리는 유지한다.

## 계산

- 축 운동: `I dω/dt = 모터 토크 + 입자 접촉 반력 토크 - 베어링 저항 - 제동 토크`.
- 모터는 목표 RPM을 추종하되 `|τ| ≤ 정격 토크 × 공급 비율`, `|τω| ≤ 효율 × 입력 전력 × 공급 비율`로 제한된다. 목표 속도에도 가속 램프를 적용한다.
- 회전 날개와 입자 사이에는 스프링·감쇠 및 쿨롱 마찰력을 계산하고, 같은 힘의 반대 토크를 축에 전달한다. 회전 형상의 위치 강제 보정은 이 모드에서 제거했다. 정적 벽과 입자 간 기존 계산은 유지한다.
- 회전각은 실제 각속도에서 적분한다. 렌더링 부품도 이 각도를 사용하며, 좌표계 변환을 반영해 월드 X축으로 회전한다.
- 정지 요청과 전원 차단은 순간적인 RPM 0 처리가 아니다. 유한한 제동 토크와 관성으로 정지한다. 전원 차단 시 전력은 0이며 관성 회전은 가능하다.
- 정지에 가까운 상태에서 모터 토크가 포화된 상태로 2 해석초가 지나면 과부하 트립한다. 부하 제거 후 정지 명령을 주고 다시 시작한다. 과부하 상태에서 시작만 반복해 보호를 우회할 수 없다.
- 소비 전력과 적산 에너지는 구동 모델의 계산값이다. 회생 전력은 계산하지 않으며, 제동 에너지는 소산으로 취급한다.

## 기준값과 출처

SEW-EURODRIVE 공식 [모터 표](https://download.sew-eurodrive.com/download/html/33346739/en-EN/24974053771.html)의 DRN90S4는 정격 축출력 1.1 kW, 1455 RPM, 전부하 효율 84.5%다. [감속기 선정 표](https://download.sew-eurodrive.com/download/html/33346739/en-EN/49904833931.html)의 R87 계열 조합에는 약 14 RPM, 750 Nm 항목이 있다. 이를 참고한 가상 인버터·감속 모터다. 모델에 장착된 실제 모터의 식별·정격 검증을 뜻하지 않는다.

| 항목 | 적용값 | 성격 |
|---|---:|---|
| 전기 입력 한도 | 1302 W | 1100 W / 0.845에서 산출. 축출력과 구분 |
| 출력축 토크 한도 | 750 Nm | 위 감속 모터 자료 참고 |
| 목표 RPM | 기존 15 RPM | 운전 설정. 부하에 따라 실제 속도는 낮아짐 |
| 총 구동 효율 | 0.8 | 모터·감속기 합산 시험 가정 |
| 축 환산 관성 | 60 kg·m² | 시험 가정. 실제 질량·관성 필요 |
| 속도 램프 | 15 RPM 기준 2초 | 시험 가정 |
| 정지/무전원 제동 토크 | 100 Nm | 유한 제동장치의 시험 가정 |
| 베어링 점성 저항 | 2 Nm·s/rad | 시험 가정 |
| 정지 포화 트립 시간 | 2 해석초 | 열·전류 보호의 간략 시험 가정 |
| 접촉 강성 / 감쇠비 | 5000 N/m / 0.7 | 기존 전동 밸브와 같은 연성 접촉 시험값 |

기본 750 Nm는 15 RPM에서 항상 제공되는 토크가 아니다. 전력 한도도 동시에 적용되므로 약 663 Nm로 제한된다. 초기 정지에서는 전력식의 0 나누기 대신 유한 정격 토크 한도가 적용된다.

## 조작과 설정

1. 위 레벨에서 기존 GUI의 혼합기 시작·정지 및 목표 RPM 조작을 사용한다.
2. 혼합기를 선택한 개별 장비 표시에서 목표/실제 RPM, 구동/접촉 토크, 전력 W, 누적 J, 과부하 정지를 확인한다. 현재 운전 GUI에서 개별 조작이 접혀 있으면 `설정 · 레시피` 아래의 `개별 설정 펼치기 · 기존 조작`을 사용한다.
3. 에디터의 `Plant_Pressure_Grains_LowPoly` 액터 → **Plant → Mixer Drive**에서 `Mixer Input Power W`, `Mixer Max Torque Nm`, `Mixer Inertia Kg M2`, `Mixer Power Fraction`, 램프·제동·트립 시간을 변경한다. 값은 다음 실행 또는 `ResetSimulation`에서 적용된다.
4. `Mixer Power Fraction = 0`이면 무전원이다. 기본은 1이다. 이 값은 GUI RPM 입력과 별개다.

시작 명령의 적용 완료는 전동 구동 명령을 받아 실제 회전이 시작되었음을 뜻한다. 목표 RPM 도달 보증이 아니다. 정지 완료는 실제 축 속도가 0으로 확인되어야 한다. 자동 혼합 시간은 실제 회전 시작부터의 해석 시간이며 가속·감속과 부하에 따른 속도 차이가 있으므로 동일한 혼합 품질을 뜻하지 않는다.

## 검증 범위

- `plant_mixer_drive_tests`: 실제 OpenCL에서 무전원, 가속, 유한 감속, 정전 후 관성, 에너지 적산, 리셋, 부하 감속, 과부하 트립을 검증.
- 목표 15 RPM에서 무부하 약 14.994 RPM, 별도 500 Nm 저항 시험 약 13.994 RPM, 1000 Nm 저항 시험 정지·트립. 저항 시험값은 레벨에 넣지 않았다.
- 실제 revision1125 날개 삼각형의 입자 접촉에서 약 −0.30106 Nm 반력을 확인하고 입자에 가한 힘의 반대 축 토크와 대조했다. 작은 시험 모터의 각속도가 실제 반력에 반응함도 확인했다.
- 현재 r=2 mm / dt=10 µs 설정의 실제 메시 접촉과 전동 밸브 동시 사용 적분 시험을 포함한다.
- UE 제어·자동 운전 회귀 9개 통과. 가속 중 명령 확인, 과부하, 정지 요청 전후 스냅샷 지연, 감속 후 정지 완료를 검증했다.
- PIE의 임시 24개 입자로 기존 GUI 시작·정지, 실제 각도에 따른 47개 부품 회전, 8개 밸브 닫힘 유지, 입자 수 유지를 확인했다. 해당 짧은 GUI 시험의 샘플 시점에는 날개 접촉 토크가 0이었다. 접촉 반력 검증은 별도 OpenCL 시험이다.
- 레벨 원래 입력 CSV와 입자 수를 바꾸지 않는다. 현재 파일 기준 A/B 각 100개, 총 200개이며 테스트용 24개 데이터는 `Intermediate`에만 생성한다.

결과는 `core_validation.txt`, `control_validation.json`, `play_validation.json`, `level_settings.json`에 저장한다. 원래 200개 입력의 시작 확인은 `production_start.json`, 최종 저장 상태는 `editor_ready.json`에 기록한다. 실제 수십 kg 분말로 모터 선정·막힘 임계값·소비 전력 정확도를 보증하는 시험은 아니다. 실제 회전자 관성, 접촉 물성, 감속기 효율과 보호 특성을 확보하면 보정해야 한다. 전기 회로·모터 열 방정식·기어 백래시·유연축 및 날개에 직접 작용하는 공기압 토크는 아직 해석하지 않는다.
