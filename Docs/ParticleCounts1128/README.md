# 레시피와 별도의 입자 수 설정 / 입자 없는 설비 시험

대상: `L_ProcessPlant_LowPoly_1111`, OpenCL 공정 액터. 기존 입자의 반경·밀도·종류 정의와 레시피는 변경하지 않는다.

## 사용

1. 플레이 화면 상단 **입자 설정**을 연다.
2. 공급 A~F의 초기 개수를 각각 입력한다. 0~100,000개의 정수, 직접 입력 및 ±100 버튼을 지원한다.
3. **입자 수 적용하고 초기화**를 누른다. 시간·입자 위치·밸브·혼합기 구동 상태와 자동 진행은 초기화된다. 레시피 값은 유지한다.
4. 입자 없이 설비만 시험하려면 **전체 0개 입력 · 설비만 시험** 후 적용한다. 초안 입력만으로는 적용되지 않는다.

수동 운전은 기존 절차인 전체 정지 확인 → 수동 운전 시작을 사용한다. 0개일 때도 밸브와 모터는 전력·토크·관성·감속 모델로 움직인다. 입자가 없으므로 입자 하중·혼합·분말 이송 결과는 제공하지 않는다.

설정은 레시피 파일과 분리하여 `Saved/ProcessUI/ParticleCounts.json`에 저장한다. 동일한 설비 데이터 디렉터리의 다음 플레이부터 적용한다. 다른 PC와 Git으로 공유되는 기본 원료 파일 `test_charge.csv`는 변경하지 않는다. 저장된 0개 설정은 액터 초기화 전에 읽으므로 시작할 때도 입자 GPU 버퍼를 만들지 않는다.

## 구현

- 개수를 줄이면 원본 공급원 입자부터 사용한다. 늘리면 해당 공급호퍼의 수직 원통 내부에 겹치지 않는 격자를 생성한다. 기존에 비어 있던 공급원도 지원한다. 초기 배치 공간 부족 또는 잘못된 수는 현재 실행을 초기화하기 전에 거부한다.
- 총 0개인 경우 `GranularGPU` 호스트가 OpenCL 컨텍스트·입자 버퍼·입자/벽 커널을 생성하지 않고 CPU 설비 전용 경로를 사용한다. 화면 렌더링의 GPU 사용과는 별개다.
- 빈 설비의 기계 운동은 1 ms 간격으로 계산하고, 작업자 스레드가 단조 시계에 맞춰 1배속으로 진행한다. 일시정지한 시간은 따라잡지 않는다. 압력 경계조건·밸브 개도에 따른 기존 압력 해석은 유지한다.
- 빈 입자 목록에 대한 잔류 확인은 0으로 보고하여 정지 확인이 무한 대기하지 않도록 했다. 원료 준비 확인 절차는 빈 설비에서 해제하되 수동 제어권·압력·정지 절차는 유지한다.
- 검증 중 발견한 90도 밸브의 부동소수점 개도 초과(`1 + 약 4e-8`)를 0~1 범위로 보정했다. 기존 입자 모드의 완전 개방에도 적용되는 수정이다.

## 검증

- `plant_empty_tests`: 0개/감소/증가/기존 빈 공급원, 20,400개 초기 배치, GPU 할당 0, 구동·제동·초기화, CPU와 OpenCL 무부하 계산 비교.
- 기존 `plant_mixer_drive_tests`: 실제 혼합 날개 접촉 반작용, 부하·정지·전력·과부하 테스트 통과.
- Unreal 자동화 11개: 전력 기반 제어·전체 정지·숫자 입력·레시피 회귀 테스트 통과.
- `Scripts/check_particle_count_play.py`: GUI로 200 → 6 → 0 → 6 → 200개, 잘못된 입력 거부, 레시피 불변, 1배속 측정, 밸브/혼합기 구동, 정지, 다음 플레이의 0개 설정 복원 및 GPU 계산 복귀. 실측 결과는 `play_validation.json` 참조.

1배속은 빈 설비용 목표 속도다. 입자를 1개 이상 사용하면 기존 OpenCL 물리 계산으로 돌아가며, 입자 수와 접촉 부하에 따라 속도가 결정된다.

## 입자 0개 표시: 60 fps

총 0개이면 플레이 프레임 제한을 60 fps로 설정한다. 개수 적용·초기화 시 자동 전환하며, 1개 이상이면 기존 30 fps로 돌아간다. 빈 설비의 축 상태는 16 ms 작업 배치마다 게시하고 화면에서 매 프레임 반영한다. 설비 물리 시간은 1배속을 유지한다. 플레이 종료 시 시작 전 프레임 제한을 복원한다.

현재 PC의 설비 3D 관찰 화면에서 10초/600 프레임(평균 60 fps), 계산 시간 약 10초(1.00배속), 기계 상태 게시 62.5회/초를 확인했다. 개수 변경에 따른 30↔60 fps 전환과 종료 시 설정 복원도 통과했다. 결과: `empty_60fps_validation.json`. 이는 해당 장면의 실측이며 모든 해상도·장치의 프레임 성능을 고정 보장하는 값은 아니다.
