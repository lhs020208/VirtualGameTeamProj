# 최신 설비 기능 연결 계획
대상은 /Game/ProcessPlant_20261103/L_ProcessPlant_ParticleSetup이다.
1. 최신 blend의 전용 충돌 표면, 포트와 밸브 위치를 추출하고 A~F별 입구에서 칭량호퍼까지 연결성을 대조한다. 형상과 연결을 식별한 경로만 물리에 반영한다.
2. 배관은 실제 메시, 호퍼·회전체는 기존 하이브리드 생성 절차를 최신 좌표에 적용한다. 게이트와 회전체가 고정 벽으로 중복되는지 검사한다.
3. 최신 전용 데이터로 저장된 시험 액터를 구성하고 정적 입자 미리보기 중복을 제거한다. 초기 A/B 각 10000개, C~F 0개, 밸브 닫힘, 회전 0을 검사한다.
4. 표시 컨트롤과 수동 밸브·혼합기 GUI를 연결한다. 각 공급기/칭량 출구/수취부 출구/혼합기 명령이 실제 적용 상태와 일치하는지 확인한다.
5. 실제 새 레벨에서 초기화·물리 스텝·밸브 변경·회전·리셋을 검증한다. 전체 장시간 이송과 분리해서 결과를 기록한다.
## 구현 및 실행 결과

최신 blend에서 전용 충돌/배관 메시 247개와 포트 83개를 추출했다. 공급 포트와 배관 단면을 대응시킨 결과 A~C는 P101, D~F는 P102이고, V101A~F_Body의 Z 범위는 밸브 중심면과 일치한다. 여섯 WH-101.IN 포트 위치에서 덮개 중심선에 막힌 면이 없는지 검사했다. 연속 수취부 벽은 local Z .218과 .69가 배출 포트 Z 2.21과 흡입관 축 Z 2.682에 맞도록 XY 반전 후 (3,0,1.992)m 이동했다. 원본에 기록된 중복 형상 제외 목록을 반영했다. 점검구 뚜껑은 최신 메시의 월드 좌표를 사용했다. 칭량 측 100mm 호스 연결 틈은 기존 시험 슬리브로 연결했다.

런타임 재생성 순서는 아래와 같다. 프로젝트 루트에서 Blender의 export_plant_physics_source.py로 최신 파일을 Intermediate/LatestPlantPhysics에 추출하고 새 모델의 test_charge.csv를 그 폴더에 복사한다.

    python Scripts/build_plant_runtime.py --source Intermediate/LatestPlantPhysics
    python Scripts/build_plant_hybrid.py --source Intermediate/LatestPlantPhysics --output Intermediate/LatestPlantHybrid
    python Scripts/build_plant_wall_index.py Intermediate/LatestPlantHybrid SourceAssets/ProcessPlant_20261103/Simulation

새 레벨에는 PowderPlantTest 하나가 실제 입자 렌더링과 계산을 담당한다. A/B 각 10000개, 나머지 공급기 0개, r=2mm, 밀도 1200kg/m³. 설비 표시 컨트롤에 부품 2254개, 프레임 371개, 전면 절개 대상 381개를 등록했다.

- PIE에서 여섯 공급기와 두 출구를 열고 닫아 실제 밸브 액터 상태를 확인했다. 혼합기 작동 시 패들 회전각이 변했다. 리셋 직후 시간 0, 입자 20000개, 이후 물리시간 진행을 확인했다. GUI가 호출하는 실제 Blueprint 제어 함수를 사용했다. 화면 버튼 클릭/시각 품질은 육안 검수 대상이다.
- 각 공급기를 하나씩 열고 나머지 다섯 개를 닫은 GPU 시험에서 열린 분기만 양의 유량을 보였고, 해당 게이트 중앙의 입자만 충돌 투영 없이 통과했다. 시험 압력차 1000Pa. 결과는 six_feeds.txt에 있다.
- 밸브·회전 변경 포함 경계 조회 19740건에서 원본 탐색 대비 위치, 법선, 벽 속도 최대 차이 0. 대상은 같은 하이브리드 데이터의 탐색 결과다.
- 전체 배치 이송 완료와 장시간 혼합 품질, 실제 설비 운전압의 타당성은 이번 짧은 검증 범위 밖이다. BV122는 이전 레벨의 개방 이송 상태를 따른다.

## 실제 에디터 화면 확인
2026-11-04 기존 에디터 창에서 새 레벨을 열고 플레이했다. 패널에 A~F 여섯 행과 칭량·수취 출구 및 혼합기 제어가 표시됐다. A 열기, 두 출구 열기 및 혼합기 시작을 직접 클릭해 상태 표시 전환을 확인했다. 설비 숨기기를 누르면 설비가 사라지고 빨강·파랑 입자가 남았으며 전면 개방을 누르면 설비가 다시 나타났다. 뷰포트에서 R을 눌러 밸브가 닫히고 혼합기가 정지 상태로 돌아온 것을 확인했다. 플레이 종료 후 새 설비의 편집 월드로 복귀했다. 기존 하이브리드 레벨 파일·기존 런타임 데이터·공용 게임 모듈은 git diff HEAD에서 변경이 없었다. 작은 뷰포트의 하늘 배경 위에서 상태 글자 대비가 낮았고 맵 체크에 M_PlantCutaway 경고 한 건이 표시됐다. 장시간 운전은 이번 확인 범위 밖이다.
