# 혼합기 고정 장애물 시험 — 2026-11-28

현재 레벨: `/Game/ProcessPlant_20261111_LowPoly/L_ProcessPlant_LowPoly_1111`

`Tests/MixerObstruction/TEST_Mixer_HeavyBlock_Fixed_10000kg` 노란 블록을 날개 회전 경로에 배치했다. 질량 속성은 10,000 kg이지만 **이 시험은 위치가 고정된 강체 장애물(무한 질량 근사)**이다. 무거운 자유 강체의 이동·기울어짐·파손을 해석하는 기능은 아니다.

## 사용

1. 입자 설정은 0개를 유지하고 PIE를 실행한다.
2. 공정도에서 기존 수동 조작으로 혼합기를 시작한다. 3D 보기는 관찰용이다.
3. 날개가 블록에 닿으면 실제 RPM이 0으로 내려가고 접촉 반력이 발생한다. 계속 가동 명령을 주면 약 2초의 정체 후 과부하 차단된다. 혼합기 상세 정보에서 구동/접촉 Nm, 실제 RPM, 과부하 상태를 확인할 수 있다.
4. 다시 시험하려면 PIE를 종료하고 재실행한다. 장애물을 옮기거나 삭제한 경우에도 재실행해야 한다.

블록 위치·크기·회전은 편집 상태에서 변경 가능하다. `MixerFixedObstacle` 태그, Static 모빌리티, Engine BasicShapes의 Cube 메시를 사용한다. 임의 메시를 박스로 오인하지 않도록 다른 메시/자유 강체는 오류로 거부한다. 기존 `MixerObstructionTest` 태그도 호환된다. 표시를 숨겨도 충돌은 유지된다.

## 계산

- 초기화 때 현재 장애물의 OBB와 `runtime.plant`의 실제 혼합기 회전 삼각형으로 양방향 접촉 각도를 계산한다. 회전각을 임의 상수로 지정하지 않는다.
- 삼각형/OBB SAT 검사와 회전 반경에 따른 연속 구간 팽창 경계를 사용한다. 각도 표본 사이의 얇은 장애물도 건너뛰지 않으며 최초 접촉 구간을 세분한다. 표면 여유는 0.01 mm다.
- 매 물리 시간 단계에 고정 장애물의 비관통 구속을 적용한다. 충돌은 완전 비탄성으로 처리하며, 축 관성과 모터 토크를 상쇄하는 구속 반력/충격량을 계산한다. 모터의 출력·최대 토크·가속·과부하 계산은 그대로 유지한다.
- 입자 0개의 CPU 장비 모드와 입자가 있는 OpenCL 모터 모드 모두 같은 접촉 제한을 사용한다. 이 블록 등록은 **축–고정 장애물 시험용**이며, 새 블록에 대한 입자 충돌이나 움직이는 외부 강체와의 양방향 연성은 추가하지 않았다.
- 장애물이 없거나 회전 경로 밖이면 제한을 적용하지 않는다. 시작부터 날개 표면과 겹치면 실행을 거부한다.

## 검증

- 실제 블록 배치의 허용 각도: 약 -0.689524 ~ +0.501516 rad. 정회전 시 약 28.735°에서 접촉한다.
- `plant_mixer_obstacle_tests`: 실제 형상의 접촉, 얇은 장애물, 회전한 OBB, 초기 겹침 거부, 비관통, 반력, 정체/차단, 역회전 이탈, 초기화, 장애물 제거, CPU/OpenCL 일치 통과.
- 기존 `plant_empty_tests`, `plant_mixer_drive_tests` 통과. 기존 무부하/입자 하중/제동 경로 회귀 확인.
- 에디터 확인 스크립트: `Scripts/check_fixed_mixer_obstacle_play.py`. 입자 설정과 블록 배치를 보존하고 종료한다. 결과는 같은 폴더의 `play_validation.json`에 기록한다.
