# 공정 OBB 통로 시험 레벨

- 레벨: `/Game/ProcessPlant_20261029/L_ProcessPlant_OBBTest`
- 기준 레벨: `L_ProcessPlant_FlowTest` (기존 삼각형 충돌 유지)
- 시작 기본 레벨을 OBBTest로 변경. 실행 중이던 에디터는 이전 DLL을 사용하므로 저장 후 재시작 필요.
- 데이터: `SourceAssets/ProcessPlantOBB`; 생성: `python Scripts/build_plant_obb.py`.
- 공급기별 1,000개, 총 3,000개, 반지름 1.25mm, dt 10µs, 접촉 반복 8회 유지.
- 시작 시 모든 밸브 닫힘, 혼합기 정지. 기존 GUI로 각각 조작.

## 충돌 방식

정지 설비의 상세 삼각형 BVH 조회를 생략한다. 141개 OBB 내부 공간의 합집합으로 입자가 움직일 수 있는 통로를 만들고, 그 외곽을 벽으로 계산한다. 구 반지름만큼 각 내부 OBB를 축소하고, 그 합집합 바깥으로 나온 입자는 가장 가까운 내부 경계로 보정한다. OBB 끝부분은 충분히 겹쳐 연결부의 가짜 끝벽을 없앴다. 호퍼 경사면과 필터는 추가 고체 OBB 21개와 구–상자 접촉으로 계산한다.

입자의 이동 경로/속도를 강제로 지정하는 방식은 아니다. 기존 중력, 공기 항력, 입자 접촉 계산을 유지한다. 수동 밸브 원판과 회전 날개는 기존 충돌 계산을 유지한다. 표시용 설비 메시와 렌더 모드는 그대로이며, 실제 OBB 충돌 경계는 표시 메시와 다르다. GUI에 OBB 근사 시험임을 표시한다.

## 허용한 형상 근사와 한계

- 원형 관을 내접 사각 단면으로 변경하므로 단면적은 원형의 약 63.7%다. 호퍼도 사각 경사면으로 근사하여 용적이 바뀐다.
- 공급관–칭량부 및 이송관–수취부 연결 끝점을 내부 중심까지 확장한다.
- 수취부–혼합기는 반지름 139mm 기준 내접 사각 통로로 단순화했다. 최종 설비 설계가 아니다.
- 압력 해석은 기존 원형 관로의 준정상 1D 모델을 유지했다. 사각 통로 면적/손실계수로 재보정하지 않았으므로 정량 유량·압력 및 실제 체류시간 검증에 사용할 수 없다.
- 과거 원형 용기의 저장 입자를 직접 불러오면 OBB 외부 입자가 생길 수 있다. 실제로 과거 hopper fixture는 안전 검사가 중단했으며 성능 비교에서 제외했다. 새 초기 배치에서 시작한다.
- 전체 공정 완주, 혼합 품질 및 실제 설비와의 일치는 아직 검증하지 않았다.
- 형상 단순화만으로 목표 속도 확보를 보장하지 않는다. 현재 구현은 내부 OBB 목록을 순회하며, 공간별 후보 목록 최적화는 별도 후속 대상이다.

## 레벨 정리

`levels.json`에 기록한 구형 데모/실험/백업 레벨 16개를 참조 검사 후 삭제했다. 공용 메시·머테리얼·데이터 에셋은 삭제하지 않았다. 남은 레벨은 다음 4개다.

1. `L_ProcessPlant_OBBTest`: 새 OBB 시험.
2. `L_ProcessPlant_FlowTest`: 원래 충돌 모델 비교 기준.
3. `L_ProcessPlant_Assembly_Display`: 공정 시험 레벨 재생성에 필요한 표시용 원본.
4. `L_ProcessPlant_Assembly`: 설비 가져오기 원본.

레벨 생성 스크립트는 기존 OBBTest 덮어쓰기를 거부한다. 데이터 변경은 생성 스크립트로 별도 재생성할 수 있다. 공유 에셋 및 예전 개발 문서는 역사 기록으로 보존한다.
