# 설비 분말 이송 시험

시험 레벨: `/Game/ProcessPlant_20261029/L_ProcessPlant_FlowTest`

기존 `L_ProcessPlant_Assembly_Display`와 원본 Blender 파일은 유지한다.
`Plant_Pressure_Grains_Test` 액터가 초기 분말과 계산을 담당한다. 공급기당
10,000개, 현재 3종 총 30,000개이며 반지름 1.25 mm, 밀도 1,200 kg/m³의
동일한 가상 물성을 사용한다. 색상은 투입원 추적용이다.

## 조작

- 재생: 시뮬레이션 시작. Space: 계산 일시정지/재개. R: 초기화.
- 1: 공급기, 2: 칭량 호퍼, 3: 수신기, 4: 혼합기 확대.
- 우클릭 + WASD 등 기존 카메라 조작을 유지한다.
- O: `Saved/PlantSnapshot.csv`에 현재 입자 위치와 식별자를 저장한다.
- 기존 표시 패널의 전체/전면 개방/숨김, 프레임 표시 기능을 유지한다.
  입자와 충돌 형상은 이 표시 설정의 영향을 받지 않는다.
- 액터 Details에서 시험 압력 차, RPM, 목표 시간 진행률, 고정 시간 간격,
  접촉 반복 수를 조절한다. 초기화가 필요한 설정은 Test 항목이다.

## 계산 범위 — 반드시 구분할 것

이 구현은 **실제 관 중심선과 내경으로 구성한 1차원 준정상 관로 압력 모델**과
**3차원 GPU 입자 접촉 계산**의 결합이다. 설비 내부 전체를 체적 격자로 채워
Navier–Stokes와 난류를 푸는 3차원 CFD가 아니다.

관로별 Darcy–Weisbach 손실과 시험 입구 손실을 합산하고, 지정 압력 차에
맞는 유량을 수치적으로 구한다. 각 직렬 경로에서 유량은 보존된다.
호퍼/수신기는 지정 압력을 유지하는 이상적인 저장소 경계로 취급한다.
진공 발생기의 압력–유량 곡선, 흡입 포트·필터의 실제 처리 용량, 챔버 압력
과도응답은 이 모델로 검증되지 않는다. 따라서 계산 유량을 실제 기계의
가능 유량이라고 해석하면 안 된다.

입자는 중력, 국소 공기속도에 대한 구 항력, 입자 접촉, 원본 삼각형 벽과
회전부 접촉으로 이동한다. 입자를 경로 위로 배치하거나 다음 장치로 순간이동
시키지 않는다. 축소/확대 관에서는 연속 방정식에 맞춘 반경 방향 유속도
사용한다. A/C 측면 유입 상자는 균일한 횡방향 유속으로 근사하며,
접합부의 3차원 질량·운동량 방정식을 해결한 것은 아니다. 입자 → 기체 반작용, 밀집 분말의 압력 손실, 입자 회전·형상,
응집력은 이 시험 경로에서 아직 포함하지 않는다. 접촉은 기존 근사 위치
기반 GPU 해석기이며, 실물 분체의 정량 정확도가 인증된 DEM은 아니다.

## 단계와 안전 처리

1. 시작/초기화 시 공급기 A·B·C와 공용 칭량 호퍼 출구는 모두 닫힌다.
   GUI에서 원하는 공급기를 각각 열어 칭량 호퍼로 공급한다.
2. 공급 완료를 확인하고 공급기를 닫은 뒤 공용 칭량 호퍼를 GUI로 열어
   수신기로 이송한다. 전량 도달에 따른 자동 호퍼 개방은 사용하지 않는다.
   출구 개방 시 공급 경로와 수취부 경로를 연결해 칭량호퍼 압력을 풀고,
   공급 경로 유량 합과 수취부 경로 유량을 일치시킨다. 공급 공기는 계속 흐른다.
3. 수취부 → 혼합기 출구는 GUI의 열기/닫기로 수동 조작한다. 전체 입자 수에
   따른 자동 배출 전환은 사용하지 않는다. 출구를 열어도 상류 밸브를 자동으로
   닫거나 조작을 잠그지 않는다. 혼합기는 별도 시작/정지 버튼으로 조작한다.
   시작/초기화 시 수취부 출구도 닫히고 혼합기는 정지한다. RPM은 액터의
   MixerRPM 설정을 사용하며 기본 15 RPM이다. Space 일시정지는 회전도 멈춘다.
   수취부 출구 닫힘은 입자가 개폐 단면을 벗어날 때까지 대기한다.
   수동 저장/배출에서는 기존 단계 완료 시간 초과 정지를 적용하지 않는다.


밸브는 시험용 이상적인 개폐 단면으로 계산한다. 개방 시 해당 디스크는
렌더링에서 숨긴다. 실제 밸브의 개도별 유동 저항·유한 개폐 시간·열린
디스크에 대한 충돌까지 모델링한 것은 아니다.

시간 간격당 이동량, 비정상 수치, 영역 이탈, 항력 적용 범위를 검사한다.
수치 안전 검사 실패 시 중단하며, 입자를 삭제하거나 강제로
이송해 완료한 것으로 표시하지 않는다. 목표 진행률은 요청값이고 실제
계산 속도 보장이 아니다.

## 현재 검증의 해석

- 1D 관로를 16배 세분한 유량과 비교했을 때 현 격자의 차이는 공급 경로 약
  1.54~1.58%, 칭량 호퍼→수신기 경로 약 3.15%였다. 이는 1D 모델 내부의
  공간 분할 민감도이며 실제 유량 오차의 상한이 아니다.
- 소량 30개 경로 시험에서는 전량 수신기 도달 후 16개가 혼합기로 들어갔고,
  14개는 수신기 내부 가스켓 턱에 남았다. 원본 형상과 현재 유동 근사에서 나온 잔류 결과이며 실물 잔류 예측은 아니다.
- 30,000개 시험에서는 전량 칭량 호퍼 도달을 확인했다. 이후 닫힌 밸브
  가장자리의 비물리적 위치 보정과 원판/몸체 간 치수 불일치를 발견했다.
  원판을 유한 두께 원기둥의 거리 기반 접촉으로 바꾸고 수신기 몸체의 실제
  139 mm 내반지름까지 닫도록 수정한 뒤 재검증한다.
- `pressure_boundaries.json`은 별도 3D GasGrid 준비 자료다. 현재 시험 액터는
  `runtime.plant`와 `runtime.routes`의 1D 압력 경로를 사용한다.
- 성능 검증 중 다른 GPU 작업과 경합한 측정값은 단독 성능으로 사용하지 않는다.

셀별 시험 유량·입출구 게이지압은 `pressure_cells.csv`에서 확인할 수 있다.
각 경로의 입구를 0 Pa, 출구를 -1000 Pa로 둔 이상적인 시험 경계조건이다.

이음부 보정 후에도 수신기 직전 밸브 몸체의 단차 부근에 잔류가 관측됐다.
이 영역의 재순환 유동을 해결하지 않는 1D 근사이므로, 잔류 원인·양을
실물과 일치한다고 해석하면 안 된다. 시험 운전의 배출 조건과 전량 이송
성공 여부를 구분해야 한다.

## 수동 밸브 연결 유동 수정 (빌드 1065)

- 공급 경로 3개(대기압 0 Pa) → 칭량호퍼 압력 노드 → 수취부 지정 흡입압의
  준정상 1D 저항 네트워크를 계산한다. 연결부에서 유입량 합=유출량을 만족한다.
- 칭량 출구가 닫히면 전용 칭량호퍼 흡입원이 -시험압력을 유지한다.
  열리면 이 전용 흡입원을 분리하고 수취부 흡입원으로 이송하는 시험 운전을
  가정한다. 실제 펌프 제어·밸브 연결이 확정된 설계라고 주장하지 않는다.
- GPU에서 단계 번호로 유동 셀을 제외하던 처리를 네트워크 모드에서는 제거했다.
  닫힌 공급 분기의 유량은 0이며, 칭량 출구를 열어도 열린 공급 분기에는 항력이 남는다.
- 공급 밸브 8조합 × 칭량 출구 2상태 × 압력 3값(0/1000/3000 Pa)의 연속성,
  닫힌 경로 차단, 압력 범위 및 GPU 단계 번호 변경에도 동일한 입자 속도 검사 통과.
- 이상적인 흡입압 유지, 비압축성 준정상·희박 단방향 항력 근사다. 공기 저장에 따른
  압력 과도응답, 필터 저항/막힘, 진공장치 성능 곡선은 포함하지 않는다.
  수취부 출구 개방 시 혼합기에서 유입되는 공기 경로도 아직 해석하지 않는다.
  따라서 전체 설비의 실제 압력장을 검증한 것은 아니다.
