# FlowTest: 30개, 지름 4mm 시험 (2026-11-02)

- 대상: L_ProcessPlant_FlowTest / SourceAssets/ProcessPlantPhysics.
- 공급기별·종류별 10개, 합계 30개. 반지름 1.25mm → 2mm, 지름 2.5mm → 4mm. 밀도 1200kg/m³ 유지.
- 정의된 관로 최소 반지름 약 22mm(내경 44mm)에 비해 작은 크기를 선택했다. 전체 경로의 동적 막힘이나 모델 연결부의 결함이 없다는 보장은 아니다.
- CSV 반지름을 계산과 렌더 크기 양쪽에 적용했다. 현재 해석기는 전체 입자의 동일 반지름을 요구하므로 서로 다른 반지름은 명시적으로 거부한다.
- Section01~04의 저장된 입자 배치는 변경하지 않았다. 구간 데이터 생성기도 3000개·반지름 1.25mm를 유지하도록 고정해 향후 재생성 시 FlowTest 설정이 번지지 않게 했다.
- 기존 레벨 파일은 변경하지 않았다. 시작/초기화 시 CSV를 읽는다. 새 모듈 1068을 적용하려면 열린 에디터를 저장하고 재시작한 뒤 Play한다. 편집 상태의 기존 미리보기는 액터의 Reset Simulation으로 갱신 가능하다.

- Unreal 빌드 1068 성공.
- 실제 FlowTest 로드 후 Reset: 3개 표시 그룹 각 10개, 각 표시 지름 0.4cm 확인 (`level_check.json`).
