# 충돌 대상 및 불필요 후보 점검

2026-11-03. 운영 레벨/충돌 데이터 변경 없음. `Scripts/audit_plant_collision_candidates.py`로 재현한다.

## 확인 범위

현재 Hybrid 정적 충돌 데이터, 원본 메시 선택 목록, 커널의 후보 제외 조건을 확인했다. 초기 20,000개 위치와 이전에 저장한 정체 스냅샷에서 각각 512개 위치를 균등 인덱스 추출했다. GPU 실행시간 프로파일이 아니라 고정 위치에서 원본 BVH leaf AABB 후보를 재구성한 오프라인 분석이다. 반경 2.004 mm. 투영 도중 위치 변화, 캐시 재사용, 회전체/밸브/혼합기 경계의 원본 메시 fallback은 수치에 포함하지 않았다.

## 결과

- 원본 물리 자료 198개 중 정적 소스 83개가 선택된다. 하이브리드 정적 형상 185,682개, 별도 회전체 형상 2,726개다. 화면의 전체 액터를 모두 DEM 충돌로 검사하는 구조가 아니다.
- 정적 선택 목록에 RackPost/프레임/모터/게이지/AIR101 공압 조절기 및 외부 호스는 없다. 표시용 액터와 DEM의 `runtime.plant`는 별도다.
- 공급기 C 입자를 0개로 해도 C 충돌 형상은 남는다: H-101C 644개, P101C 출구 목 384개, V101C 몸체 384개, P101C 경로 8,832개, 연결관 384개. 이것만으로 삭제가 안전한 것은 아니다. 공용 통로에서 C 분기로 역진입할 가능성과 닫힌 밸브 경계를 보존해야 한다.
- 상세 배관·페룰·씰은 원본의 전체 삼각형을 가져온다. 외측 면도 포함되며 정상적인 내부 이송에서는 많은 면에 닿지 않는다. 그러나 내측 접합면까지 함께 있는 부품이므로 부품 전체 삭제는 누출/벽 관통 위험이 있다.

## 후보 묶음의 낭비

초기 위치 표본은 11,337개 형상 후보가 선택됐지만 개별 형상 AABB와 겹치는 후보는 없었다. 정체 위치 표본은 28,541개 후보 중 27,489개(96.3%)가 개별 형상 AABB 기준으로 겹치지 않았다. 원본 처리 순서를 유지한 leaf 묶음에 서로 먼 형상이 들어가면 묶음 전체 AABB가 넓어지는 것이 원인이다.

정체 표본의 예:

| 소스 | 형상 후보 | 개별 AABB 불일치 |
|---|---:|---:|
| BV122_PIPE_Receiver_side | 7,729 | 7,526 |
| BV122_PIPE_Weighing_side | 6,618 | 6,375 |
| PL_C02_Ferrule | 2,010 | 1,980 |
| H-101C_Collision | 164 | 164 |
| MX-301_Collision_Vessel | 144 | 144 |
| V101C_Body | 96 | 96 |

**96.3%는 정밀 충돌 연산 낭비율이나 예상 속도 개선율이 아니다.** `plant_hybrid_shape`는 삼각형별 AABB, OBB별 로컬 범위 검사를 이미 수행한다. 위 삼각형 후보의 많은 부분은 정점 로딩과 범위 검사 후 `plant_closest` 전에 반환한다. OBB도 좌표 변환/범위 검사 후 제외될 수 있다. 또한 캐시가 같은 결과를 재사용하면 이 호출 자체도 생략될 수 있다.

## 권장 방향

1. 부품을 무작정 삭제하지 말고, leaf 안에서 실제 근처 형상만 보존하는 후보 캐시를 검토한다. 위치 보정으로 이동한 뒤 새 접촉을 빠뜨리지 않도록 보수적 여유 범위/재구축이 필요하다.
2. 원본 접촉 순서를 유지하면서 더 작은 공간 후보 묶음을 구성한다. 이전 공간 재정렬 실험은 접촉 순서 변화로 거절된 이력이 있으므로 단순 재정렬은 재사용하지 않는다.
3. 관 외측 면 제거는 내측/외측/끝단을 구분한 전용 충돌 메시로 별도 검증한다. 열린 접합부와 역류 경계는 유지한다.
4. 위 수정 전후 실제 GPU 시간을 비교해야 효과를 판단할 수 있다. 이번 점검만으로 현재 최대 병목이나 개선 배율을 결론내리지 않는다.
