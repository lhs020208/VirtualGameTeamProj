# 벽 충돌 최적화 01~04 — 2026-11-02

대상: `L_ProcessPlant_HybridCollisionTest`, RTX 4060 Ti, 30개(종당 10개), 반지름 2 mm, dt 10 µs, 접촉 반복 8회, 배치 16. 기존 물성·시간 간격·형상·접촉 처리 순서는 유지한다.

## 작업별 결과

1. **공간 탐색과 접촉 순서 분리: 구현.** 원래 충돌 리프들을 별도의 공간 BVH에 등록한다. 공간적으로 찾되 원래 리프 순서로 처리한다. 위치 보정 후 새로운 후보가 생길 가능성까지 다시 확인한다. 인덱스만 사용하는 mode 1은 반복 탐색 비용이 있어 최종적으로 캐시 구축에 활용한다.
2. **가까운 벽 후보 재사용: 적용.** 입자별 정적 벽/회전체 후보를 따로 저장한다. 보수적인 여유 영역 안에 있을 때만 재사용한다. 회전체는 회전한 로컬 좌표로 판정한다. 중간 보정으로 영역을 벗어나면 다음 원래 리프부터 정확한 검사로 복귀한다. 64개 초과 후보는 원래 검사로 복귀하며 일부 후보만 사용하는 일이 없다.
3. **중복 경계 계산 공유: 적용.** 입력 위치·반경·회전각·참조 위치·단계가 모두 정확히 같을 때만 위치·법선·벽 속도를 재사용한다. 속도용으로 확대한 반경은 별도 질의다. 상태 리셋과 밸브/압력 갱신 시 캐시를 비운다. 실제 하이브리드 레벨은 mode 3을 선택한다. 기존 FlowTest는 mode 0을 유지한다.
4. **단순 관의 수학적 곡면 치환: 구현 및 평가, 실제 레벨 적용 제외.** 공급기 출구 목 3개를 개방된 유한 환형 원통으로 시험했다. 원본 48각형 대비 최대 기하 오차 약 53.5 µm이지만, 벽 내부·모서리를 포함한 질의에서 접촉 투영 차이가 최대 7.032 mm, 법선 차이 2였다. 짧은 동작 비교에서도 속도 이득이 없었다. 곡관 및 현재 실행 레벨은 기존 형상을 그대로 사용한다. 실험 옵션 `--analytic-necks`는 별도 출력 폴더에서만 허용된다.

## 속도 비교

같은 초기 상태, 동일 3,000스텝(0.03초), 프로파일러 끔. 에디터의 기존 물리 계산을 일시정지한 상태에서 순차 측정. 초기/배관 상태에서 기준과 최종 각각 3회 중앙값. 화면 포함 전체 공정의 최소 보장 속도가 아닌 솔버 처리량이다.

| 구간 | 최적화 전 | 후보 캐시만(1회) | 최종(중앙값) | 개선 |
|---|---:|---:|---:|---:|
| 초기 공급기 | 0.01913배 | 0.03668배 | 0.05494배 | 2.87배 |
| 배관 진입 체크포인트 | 0.004867배 | 0.01064배 | 0.02692배 | 5.53배 |

최종 반복 범위: 초기 0.05340~0.05500배, 배관 0.02673~0.02697배. 따라서 30개 전체 공정에서 0.03배 이상을 보장한다고 말할 수는 없다. 4번 실험은 각각 0.05305배/0.02615배로 이점이 없었다. 동시 PIE 계산이 켜져 있던 앞선 임시 측정값은 성능 결론에서 제외한다.

분리 프로파일은 계측 및 별도 커널 실행 비용 때문에 일반 실행보다 느리다. `final_split.json`은 벽 투영/속도용 검사 합계 약 1.258 GPU초로 여전히 가장 큰 단일 범주임을 보여준다. 이 측정 중 CPU 빌드가 진행되어 최종 처리량 근거로 쓰지 않는다. 다음 과제는 후보 구축보다 남은 실제 접촉 검사, 커널 실행 횟수, 복잡한 접합부 형상이다.

GPU 확인 시 43°C, 약 45W였다. 지속 열 스트레스 시험은 하지 않았다.
