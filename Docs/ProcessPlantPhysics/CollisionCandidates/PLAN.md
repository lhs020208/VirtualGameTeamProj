# 충돌 후보 최적화 실행 계획

프롬프트 1회와 해당 문제 수정을 작업 단위로 한다. 2026-11-03 순차 실행 승인. 커밋/푸시 없음. 기존 공기장·물성·입자 수·충돌 표면은 보존한다.

1. 기준 실행 파일, 입력 해시, 초기/정체 위치 재현 자료를 보존하고 경계 투영/프로브 GPU 시간을 측정한다.
2. GPU 업로드 시 형상별 경계 정보를 사전 계산한다. 단독 성능이 나쁘면 기본 적용하지 않는다.
3. 기존 leaf 후보 캐시에 개별 형상 마스크를 추가한다. 보정으로 여유 범위를 벗어나면 누락 없이 기존 탐색으로 복귀한다.
4. 개별 형상의 공간 인덱스로 후보를 찾고 원래 leaf/형상 순서로 정렬해 접촉 계산 순서를 보존한다.
5. 회전, 밸브 갱신, 빠른 이동, 다중 벽, 캐시 초과 및 복귀를 검증한다.
6. 작은 재현 시험과 3,000/20,000개 동일 입력 비교 후 효과가 있는 방식만 에디터 기본값에 적용한다. 단기 측정과 장시간 전체 공정 검증을 구분한다.

결과는 RESULTS.md 및 개별 JSON에 기록한다. 기존 mode 0~3은 비교 및 복귀용으로 유지한다. mode 4~6은 각각 02~04 단계의 실험 방식이다.
