# 수취부 직전 입자 정체: GPU 분리 시험

2026-11-03. 사용자의 요청에 따라 실제 plant GPU 솔버와 현재 hybrid 충돌 데이터를 사용했다. 운영 레벨, 물성, 20,000개 초기 입자 설정은 변경하지 않았다. 진단 실행 파일만 추가했다.

## 조건

- `SourceAssets/ProcessPlantHybrid/runtime.plant`, `runtime.routes` 사용.
- 공급 A/B 열림, C 닫힘, 칭량 출구 열림, 수취부 출구 닫힘, 회전 0 RPM.
- 시험 압력차 1,000 Pa. 계산된 칭량 게이지압 -250.2353 Pa, 수취부 -1,000 Pa.
- 반지름 2 mm, 밀도 1,200 kg/m³, 마찰계수 0.4, dt 10 µs, 접촉 반복 8.
- 에디터 코드와 같은 threaded=true, triangle_fast=false, wall_mode=3, kernel_optimize=true.
- 첫 탐색은 서로 떨어진 6개 입자. 최종 결론은 입자 간 영향을 배제한 **한 개씩 독립 실행**한 `isolated_*.csv`를 기준으로 한다.
- 각 시험은 0.2초 또는 0.6초의 물리 시간을 계산했다. 단일 입자 실행은 약 7~23초 걸렸다. 전체 공정 처리속도 측정은 아니다.

## 수취부 입구 앞 동일 위치 비교

시작 위치 (2.69, 0, 2.6231) m. 관 중심은 (y=0, z=2.682) m, 내경 122 mm. 바닥 가까이에 둔 입자다.

| 조건 | 물리 시간 | X 이동 | 결과 파일 |
|---|---:|---:|---|
| 현재 물성·유량, 정지 출발 | 0.2 s | 0 mm | isolated_base.csv |
| 마찰만 0, 기존 유량 | 0.2 s | 38.15 mm | isolated_no_friction.csv |
| 기존 마찰, 유량만 2배 | 0.2 s | 74.33 mm | isolated_double_flow.csv |
| 기존 조건, 진입 속도 0.2 m/s | 0.6 s | 9.96 mm | isolated_slow.csv |
| 기존 조건, 진입 속도 2 m/s | 0.6 s | 377.47 mm | isolated_incoming.csv |
| 마찰 0, 유량 0 | 0.2 s | 0 mm | isolated_no_air.csv |

0.2 m/s 입자는 약 0.11초에 정지했다. 2 m/s 입자는 입구를 통과한 후 수취부 바닥까지 떨어졌다. 따라서 검사한 중앙 하부 경로는 고정된 막힘벽으로 완전히 폐쇄되어 있지 않다. 다른 위치의 돌출부·입자 집단 막힘까지 부정하는 결과는 아니다.

마찰 제거와 유량 증가는 원인 분리를 위한 진단 조건이다. 실제 물성이 마찰 0이라는 뜻도, 현재 펌프로 유량 2배가 가능하다는 뜻도 아니다. 2배 유량은 압력 해를 다시 구하지 않고 유량 필드만 배율 변경했다.

## 확인된 원인

1. **현재 공기 힘과 바닥 마찰의 조합에서 느린 입자가 정체한다.** 정지 출발은 움직이지 않고, 0.2 m/s 입자는 감속 정지한다. 벽을 그대로 둔 마찰 제거/유량 증가 시험에서는 움직였다. 입자 간 접촉이 없어도 나타나므로 20,000개 입자의 집단 막힘만으로 설명할 현상이 아니다.
2. **넓어진 관에서는 풍속이 낮다.** 현재 유량 0.05772056 m³/s에서 내경 44 mm의 평균 속도는 약 37.96 m/s, 내경 122 mm에서는 4.93766 m/s다. 수취부에 가까워질수록 같은 직경 안에서 계속 낮아지는 구현은 아니다. `field_probe.txt`의 X=1.9~2.77 m 구간은 모두 같은 유량·같은 속도이고 방향은 +X다. 정지 입자의 계산 항력 가속도 약 2.01 m/s²에 비해 평평한 바닥의 단순 마찰 규모 μg는 약 3.92 m/s²다. 이는 관측된 정체와 부합하는 대략적인 힘 비교이며 이 근사 접촉 솔버의 정확도 인증은 아니다.
3. **BV122 연결부 홈에는 공기장과 벽 형상의 불일치가 있다.** 실제 내벽 반경은 일부 64 mm, 공기장 반경은 61 mm다. (2.17,0,2.6201) m의 입자는 공기장 밖이다. 마찰을 0으로 하고 전체 유량을 2배로 해도 이동하지 않았다(`isolated_recess.csv`). 3 mm 깊이 홈과 출구 턱도 존재한다. 유량 숫자만 키워서는 이 공기장 누락을 고칠 수 없다.
4. **수취부 내부의 필터 방향 공기 흐름이 없다.** 이송 경로 공기 셀은 X=2.77 m에서 끝난다. 현재는 1D 압력 손실망에 관내 속도를 부여하는 단방향 근사이며, 눈에 보이는 상부 진공장치가 수취부 내부의 3D 공기장을 자동으로 생성하지 않는다. 따라서 “수취부 위 펌프까지 공기가 흐른다”는 물리 요구를 현재 구현이 모두 만족하지 않는다.

## 우선 수정 대상

1. 유체 통로를 수취부 입구부터 내부·필터 흡입 경계까지 연결하고 연결부 홈의 유체 영역도 실제 벽과 맞춘다. 질량 유량 연속성과 벽 비관통을 검증한다.
2. 실제 입도·밀도·벽 마찰, 관경, 시험 압력 조건을 일관되게 설정한다. 넓어진 관에서 재비산/이송이 가능한지 분리 시험한다. 단순히 마찰을 없애거나 공급호퍼를 가압해 통과시키는 수정은 하지 않았다.
3. 낮은 속도의 바닥 접촉에 대해 dt/정밀도 수렴성을 검증한 뒤 소량 집단 시험과 20,000개 재시험을 한다. 이번 시험은 현재 솔버에서 원인을 분리한 것으로 실제 설비의 이송 성능을 보증하지 않는다.

## 재현

프로젝트 루트에서 `plant_transport_diagnostics` Release 타깃 빌드 후:

```text
Intermediate/PowderCore/Release/plant_transport_diagnostics.exe SourceAssets/ProcessPlantHybrid output.csv 0.4 1 20000 0 3
```

인수: 데이터 폴더, 출력 CSV, 마찰계수, 유량 배율, step 수, 초기 X 속도, 위치 번호.
위치 번호 1=BV122 홈, 3=수취부 직전, 4=입구 이후. 생략하면 6개 위치 동시 탐색이다.
출력은 1,000 step(0.01초) 간격 위치·속도·벽 법선·투영량이다.
시험 중 확인한 GPU 온도는 46~48°C였다(상시 최대치 측정은 아님).
