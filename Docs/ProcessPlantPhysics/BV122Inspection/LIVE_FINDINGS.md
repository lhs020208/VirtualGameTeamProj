# 실행 중 정체 조사

현재 PIE를 정지/리셋하지 않고 물리 시각 6.42368~6.45392초의 위치 스냅샷 두 개를 읽었다. 시험 압력 1000 Pa, 20000개, 오류 없음. A/B 열림, C 닫힘, 칭량 출구 열림은 UI에서 확인했다. 속도는 CSV 위치 차분이므로 정밀한 순간 속도/접촉력 측정은 아니다.

- X=2.655~2.77 m 수취부 직전 206개: 중앙 변위 약 0.0799 mm / 0.03024 물리초. 평균 X 전진속도 약 0.00703 m/s. 모두 반경61mm 기류 영역 안에 있었다.
- X=2.2~2.445 m: 5526개, 중앙 변위2.109mm. 평균전진0.06679m/s.
- BV122 부근 2550개 중 434개는 반경61mm 기류 영역 밖. 이는 별도 홈/공기 영역 불일치 문제다.
- X=2.77~2.9 m에서 관높이 주변1개는 두스냅샷에서 움직임이없음. 이영역엔 현재 흐름셀이 없다.
- 동일1000Pa 수동네트워크 A/B 개방 조건 재계산: 칭량노드-250.235Pa, 수취부-1000Pa, 이송유량0.0577206m3/s, 내경122mm의 축방향공기속도4.93766m/s. 방향은 수취부쪽 +X다. 실제 GPU 유량버퍼를 읽은 값은 아니며 동일코드식/조건의 CPU재계산이다.
- 구현 항력식에서 정지한 r2mm/rho1200 입자의 수평항력가속도는 약2.011m/s². 기본벽마찰mu0.4에서 평평한바닥 단일입자의 마찰한계mu*g=3.924m/s². 바닥에침전한입자가 정지/감속할수있는조건이다. 군집의정확한힘은 개별접촉상태를추적해야하지만 압력차가존재한다는이유만으로 운반이보장되지않는다.
- 바닥근처 Y0/Z2.623,2.626,2.640m 및 관축 Z2.682m에서 X2.64→2.91의 원본충돌표면 +X광선검사상 중앙을가로막는면은없다. 유한반경입자 모든위치의통과검증은아니다.
- 현재 시뮬레이션에서는 펌프가 있는 시각적위치로부터 유동장을해석하지않는다. 1D관망압력차로 정한 공기속도를 고정관영역에 적용한다. 수취부입구 X2.77에서영역이끝나고 필터로향하는내부기류, 분말압력피드백/막힘에따른손실은없다.

결론: 관내공기방향이역전되어서멈추는증거는없다. 실제후단정체입자는대부분공기영역안이며, 항력보다큰바닥마찰한계와입자적층이유력하다. 밸브홈의무기류영역및수취부내부기류누락은추가구현결함이다. 물성/형상/유동파라미터는바꾸지않았다. 정확한원인분리는현상태에서마찰·항력·접촉충격량기록과독립재현시험이필요하다.
