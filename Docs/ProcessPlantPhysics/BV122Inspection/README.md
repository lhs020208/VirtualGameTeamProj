# BV122 칭량 → 수취부 밸브 접합부 검사

2026-11-02. 실행 중인 Unreal Editor에는 입력·정지·리셋을 하지 않았다. GPU 작업도 실행하지 않았다. 원본에서 내보낸 SI 메시 JSON과 현재 ProcessPlantHybrid/runtime.plant를 CPU로 확인했다. 원본 파일 SHA256은 내보내기 manifest와 일치한다. 별도 Blender 4.2로 원본 열기는 실패했다(파일은 Zstandard 압축 헤더). 따라서 원본 GUI 내부 검사는 완료하지 않았으며 아래 결론은 내보낸 실제 충돌 형상 분석이다.

- 대상: BV122_110_Split_body_half 두 개, BV122_111_Ferrule_neck 두 개, 전후 연결관. 관 축은 Blender X, 중심 Y=0/Z=2.682 m.
- 전후 관 내경 약 122 mm, 밸브 몸통 내경 약 128 mm. X=2.153800~2.186200 m 구간에 길이 32.4 mm, 반경 방향 깊이 3 mm인 환형 홈이 있다. 수취부 방향 출구에서 다시 내경 122 mm로 좁아져 하부에 3 mm 턱이 생긴다.
- 현재 입자는 반지름 2 mm(지름 4 mm). 바닥으로 가라앉은 입자가 홈에 모이거나 출구 턱에서 감속·정체될 가능성이 있다. 입자 중심의 이동 방향과 접촉력/항력이 필요하므로 관찰된 정체 원인의 단독 확정은 아니다.
- 원본 몸통 두 반쪽 사이 X=2.168~2.172 m에는 축방향 약 4 mm 틈이 있다. 현재 충돌 모델에는 Test_BV122_seal이 X=2.167~2.173 m, 반경 64 mm로 들어 있어 이 틈을 연결한다. 중앙 바닥 반경 63.99997 mm로 실제 packed 충돌 삼각형에서도 확인했다.
- 현재 충돌 삼각형 대상으로 X=2.13~2.21 m 하단 401개 단면을 광선 검사했으며 바닥 누락은 0개. 이는 해당 하단 단면 검사이며 모든 각도에서의 수밀성이나 시간 적분 관통을 보증하지 않는다.
- 따라서 현재 가장 명확한 형상 문제 후보는 열린 4 mm 이음새보다 122→128→122 mm 전환의 홈/출구 턱이다. 단순 OBB 변환 때문인 부분은 아니며 이 위치는 기존 삼각형 형상을 유지한다.

수정 후보: 밸브 시트/라이너를 내경 122 mm로 연속되게 구성하거나 전후 단차를 완만하게 연결한다. 실제 밸브 설계에 홈이 필요한 경우에는 임의 제거 대신 실제 시트 형상을 확인해야 한다. 이번 요청은 검사이므로 모델·충돌·물성 파일은 수정하지 않았다.

수치: measurements.json. 실행 중 입자 위치·속도는 읽거나 변경하지 않았으므로 특정 정체 입자의 접촉 이력 검증은 하지 않았다.
