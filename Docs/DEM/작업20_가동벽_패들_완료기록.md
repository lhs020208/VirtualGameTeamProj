# 작업 20 — 처방된 가동 벽과 간단한 패들 시험

상태: 완료 (2026-10-21). PowderCore 0.20.0.

## 구현한 범위

작업 19의 정적 삼각형 메시를 강체 운동시키는 `MovingTriangleMesh`와 `PrescribedMotion`을 추가했다. 구형 `ParticleSystem`과 비구형 `ClumpWorld` 모두 가동 메시를 접촉 대상으로 사용한다. 벽은 지정 운동을 따르는 무한 질량 경계이며 입자 반력 때문에 RPM이 감소하지 않는다. 모터 전류·기어·축 관성·속도 제어기·구동계 동역학은 구현 범위에서 제외했다.

이번 운동은 **일정 병진 속도 + 고정 축 일정 RPM + 초기 위상**이다. 피벗 p0, 병진 속도 V, 단위 회전축 a, 각속도 ω=a·RPM·2π/60을 사용한다.

```text
pivot(t) = p0 + V t
x(t) = pivot(t) + R(axis, phase + RPM·2π/60·t) · (x_reference − p0)
v_wall(q,t) = V + ω × (q − pivot(t))
```

양의 RPM은 축에 대한 오른손 방향이고 음수 RPM은 역회전이다. 운동은 렌더 프레임 시간이나 현실 경과시간이 아니라 **해석기의 물리 시계**에 종속된다. 가변 RPM·가속 램프·시간표 운동은 아직 없다.

## 접촉 속도와 반력·일

입자 중심 속도 vp, 각속도 ωp, 접촉점까지의 팔 r에 대해 접선 미끄럼은 `vp + ωp×r − v_wall`로 계산한다. 수직 감쇠도 벽과 입자의 상대 접근 속도를 사용한다. 구름 저항은 `ωp−ω_wall`을 사용하며 접촉 이력의 법선 주위 회전은 두 각속도의 평균을 사용한다. 기존 선형/Hertz·마찰·구름·응집 모델을 재사용한다.

입자에 작용한 힘 F와 독립 구름 커플 Tr로부터 벽 피벗 기준 반력과 반력 토크를 계산한다.

```text
F_wall = −F
T_wall = −[(q − pivot) × F + Tr]
P_wall_to_particles = F · v_wall + Tr · ω_wall
ΔW = P_wall_to_particles · dt
```

독립 구름 커플은 입자 중심 토크에서 접촉력의 팔 토크를 뺀 값이다. 따라서 병진 마찰과 구름 토크의 일을 중복 계산하지 않는다. 일은 부호를 갖고 누적한다. 이 값은 처방 운동이 **입자와 접촉 탄성 에너지를 포함한 계**에 공급한 외부 일이며, 전부 입자 운동에너지로 전환됐다는 뜻이 아니다. 감쇠·미끄럼이 있는 일반 패들 실험의 전체 소산 에너지 장부까지 구현한 것은 아니다.

보고서의 `moving_wall_loads`는 각 가동 표면의 반력·피벗 기준 토크·순간 출력이다. `moving_wall_work_j`는 단계 보고서에서는 해당 단계의 일, 세계 상태에서는 누적 일이다. 정적 벽은 이 누적 일에 포함하지 않는다.

## 형상·시간·원자성

삼각형/BVH는 기준 형상으로 한 번 구축하고, 질의할 입자를 역변환해 접촉을 찾는다. 접촉점·법선은 현재 자세로 되돌리므로 매 프레임 BVH를 재구축하지 않는다. 이음부 이력 키는 기준 메시의 패치/특징 ID를 유지한다.

힘은 tn에서 평가하고 입자를 tn+dt로 적분한다. 이동 후 입자와 벽의 tn+dt 형상으로 겹침을 재검사하고, **화면도 tn+dt의 입자와 벽**을 표시한다. 최근 반력·토크는 tn에서 평가된 값이므로 출력에 `state_time_s`와 `last_load_time_s`를 따로 기록했다.

벽의 한 단계 회전은 0.01 rad 이하, 전체 벽의 보수적 이동 상한은 최소 입자 반지름의 0.05배 이하로 제한한다. 입자의 기존 이동·다중 접촉 강성·Hertz 제한도 유지한다. 벽 좌표계로 변환한 입자 중심 선분이 벽을 가로지르면 단계를 거부한다. 실패하면 입자, 이력, 물리 시계와 누적 일이 모두 이전 상태를 유지한다.

이 보호 장치는 이산 계산용이며 곡선 궤적의 정확한 연속 충돌 시각을 푸는 CCD나 자동 dt 감소는 아니다. 단위 축 오류, 비유한 값, 과도한 위상·속도 입력도 거부한다. 형상·운동 설정 변경 시 새 실험으로 Reset해야 한다.

## 언리얼 시험장과 조작

**`/Game/L_PaddleTest`**를 추가했다.

- 바닥과 사각 트레이 벽 4개는 정적 메시다. 36×2×6 cm 기본 Cube 패들 1개를 z=4 cm 피벗에서 기본 **30 RPM**으로 회전시킨다.
- 실제 렌더 LOD0를 읽어 계산한다. 정적 5개 표면 + 가동 1개 표면, 총 **288개 삼각형**이다.
- 구형 분말 3개와 두 구 이물질 3개, **6개 강체 / 9개 구성 구**를 바닥 근처에 배치했다. 실제 분말을 보정한 물성이 아닌 기존 가상 시험 물성이다.
- `Clump | Paddle`의 **Paddle RPM**을 수정하고 **R / ResetSimulation**으로 적용한다. 실행 중 필드만 수정하면 진행 중인 실험의 속도를 몰래 바꾸지 않는다. `Triangle Mesh Rig`와 `Paddle Rig`는 동시에 켤 수 없다.
- **Space** 실행/일시정지, **N** 한 단계, **R** 초기화, **O** 정지 상태 출력. 기존 우클릭+WASD 카메라 조작을 유지한다.
- HUD에 적용 RPM, 누적 일(J), 최근 패들 반력 Tz(N·m)를 표시한다. 정지 상태에서 렌더 Tick만 호출해도 물리 시간과 패들 자세는 움직이지 않는다.
- 기본 고정 dt=2e-6 s, 최대 200단계/프레임과 약 4 ms 작업 예산을 유지한다. 실제 시간보다 느리게 진행되는 계산이며 녹화 재생이 아니다.

기존 `L_Main`, `L_ClumpTest`, `L_MeshTest`, 기본 시작 맵 설정은 그대로 두었다. 정적 메시의 구형 공급·배출 통계 및 Worker 통합은 기존 후속 항목과 같이 별도 범위다.

## 상태 출력

`Saved/DEM/Clumps/<GUID>/`에 기존 몸체/구성 구/정적 표면 파일과 함께 다음을 저장한다.

- `moving_reference_0.mesh`: 변환 전 실제 패들 해석 메시(SI).
- `configuration.txt`: 적용된 RPM·피벗·축·병진 속도·초기 위상과 물성·dt.
- `paddle_state.csv`: 물리 시간, 최근 힘 평가 시간, 적용 RPM, 자세 quaternion, 누적 일, 반력, 피벗 기준 반력 토크.

현재 상태의 진단 출력이며 전체 접촉 이력을 포함하는 재시작 체크포인트가 아니다. 기록한 토크를 모터의 요구 전력·정격 토크·소비 전류로 해석하지 않는다.

## 검증 결과

- 코어 **18개 × 2회**, 언리얼 **10개 × 2회**, CLI/결과 검사 4묶음 × 2회 통과.
- 기존 **42조건 × 2회** 통과. 작업 19의 기준 CSV와 측정 시간 외 모든 수치·최종 상태가 일치했다.
- 60 RPM의 1/4회전, 피벗 병진·점 속도·역변환·음수 RPM: 오차 1e-12 이내.
- 벽과 입자가 같이 이동하면 접선 힘이 0, 이동 벨트가 정지 입자를 끌며 반력은 반대 부호. 벽의 수직 접근 속도 0.2 m/s와 감쇠 40 Ns/m는 선형/Hertz 모두 8 N의 감쇠 증가를 만들었다.
- 회전 패들의 `P=−T_wall·ω` 관계, 동일 각속도의 상대 구름 0, 순수 구름 커플의 일, 평균 스핀을 통한 마찰 이력 회전을 검사했다.
- 정지한 처방 메시와 기존 정적 메시의 1,000단계 결과는 정확히 일치했고 벽의 일은 0이었다.
- 1 kg 구, k=10000 N/m, 초기 겹침 0.001 m, 벽 속도 0.1 m/s의 무감쇠 수직 접촉을 1/4주기 계산했다. 이론적 일 0.02 J에 대해 계산값은 1e-4 J 이내였고, `Δ(K+U)−W` 오차는 400/800/1600단계에서 **3.91930e-5 / 1.96157e-5 / 9.81266e-6 J**였다. dt 절반 시 감소비 >1.8, 최종 오차 <2e-5 J 기준을 통과했다.
- 비구형 세계에서 패들 힘에 따른 입자 운동량 변화와 벽 반력 충격량이 1e-12 이내로 일치했다. 과속/관통 실패는 시간·누적 일·위치·이력에 부분 반영되지 않았다.
- 실제 언리얼 패들/트레이 메시, 30 RPM, 150,000단계 = 물리 시간 0.3초: 전달한 일 **0.25211203778347624 J**, 최대 |Tz| **5.1087349459511504 N·m**, 벽 접촉 관측 **706,412회**, 바닥 누출 없음. 관측 수는 단계별 합이며 독립 충돌 사건 수가 아니다.
- 언리얼 표시 quaternion과 같은 물리 시간의 해석 자세, 정지 시 시간/자세 불변, RPM 설정 적용 시점, 역회전, 상태 저장, 과속 초기화 거부를 검사했다.
