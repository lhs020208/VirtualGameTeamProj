# 추가 최적화 05 — 벽·날개 충돌 후보 축소

## 구현

MX301 테스트 형상의 벽 133개 평면을 연속 8개씩, 회전체 17개 부품을 연속 4개씩 묶는다. 좁은 범위의 기존 접촉 계산과 처리 순서, 마찰 계산에 쓰는 법선과 벽 속도는 유지한다. 중력·마찰·반지름·시간 간격·반복 수는 변경하지 않았다.

- 벽 그룹은 법선 성분별 최솟값/최댓값과 평면 오프셋 최솟값을 저장한다. 현재 위치 p에서 각 성분의 부호에 따라 극값을 선택하면 `max(dot(n,p)-w+r)`의 상한을 구할 수 있다. 상한이 음수이고 수치 여유보다 작을 때만 그룹을 제외한다.
- 날개 그룹은 기존 부품 AABB들의 합집합 AABB를 사용한다. 현재 회전각으로 변환된 입자가 반지름과 수치 여유만큼 확장된 AABB 밖이면 그룹을 제외한다.
- 수치 여유는 `1e-5*(1+length(p))` m이며, 충돌 반지름을 바꾸는 값이 아니라 후보를 더 보수적으로 남기는 값이다.
- 앞선 평면/부품이 위치를 보정하면 다음 그룹은 보정된 현재 위치로 다시 검사한다. 프레임 시작 위치로 계산한 고정 마스크를 재사용하지 않는다.
- 그룹 데이터는 초기화 시 GPU에서 실제 narrow phase의 동일한 형상 상수로 만든다. 추가 버퍼는 704바이트이며 매 단계 CPU 전송은 없다.
- 새로운 형상이나 다른 레벨은 이번 적용 범위가 아니다. MX301 이외 형상에서 옵션을 켜면 명시적으로 거부한다.

## 실행 옵션과 진단

`-GrainBoundaryCandidates`로 활성화한다. 이웃 목록 옵션과 독립적이며, 이번 대규모 비교는 양쪽 모두 `-GrainCandidateReuse -GrainCandidateCapacity=64 -GrainCandidateSkinRatio=0.5`를 사용한다. 기본 활성화는 작업 08의 조합 검증 후 결정한다. 저장 레벨과 목표 배속은 변경하지 않았다.

`timing.json` schema 5의 `boundary_candidates_enabled`로 적용 여부를 확인한다. 진단 API `inspect_boundaries()`는 시뮬레이션을 진행하지 않고 위치 보정·접촉 법선·벽 속도와 실제 방문한 평면/부품 수를 반환한다. 방문 카운터는 이 진단에서만 읽으며 일반 실행에 별도 atomic 계측을 추가하지 않는다.

## 재현

에디터 종료 후:

```powershell
python -B Scripts/run_additional_optimization05.py --run
python -B Scripts/run_additional_optimization05.py --run --modes boundary --seconds 30 --repeats 1 --label extended30
```

각 경로 12초 2회, 두 번째 반복은 역순으로 실행한다. 성능 실행에서 GPU 이벤트 계측은 끈다. 초기 입자 SHA, 수량·그룹·질량·유한값 및 마지막 저장 위치의 겹침/벽·날개 침투를 검사한다. 시간 간격과 물성은 기존 고정값이다.

## 검증 범위

소규모 시험은 3개 반지름, 6개 회전각, 일반/속도 탐침 반지름에서 무작위 내부·외부 점 및 평면/회전체 경계 점의 투영 결과·법선·벽 속도를 전체 계산과 비교한다. 회전 중 연속 실행도 fused/split 양쪽에서 비교한다.

대규모 실행의 마지막 위치 기록은 종료 시각보다 앞설 수 있다. 모든 중간 상태의 충돌을 전수 검사하거나 실제 분말 정확도를 인증하는 검증은 아니다. 현재 근사 접촉 모델을 그대로 유지하는 최적화이며, 최종 기계 형상/실제 물성 검증은 별도로 필요하다.

## 결과 (2026-10-27)

- 코어 회귀 시험 4/4 통과. 경계 단독 비교 571,860개에서 위치·법선·벽 속도의 차이 벡터 길이 < 1e-6 조건을 만족했다.
- 위 합성 표본에서 평면 방문은 76,057,380 → 21,014,395(72.4% 감소), 회전체 부품 방문은 9,721,620 → 1,291,162(86.7% 감소). 실제 5만 입자 장면의 방문 감소율이나 GPU 시간 감소율을 뜻하지 않는다.
- RTX 4060 Ti의 5만 입자, 12초 × 경로별 2회 중앙값: 안전 재사용만 **0.280515배속**, 경계 후보 축소 추가 **0.276845배속**. 소요시간은 **1.33% 증가**했다. 그룹 검사와 분기 비용을 포함하면 이번 장면에서 속도 이득이 확인되지 않았다.
- 따라서 이번 기능은 검증된 선택 경로로 보존하고 **기본 OFF**를 유지한다. 성능 개선으로 채택했다고 해석하면 안 된다. 작업 08에서도 이 측정 결과를 반영해 조합을 선택한다.
- 30초 연장 실행 평균 **0.255890배속**, 오류 0. 초기 SHA/수량/그룹/질량 및 최종 기록의 기하 검사 통과.
