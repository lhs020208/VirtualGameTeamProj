# 최적화 17 — 구간별 계산 계약과 보존적 인계

상태: q=1 구형 입자의 접촉 없는 경계 인계 기준판 구현·검증 완료. 대량 병렬 도메인 분해가 아니다.

`process.hpp`에 Supply/Storage/Transfer/Receiver/Mixing 순서의 5개 구간과 동기화된 SI 시계를 정의했다. 원료 ID는 한 구간만 소유한다. 인계 영수증에는 증가하는 sequence, from/to, 시각, ID 목록, 총질량/그룹별 질량, 운동량, 회전 포함 운동에너지, 외부 일이 담긴다. 위치·속도·회전·크기·밀도는 그대로 복사한다. 인계 자체의 외부 일은 0이며 가동 벽의 일은 각 구간 World에 유지된다. 체류 시간은 ID별 5개 누적 시간과 진입 시각으로 기록한다.

인계는 인접한 다음 단계로만 허용한다. 공급/수취 구간 전체에 활성 접촉 이력이 없고, 실제 현 상태와 인계 후 상태에도 접촉이 없어야 한다. 따라서 활성 접촉을 삭제하고 넘기지 않는다. 동일한 입자-입자 물성 계약을 요구하며 각 구간 벽 물성은 명시적으로 설정할 수 있다. 서로 다른 q/자동 분할·병합은 도입하지 않았다.

중복 ID, 소유권 위반, 재전송, 미래/과거 시각, 단계 건너뛰기, 접촉 중 인계, 구간 사이 근접 접촉을 거부한다. advance는 모든 구간을 임시 복사해 성공 후 교체한다. 구간 사이 탐색이 없다는 제한을 보완하기 위해 경계 간격과 엄격한 이동 상한을 검사한다. 실패는 기존 상태를 보존한다.

검증: 두 원료/서로 다른 밀도의 8개 구를 5구간에 인계 후 바닥 충돌까지 총 15,080스텝 진행. 단일 ClumpWorld와 직렬화 상태가 정확히 같았다. 그룹별 질량·운동에너지 및 체류 시간 합계를 확인했고 중복·시각·접촉·ID 오류를 거부했다. `process_tests` 및 전체 Core 회귀 통과.

제한: O(N²) 구간 경계 검사와 전 상태 복사를 쓰는 작은 접속 기준판이다. 공간상의 자동 입구 검출·기계 유량 예측·동시 접촉 영역 분할은 제공하지 않는다. 호출자가 실제 경계 도달 여부를 판단해 handoff를 요청해야 한다. 목표 159만 개 공정에 이 기준판을 그대로 연결하지 않는다. 더 큰 구간 접속은 halo/소유권/공통 접촉 이력 설계와 단일 해석기 비교가 추가로 필요하다.

검증 환경: 2026-10-22, Windows, RTX 4060 Ti 16GB, OpenCL FP64, MSVC Release /fp:strict, UE 5.8 Development Editor. 브랜치 PowderSimulationOptimization. 이번 요청에서 커밋/푸시는 하지 않았다.

Core 전체 41개 테스트 통과 후 변경된 GPU/인계 테스트를 재검증했다. Unreal 실제 RHI 활성화 환경의 16개 테스트 모두 통과했다. 재현은 프로젝트에서 `python Scripts/run_optimization14_18_validation.py --output Saved/Optimization14_18_new --full-target`. 이 스크립트는 Core/GPU 시험이며 Unreal 실행 결과는 별도다. 원본 로그와 코드 SHA-256은 `optimization14_18/`에 보관한다.
