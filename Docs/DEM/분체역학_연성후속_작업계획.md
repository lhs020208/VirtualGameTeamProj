# 연성 후속 작업 계획

2026-10-29. 이전 통합 최소 구현의 미달 항목을 이어서 진행한다. 원문 요구와 기존 5만 개 GPU 경로를 유지한다.

## 유한 작업과 완료 기준

1. **현상 연쇄 검사**: 퇴적/부착 입자를 공기 힘으로 이탈시키고 가스 통과·입자 포획 경계에 재부착시키는 연속 계산. 이탈 전·중·후 위치/속도/질량 장부, 재부착 뒤 유지 시간 기록. 압력 부호 반전과 추가 포트는 기존 시험 유지. 실패는 수치 설정/구현 원인을 분리하여 수정.
2. **같은 방정식 CPU 비용 감소**: 매핑용 입자 형상/관성 재계산과 압력 기울기 반복, 외력 ID 선형 검색 제거. 동일 입력 참조 경로 대비 궤적/보존/접촉 결과를 검사하고 64/512개 성능 비교. 시간간격·접촉 물리·입자 수는 변경하지 않음.
3. **대량 경로 선택**: 현재 GPU 접촉/공기 인터페이스, 셀 데이터·반작용 전달 비용과 명시적 가스 시간간격을 확인. CPU 부분 개선 / CPU 가스+GPU 입자 / 전부 GPU / 저마하 준정상 방식의 요구 충족·구현 위험을 비교하고 선택 기록.
4. **선택한 연성 경로 연결**: 공기 상태의 입자 힘 수집·동일 반작용 분배와 물성/공극률 가드. 정지·단일 입자·두 방향 운동량·닫힌/열린 질량 장부를 참조 CPU와 비교. 기존 GPU 기능 회귀 유지.
5. **규모/표시/성능 시험**: 동일 5만 개 입력과 실제 질량 기준으로 0.1배속, 벽 접촉·물성·공급/배출·재부유를 확인. 표시 FPS와 물리 속도를 별도 기록. 짧은 실행으로 장시간 보장하지 않음.
6. **요구 재대조**: 미구현/미검증/성능 미달을 재분류. 미달이면 다음 유한 계획을 기록해 이어간다. 실제 실험/실측 보정이 없으면 수치 검증만 통과했다고 명시한다.

## 경계

기계 모델 제작/상용 해석기 사용/입자 수 감축으로 성능 맞추기는 제외. 접촉과 보존을 없애거나 GPU 5만 개 기존 결과를 양방향 연성 결과로 대신 쓰지 않는다. 필터는 기체 통과·입자 포획의 단순 경계이며 실제 필터 저항/케이크 정량 보정과 구분한다.

## 추가 유한 작업 07~09

7. GPU 기본 상자에 접촉 시 인력(쌍/벽)을 선택적으로 연결한다. 인력 크기 4πγR_eff는 기존 접촉 인력과 같은 정의를 사용하되, 반발은 기존 PBD 강체 근사이므로 완전한 Hertz–DMT 모델이나 분리 에너지 보증이라고 부르지 않는다. 접촉 수치 허용오차는 반경의 1e-5 이내로 제한한다. 무응집 경로 동일성, 쌍 작용·반작용, 벽 하중 임계 이하 유지/이상 이탈, 공기 힘과의 합산 및 단계별 성능을 검사한다. 이 모델로 요구 현상이 재현되지 않으면 고정된 접촉 상태 모델을 더 보완하며 억지로 통과시키지 않는다.
8. 비구형 이물을 대량 경로에 연결할 수 있는 최소 강체 교환 방법을 기존 GPU 클럼프 구현과 비교한다. 시각 모양만 바꾸지 않고 실제 관성·접촉·반작용을 유지한다.
9. 공급/유출 장부와 연속 이송·역류를 대량 경로로 연결하고 전체 재대조한다. 0.1배속은 위 기능을 켠 상태에서 다시 측정한다.

인력 정의 참고: https://docs.lammps.org/pair_granular.html . 문서 참고만 하며 외부 해석기를 사용하지 않는다.

## 최신 완료 기준

기능 우선으로 변경: 0.1배속은 측정 목표이며 완료 차단 조건이 아니다. 07의 수치 회귀 후 08의 실제 비구형 관성/접촉, 09의 공급/배출 보존 및 연쇄 경계 검증을 우선한다. 성능 개선만을 위한 반복 벤치마크는 최소화한다. 미구현, 구현했으나 미검증, 물리 근사, 실험 미보정, 성능 미달을 각각 구분한다.

## 08~09 경로 검토 결과와 남은 구현

기존 `gpu_clump.cpp`는 이름과 달리 중심 구 하나인 강체만 허용하고 비구형을 거부한다. 기존 어댑터 옵션을 켜는 방법으로 비구형 GPU 구현을 완료할 수 없다.

- 기능을 사용하는 현재 경로: `L_CoupledPowder_Minimum`의 CPU 강체 연성. 비중첩 여러 구의 실제 관성 텐서·각운동량·회전, 각 구성 구의 접촉 및 공기 힘의 모멘트, 고유 ID 공급/배출을 계산한다. 소규모 전단 회전 및 양방향 반복 출구 검사를 추가했다.
- 대량 경로 확장에 필요한 구현: GPU상의 강체 상태(질량, 관성, 자세, 각운동량), 구성 구의 소유 ID와 위치/속도 갱신, 구 접촉 하중의 강체별 합산, 동일 반작용 가스 전달. 서로 독립된 구를 그려 비구형으로 표시하는 대체는 하지 않는다.
- 공급/배출: GPU 상태를 보존하는 활성 슬롯/ID 장부와 스폰 공간 검사, 출구 제거 시 질량·운동량 장부 및 이웃 캐시 무효화가 필요하다. 재생성으로 전체 입자 속도나 회전 상태를 초기화하는 방식은 사용하지 않는다.
- 08~09의 GPU 이식은 아직 미구현이다. CPU 기능과 GPU 기능을 합쳐 단일 대량 통합이 완료되었다고 주장하지 않는다. 최신 기능 우선 지시에 따라 이 구현을 이후 성능 반복 튜닝보다 우선한다.

## 기능 우선 통합 확인 작업 A~D

A. 기존 CPU 강체 연성 해석기를 사용하는 재현 가능한 기본형 실험 프리셋을 공유 코드로 만든다. 다종 구/비구형, 응집, 양방향 공기, 순차 공급/출구 장부를 함께 켠 이송과 다입자 재부유/포획 실험을 분리한다. 소규모 테스트 입자 수는 원래 GPU 5만 개 설정의 변경이 아니다.
B. 동일 프리셋을 CLI에서 실행하여 물리 단계·보존·비구형 강체·필터 정상 상태에서 입자 소실 없음·공급 뒤 잔류 운동을 검증한다. 압력 없음/차단/무부착 대조를 둔다. 실패는 모델 범위와 수치 문제를 구분한다.
C. 사용자가 여는 기존 CPU 테스트 액터에 같은 프리셋 선택을 연결하고, 경계·입자·단계·질량 장부를 실시간 표시/저장한다. 시뮬레이션 위치를 강제로 변경하거나 녹화로 대신하지 않는다. 기존 수동 모드와 모든 GPU 기본값 보존.
D. Unreal에서 동일 프리셋의 단계까지 실제 실행하고 CLI 결과와 대조한다. 요구 대응표를 기능 구현/사용자 실행 통합/수치 검증/실험 미검증으로 판정한다. 이 CPU 통합으로 최소 기능이 충족되는 항목에는 GPU 이식을 추가 필수 조건으로 강요하지 않는다. 대량 성능과 GPU 미지원은 별도 한계로 남긴다.

## A~D 실행 상태

A 공유 프리셋 6종과 원료별 질량 장부 구현, B CLI 검사 및 겹침 제한 보완, C Unreal 프리셋/개구/UI/저장 연결 완료. D 정상 이송·완전/부분 차단·무유동·부착/무부착 필터의 6가지 사용자 실행 및 종류별 독립 질량 감사 통과. A~D의 소규모 CPU 최소 기능 통합 확인 완료. 예비 필터 검증의 큰 겹침, 파일 잠금으로 인한 이전 실행 파일 사용, 모든 형상의 동일 포획을 강제한 판정 문제는 최종 검증 보고서에 남긴다. 물리 강성/감쇠를 명시한 최신 실행 결과만 최종 근거로 사용한다.
