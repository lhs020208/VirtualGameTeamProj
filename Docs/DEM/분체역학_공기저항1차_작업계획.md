# 분체역학 공기저항 1차 확장 — 작업 01~07

진행 상태: **01~07 완료**. 상세 결과: [air_extension/README.md](air_extension/README.md).

2026-10-28. 작업 하나는 프롬프트 1회 분량의 구현·검증·문제 수정이다. 이번 연속 실행은 아래 7개로 종료한다.

## 범위와 기존 상태

- 현재 브랜치 PowderSimulationOptimization, 기존 OpenCL 계산 유지. CUDA 전환 없음.
- 현재 50,000개 가상 구형 입자, 기존 접촉/회전/후처리/시간간격/저장 레벨 유지.
- 기존 미추적 simple_visuals_rate 보고서와 검증 스크립트 보존.
- 이번 구현은 균일하게 주어진 공기 속도에 대한 단방향 구형 항력과 부력이다. 유동을 푸는 CFD, 고농도 차폐/압력손실/진공수송 예측이 아니다.
- source_diameter는 메타데이터이며 항력 지름으로 몰래 사용하지 않는다. 실제 구의 질량/충돌반경/항력반경을 일치시킨다. 서로 다른 실제 미세입도 축약은 지원하지 않으며 활성화 시 거부한다.
- 기본 비활성. 기존 장면을 공기 이송으로 오인하지 않도록 에디터와 출력에 모델/한계를 표시한다.

## 확정 작업과 완료 기준

| 번호 | 작업 | 완료·검증 기준 |
|---|---|---|
| 01 | 적용 범위와 SI 설정 계약 | 밀도·점도·속도·직접 구형 물성 검증, 잘못된 축약 입력 거부, 기본 OFF |
| 02 | CPU 기준 항력 적분 | Schiller–Naumann/고 Reynolds 수 상수 Cd 근사, 반암시적 감쇠, 부력; 정지·방향·Stokes 해·수렴 검증 |
| 03 | OpenCL 예측 단계 통합 | 추가 전송/dispatch 없이 기존 predict에 융합; OFF 경로 보존; CPU/GPU 비교 |
| 04 | 언리얼 에디터 연결 | SI 공기 설정, Reset 적용, 검증 메시지, 계산 결과에 공기 설정 기록; 빌드 |
| 05 | 물리·회귀 검증 | GPU 항력 방향/감쇠/부력/시간간격 수렴, 기존 granular 테스트 통과 |
| 06 | 현재 5만 개 비용 비교 | 같은 초기 상태·dt·접촉·회전으로 OFF/ON 비교, 자체 프로세스 온도/전력 감시, 실제 측정과 추정 구분 |
| 07 | 검토 및 사용·제한 문서 | 작업별 결과·실행 명령·변경 파일·실패/미실행 항목 기록; 기존 저장 장면 유지 확인 |

## 후속 단계 (이번 7개에 포함하지 않음)

실제 입도/축약 모델과 보정 실험 → 입도분포·응집/벽부착 → 보존적인 공기 격자 전달 → 유한 공극률 3D 양방향 유동 → 이송/퇴적/재비산 검증 순서다. 기존 2D 희박 유동 시험을 현재 GPU 고농도 장면의 완성된 CFD로 간주하지 않는다. 미측정 실제 재료의 정확도를 주장하지 않는다.

## 성능과 안전

현재 30FPS 전면 시험의 0.2배속은 과거 실측이며 신규 공기 기능의 보장이 아니다. 이번 계산 전용 비교는 화면 포함 최대 배속으로 대체해 표현하지 않는다. 자체 시험만 종료할 수 있으며, GPU 온도 75°C 또는 전력 155W 이상/계측 실패 시 중단한다. 사용자 에디터의 미저장 작업을 버리지 않는다.
