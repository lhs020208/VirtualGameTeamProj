# 대량 연성 경로 선택

CPU 512개 프로파일에서 입자별 연성/DEM/매핑이 대부분을 차지하고 가스 셀 계산은 약 3%였다. 같은 기울기 중복 계산과 외력 ID 탐색 개선 뒤 512개는 0.002856→0.003214배속(짧은 단회 측정)으로, 목표까지의 차이는 여전히 크다.

| 후보 | 장점 | 제한 | 판단 |
|---|---|---|---|
| CPU 참조 경로만 최적화 | 기존 접촉/비구형/응집 유지 | 5만 개에서 목표에 못 미칠 가능성 큼, 작은 음향 시간간격 | 현상 검증 기준용으로 유지 |
| 기존 FP64 GPU force DEM | 힘 기반 비교가 쉬움 | 현재 건조·비응집 구만 지원, 작은 시간간격과 FP64 비용 | 바로 생산 경로로 전환하지 않음 |
| 기존 GranularGPU + 격자 공기 교환 | 5만 개 기존 검증 경로 유지, 위치/속도 전체 다운로드 불필요 | 현재 PBD 근사 접촉, 응집/비구형 기능은 아직 미연결 | 우선 가스 격자 수집·반작용 장부 인터페이스를 선택 |
| 전부 GPU 가스 PDE | 전송 적음 | 음향 시간간격으로 많은 커널 호출, 구현/검증 범위 큼 | 교환 인터페이스 검증 뒤 비교 |
| 저마하/준정상 가스 | 큰 시간간격 가능 | 압력 반전 등 비정상 현상 검증 없이 바꾸면 요구 축소 | 당장 대체하지 않음 |

첫 연결은 각 GPU 입자의 실제 적분 공기 충격량을 같은 CIC 가중치로 격자에 반대로 누적한다. 물성·공극률·영역 이탈·드래그 안정성 가드와 원자 누적 오차 검사를 포함한다. 격자 교환 구현은 가스 PDE 전체 연성의 완료와 별개이며, CPU 가스 또는 후속 GPU 가스에 연결하기 위한 단계다. 기존 air OFF 경로는 보존한다. 응집과 비구형을 조용히 제거한 뒤 전체 목표를 달성했다고 선언하지 않는다.
