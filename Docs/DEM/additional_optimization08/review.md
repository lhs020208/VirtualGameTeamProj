# 작업 08 개발 점검

범위: 이번 추가 최적화01~07의 후보 목록/재사용/경계 그룹/전송/인수 캐시/목록 인덱스와 UE 작업 스레드·표시 경로를 읽고, 현재 입자 상태의10회 실행 결과를 검토했다. 다른 입자 상태 또는 기존 소규모 합성 시험은 사용자 요청에 따라 이번에 새로 실행하지 않았다.

## 발견 및 수정

처리 지연 시간이 무한히 누적되는 배속 제어 문제를 수정했다. 목표 속도가 처리능력보다 높을 때 생긴 과거 요청이 이후 낮은 목표 속도에서도 계속 실행되는 원인이었다. 누적값은2배치(현재0.024초) 이내로 제한하고 Pause에서 초기화한다. 이는 물리 상태를 미래로 건너뛰는 처리가 아니다. 현재 상태의 최종60초 시험2회는 이 수정과 기본값 적용 빌드에서 통과했다. 배속 변경 자체의 별도 실시간 조작 시험은 수행하지 않았다.

## 확인한 사항

- 후보 생성/접촉/감사/진단이 동일한 전치 인덱스를 사용하고 각 입자 후보 순서를 유지한다.
- 초과 목록은 잘라서 사용하지 않고 전체 격자 fallback 및 다음 반복 재구축을 사용한다.
- 변위 검사에는 접촉과 벽 위치 보정이 포함되며 Reset이 캐시를 무효화한다.
- 인수 캐시는 값 변경 시 재설정한다. 임시 진단 버퍼 핸들은 매 진단에서 캐시를 비운다.
- 비동기 전송은 한 건만 유지하고 완료 전 메모리를 보존한다. 위치와 같은 시점의 각도/시각을 게시한다.
- 저장 레벨/초기 입자/물성/시간 간격은 보호 해시와 일치한다.

점검한 범위에서 추가로 확정한 구현 결함은 없었다. 결함이 전혀 없음을 보증하는 결론은 아니다. 새 기본값은 검증한 MX301 생성기50000개·반지름/dt/반복수/마찰 조건에 제한한다. 비동기 표시와 경계 후보 축소는 기본 적용하지 않는다.

## 남은 한계

근사 위치 기반 구형 입자 모델이며 실제 분체 접촉력/물성 정확도 인증은 없다. 중간 기하 검사는 약2초 간격이라 모든 순간의 겹침을 포착하지 않는다. 벽시계 속도 하한은 시스템 부하에 따라 달라진다. 이 결과를 다른 입자 수·입도·충전량·최종 기계 형상에 확장해서는 안 된다.
