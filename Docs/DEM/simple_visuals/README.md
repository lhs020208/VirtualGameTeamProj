2026-10-28. 현재 `/Game/DEM/Tests/L_MX301_BinaryMaterials`에 적용.

- 공통 `/Game/M_BulkFlow`를 불투명 Unlit 재질로 변경. 입자의 빨강/파랑 Tint는 유지.
- 실제 조명·금속 반사 대신 고정 방향과 표면 법선의 내적으로 약한 명암만 표현한다. 텍스처·그림자 샘플링 없음. 입체 형태를 구분하기 위한 표시용 명암이며 물리 모델이 아니다.
- `Powder_SimpleDisplay` 무한 범위 PostProcessVolume: GI/반사/AO/블룸/모션 블러 비활성, 수동 고정 노출.
- 현재 레벨의 메시 및 조명 그림자 비활성. 공통 재질은 이를 참조하는 다른 시뮬레이션 레벨에도 반영되지만 후처리 설정은 이 레벨에 한정된다.
- 메시·충돌 형상·입자 물성 에셋은 수정하지 않았다. 입자 50,000개, dt 0.000375, 접촉 16회, RPM 30, 목표 0.1배속, 회전·구름 저항 설정 유지.

`Scripts/simplify_powder_visuals.py`를 현재 테스트 레벨의 에디터 Python으로 실행하면 재적용할 수 있다. 스크립트는 기존 공통 재질 그래프를 재구성한다. 원래 재질은 Git 이력에 보존돼 있다.

검증: 보호 대상 물성·형상 에셋 SHA 및 solver 설정 전후 동일 확인(`verification.json`). 열려 있는 에디터에서 재생해 5만 입자와 0.1배속 진행 및 재질 표시를 확인하고 정지했다. 물리 계산 코드는 변경하지 않았다. 이번 표시 변경만의 성능 배수는 별도 측정하지 않았다.
