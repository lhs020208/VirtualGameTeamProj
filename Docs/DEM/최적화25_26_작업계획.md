# 최적화 25~26 작업 계획

2026-10-22. 기존 24 결과에서 확인한 정렬 실행 비용의 후속 개선. 작업 1개 = 프롬프트 1개와 문제 수정 범위.

25. 셀 변경 검사 결과 4바이트를 확인하여 변화가 없으면 정렬·해시 재생성 커널 제출 자체를 생략한다. 기존 비동기 조건부 실행 경로를 비교 스위치로 유지한다. 호스트 동기화 비용까지 실측한다.
26. 재정렬 시 128개 키의 초기 정렬과 마지막 병합 단계를 GPU 로컬 메모리에서 묶는다. 기존 전역 bitonic 기준과 동일 키/입자 순서를 유지한다. 패딩 경계·동일 셀·이동·실패 복구·전체 총량을 검증한다.

두 작업은 dt/입자 수/물성/q를 변경하지 않는다. 24 실행 파일을 보존하고 동일 전체 총량 측정을 재실행한다. 작은 장면이나 변화가 잦은 장면의 회귀도 보고한다. 0.1배속·장기 공정 인수는 별도이며 실측 근거 없이 달성으로 기록하지 않는다.
