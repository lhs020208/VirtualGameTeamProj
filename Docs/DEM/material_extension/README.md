# 두 분말 물성 확장 01~07

작성일: 2026-10-28. 한 작업은 한 프롬프트에서 구현·관련 검증·문제 수정을 포함한다.
현재 결과는 자체 위치 기반 GPU 모델의 확장이다. 실측 분말 DEM 또는 의약품 제조 공정의 검증 완료를 뜻하지 않는다.

## 작업과 상태

| 작업 | 범위 | 상태 |
|---|---|---|
| 01 | 실제 입도 메타데이터, 계산 반지름, 진밀도, 계산·대표 질량 관계 | 구현. 계산 질량=진밀도×계산 구 체적=대표 질량. 독립 질량 배수 금지. 실제 입도 0은 미확인. |
| 02 | 두 크기·질량의 GPU 접촉 및 초기 배치 검사 | 구현. 질량 역수 비율에 따른 보정, 최대 반지름의 보수적 후보 탐색, 접촉 감사. |
| 03 | A–A/B–B/A–B 및 성분별 벽 마찰 | 구현. 교차 마찰은 명시적으로 입력, 자동 혼합 법칙으로 위장하지 않음. |

## 사용

레벨 `/Game/DEM/Tests/L_MX301_BinaryMaterials`를 열어 Play한다.
이후 0.1배속 재검증에서 `/Game/L_MX301_Test`와 이 시험 레벨 모두 목표 속도를 0.1로 저장했다. 결과는 `../rate01_recheck/summary.json`을 참조한다.
새 시험은 0.1 목표 속도, 50,000개, 약 40.838kg, 빨강 약 20% / 파랑 약 80% 질량이다.
이 배합은 두 성분을 검증하기 위한 가상 배합이며 Relenza의 제조 공정이나 실제 물성 구현이 아니다.

- 빨강 A: 반지름 6.3647064mm, 진밀도 가정 900kg/m³, 입자 마찰 0.3, 벽 마찰 0.25.
- 파랑 B: 반지름 5mm, 진밀도 가정 1500kg/m³, 입자 마찰 0.5, 벽 마찰 0.45.
- 교차 마찰 0.35, 구름 저항 0.02: 모두 시험 가정값.
- 두 Data Asset은 `/Game/DEM/Settings/DA_VirtualPowder_A`, `DA_VirtualPowder_B`.
- `Binary Materials`, `Enable Particle Rotation`, `Material Optimizations`는 새 시험에서만 켠다.
- 데이터 에셋의 원료 이름·출처·실제 직경은 기록용이다. 실제 직경이 계산 반지름을 자동 변경하지 않는다.
- 생성 개수는 `ParticleCountForMass` 또는 core `plan_binary_charge`로 산출한다. 생성 위치는 별도 배치 검증이 필요하다. 연속 방출은 이번 범위 밖이다.

## 수치 모델

두 성분 각각 하나의 계산 반지름·진밀도를 사용한다. 성분 내부 PSD 표본 추출/임의 N종 성분은 아직 지원하지 않는다.
접촉 탐색은 최대 반지름으로 구성하고 실제 접촉은 두 반지름의 합으로 판정한다.
회전 사용 시 구 접촉점의 상대 접선 변위에 각변위를 포함하고 고체 구 관성 I=2mr²/5로 접선 보정의 토크를 적용한다.
정지 벽에서 미끄러짐→구름 전환 v=5v0/7, ω=v/r을 시험한다. 구름 저항은 에너지를 줄이는 근사 저항이다.
기존 모드는 이전의 동일 입자 계산을 유지한다. 실제 힘/토크의 계측값이나 Hertz/JKR 보정을 제공하지 않는다.
초기 각속도 입력과 구의 표면 방향 렌더링은 미지원이다. 초기 회전은 0이며 접촉에서 생성된 회전을 계산한다.

## 자료가 없어 완료할 수 없는 부분

공개된 제품 조성은 원료의 제조 등급과 마찰·응집 계수를 제공하지 않는다.
`SourceAssets/Granular/Pharmaceutical/relenza_reference.json`의 미확인 값은 null로 유지한다.
유당 공급사 특정 등급을 제품에 실제 사용된 등급으로 가정하지 않는다. 벌크/탭 밀도를 진밀도로 사용하지 않는다.
흡입 미세 분말의 부착 혼합을 현 dry 모델로 예측한다고 주장하지 않는다.

응집을 진행하려면 접촉 후 부착·분리 법칙, 표면 에너지 또는 보정 가능한 응집 계수, 대표 입자 확대에 따른 보정 검증이 필요하다.
기존 `representative.hpp`도 확대 입자의 응집/구름 법칙을 검증된 것으로 허용하지 않는다. 이번 구현은 그 계약을 수정하거나 우회하여 실제 분말 유사성을 주장하지 않는다.

## 재현

- 최초 에셋 생성: `Scripts/configure_binary_material_test.py` (기존 에셋 덮어쓰기 거부).
- GPU 시험: CMake `granular_material_tests`와 기존 granular 회귀 6개.
- UE 시험: `Powder.EmitterIntegration.GPUBridge`에 두 물성 연결 검증 추가.
- 기하·질량·혼합 독립 감사: `python Scripts/audit_binary_material.py <실행 폴더>`.
- 실행별 `material_model.json`에 계산 물성/회전 설정 기록. `trace.csv` 혼합 지수는 질량 기준.
- 성능은 같은 장치·입자 상태·형상·시간 간격에 한정하며 다른 입도/약물에 이전하지 않는다.
