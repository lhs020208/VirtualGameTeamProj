# 실시간 1배속 목표 시험 (2026-10-22)

요청: 실제 1초당 시뮬레이션 1초 진행을 시험한다.

적용: PowderClumpTest의 기본 Realtime Pacing=true, Target Simulation Rate=1.0, Compute Budget Ms=50. 기존 200 steps/frame 제한은 실시간 목표 모드에서는 사용하지 않는다. 고정 물리 간격 2e-6 s와 충돌 모델은 변경하지 않았다. 목표는 단조 벽시계로 누적하며, 물리 단계로 실제 계산한 시간만 t에 표시한다. 일시정지/재개는 대기 시간을 계산 부채로 추가하지 않는다. HUD는 목표/실제 배속 및 지연을 표시한다. 실제 배속은 약 0.5초 구간마다 갱신된다. 예산은 단계 사이에 검사하므로 단일 단계 비용만큼 초과할 수 있다.

결과: Editor Development 빌드 성공. ClumpBridge, MixingBridge, PaddleBridge, RealtimePacing 4/4 통과. 32입자 혼합 조건의 NullRHI 측정에서 실제 1.1041445 s 동안 물리 0.01747 s, 약 0.0158222배속. 따라서 **1배속 달성은 미완료**이며 목표 설정과 계산 제한 확대만 적용된 상태다. 렌더링을 포함한 화면 실행은 별도 비용이 있다. 현재 간격에서는 500,000 단계/실제 초가 필요하지만 측정 처리량은 약 7,911 단계/초다. 약 63배의 추가 처리량 개선이 필요하다. 숫자만 1배속으로 올리거나 물리 시간을 건너뛰지 않았다.

테스트는 실제 시간 증가, 고정 계산 간격 유지, 실시간 초과 진행 방지, 배속 표시, 정지·재개·수동 한 단계, 초기화 및 수동 프레임 단계 모드를 확인했다. 기존 물리 적분과 접촉 코드는 그대로다. 후속 최적화는 가동 메시 조회 및 반복 검증 비용 프로파일링, 계산 스레드 분리 등을 측정하여 진행해야 한다. 시간 간격 확대는 별도 안정성/수렴 검증이 필요하다.
