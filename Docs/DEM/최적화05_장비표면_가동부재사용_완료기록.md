# 최적화 05 완료 — 장비 표면과 가동부 재사용

2026-10-22 / PowderSimulationOptimization

정확히 인증된 축 정렬 상자의 면 내부는 직접 접촉 계산하며, 모서리·이음매·비정형 메시·관과 판은 기존 삼각형/BVH 경로를 유지한다. 물체 경계로 먼 입자를 제외하고, 가동부의 현재/다음 자세를 단계당 한 번씩 준비한다. 관통 검사와 물리 시간 간격·재료 모델은 변경하지 않았다.

## 검증

- Core 전체 25/25, 최종 계측 변경 후 관련 6/6, Unreal 13/13 통과. Editor 빌드 성공.
- 보관한 최적화 04 실행 파일과 3회 교차 반복 및 프로파일 실행 비교. 수치 359,460개 비교, 최대 절대 차이 2.36356e-15 (여러 단위가 섞인 집계). 사전 계약 abs<=1e-12+1e-9*maxabs 이내이며 이벤트·접촉 수·종료 상태 동일.
- 동일 실행 경로의 반복/프로파일 결과 및 현행 legacy 경로와 보관 실행 파일 결과는 동일.
- 5 RPM 32입자 혼합: 전체 중앙값 1.784배, 정적/가동 메시 벽 힘 계산 합계 2.028배. 벽 수치는 후단 관통 검사 비용을 포함하지 않는다.
- 256개 1mm 시험: 전체 1.068배. 메시 없는 자유낙하/배출은 각각 0.952/0.959배로 개선 확인 안 됨.
- 면 직접 계산, 모서리/이음매, 회전, 열린 관, 얇은 벽, 양방향 RPM, 접촉 모델/토크/일, 실패 원자성 검증.

## 제한

300 rigid bodies / 1024 pebbles 한도 유지. mm·kg 규모와 목표 0.1배속은 아직 미달이다. Unreal 기본 Cube의 48삼각형 메시 등 인증 형식에 맞지 않는 형상은 BVH 경로를 사용한다. 소규모 시험의 속도 향상을 대량 장비 성능으로 해석하지 않는다.
