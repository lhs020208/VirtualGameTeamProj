## 모델과 가정

- SI 단위, 균질한 구의 등방성 관성. 세계 좌표계 토크로 각속도를 갱신하고 쿼터니언 지수 회전·정규화로 자세 갱신.
- 접촉점 속도 = 중심 속도 + 각속도 × 접촉점 팔 길이.
- 접선 변위를 시간에 따라 누적하여 `Ft=-kt*ξ-ct*vt`를 계산하고 `|Ft|≤μFn`으로 제한.
- 한 개의 μ로 정지 탄성 영역과 미끄럼 한계를 표현한다. 별도의 정마찰·동마찰 계수는 아직 없다.
- 제한이 발생하면 이력을 제한된 힘과 일치하도록 보정한다. 마찰 스프링은 저장 에너지를 반환할 수 있으므로 매 순간 힘이 속도 반대라는 조건으로 검증하지 않는다.
- 법선 변화에 따라 최단 회전으로 이력을 이동시키고 법선축 평균 스핀도 반영한다. 거의 반대 방향으로 뒤집힌 법선은 오류로 거부한다.
- 접촉 종료 시 이력을 초기화한다. 활성 이력의 입자 ID·쌍 순서 변경을 거부한다.
- 두 구는 공통 접촉점을 사용하여 힘·토크의 각운동량 수지를 맞춘다. 평면의 팔 길이도 실제 평면까지의 거리다. 큰 겹침으로 중심을 넘어가는 접촉은 거부한다.
- 시간 간격 제한은 법선 질량뿐 아니라 회전 관성을 포함한 접선 유효 질량·강성·감쇠도 고려한다.
- 계산 실패 시 상태·힘·접촉 이력을 부분 갱신하지 않는다.

접선 이력·쿨롱 제한·접촉 좌표계 회전의 개념 참고: https://docs.lammps.org/pair_granular.html . 공개 설명을 참고한 자체 구현이며 외부 해석기나 해당 코드의 실행을 사용하지 않는다.

## 사전 허용 기준

검증 코드 작성 시 지정한 기준:

- 일정 각속도 자세와 각속도 기준값: 1e-10/1e-12.
- 수평면 미끄럼→구름 최종 속도: 이상적 구 기준값 대비 0.003m/s 이내.
- 마찰 경사면 구름 속도: 이상적 구 기준값 대비 0.004m/s 이내.
- 마찰 없는 경사면 가속도 결과: 1e-9m/s 이내.
- 두 구의 선운동량 성분 오차: 1e-10kg·m/s, 전체 각운동량 오차: 1e-9kg·m²/s 이내.
- 이력 방향·크기, 쿨롱 한계, 접촉 종료 초기화, 오류 시 상태 보존을 별도 검사.

## 검증 결과

기본 수치 시험은 질량 1kg, 반지름 0.5m, kn=10000N/m, cn=40Ns/m, kt=2500N/m, ct=10Ns/m, μ=0.3을 사용했다. 실제 분말 물성이 아니다.

| 시험 | 결과 |
|---|---|
| 자유 회전 1초, 각속도 2rad/s | 쿼터니언 이론값·각속도 허용 오차 통과 |
| 토크/관성 | 각가속도 기준값 통과 |
| 쿨롱 제한·낮은 미끄럼의 탄성 영역 | 통과 |
| 법선 90도 변경 | 접선 이력의 접평면 이동과 크기 보존 통과 |
| 접촉 종료 | 평면·두 구 모두 이력 제거 확인 |
| 수평면 초기 속도 1m/s에서 구름 전환 | 최종 속도 0.713483m/s, 각속도 1.42977rad/s |
| 같은 시험의 최종 운동에너지 | 약 0.356742J, 초기 0.5J보다 감소 |
| 마찰 없는 경사면 | g sin(θ) 기준 통과 |
| θ=0.2rad 경사면, 0.5초 구름 | 속도 0.695287m/s, 이상적 기준 0.696052m/s |
| 비스듬한 두 구 충돌 | 회전 발생, 운동에너지 감소, 선운동량 보존 통과 |
| 같은 충돌의 각운동량 최대 오차 | 약 2.51354e-13kg·m²/s |

구름 속도의 작은 차이는 유한 겹침으로 접촉 팔 길이가 이상적 반지름과 다른 효과 및 이산화의 영향을 포함한다. 전체 오차를 한 원인으로 단정하지 않는다.

Release 빌드와 기존 C++ 세 시험, 신규 rotation_friction 시험이 통과했다. 추가한 경사면 마찰·충돌 종료 검사는 재빌드 후 신규 실행 프로그램으로 다시 통과했다. 기존 motion_tests.py, cli_tests.py, contact_cli_tests.py도 모두 통과했다.

빌드·실행 검증에서 실패는 없었다. 검증 범위를 확대하여 마찰이 있는 경사면과 두 구 분리 후 이력 제거까지 확인했다.
