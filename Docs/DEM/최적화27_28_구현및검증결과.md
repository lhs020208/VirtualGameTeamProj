# 최적화 27~28 결과 — 축약 공정 흐름 시제품

2026-10-22 · PowderSimulationOptimization

27 목표/검증 계약 고정 및 28 최소 성능 시제품 구현 완료. 기존 상세 DEM 코드를 대체하거나 삭제하지 않았다. 새 코어는 자체 구현한 제한된 1차원 보존 수송 모델이다. 실제 진공 이송·칭량 제어·공간 혼합의 구현/검증은 후속 작업이다.

## 27: 계약

최종 목표 30kg 기본, 10/50kg 추가, 전 공정 0.1배속. 표시 분말의 이동은 보여야 하며 지원 통로 벽/닫힌 밸브를 넘지 않아야 한다. 항력은 상대속도를 감소시키는 방향이고 중력/관성에 의한 역류는 허용한다. 화면 입자 수와 원료 질량 계산은 독립이다.

문서: 최적화27_28_계획및검증계약.md. 기계 판독 조건: Physics/PowderCore/fixtures/optimization27_contract.json. 실제 재료/장비 보정 전이므로 현실 정확도와 전체 공정 인수는 미완료다.

## 28: 구현 범위

- 5m 직선 통로, 0.4m × 0.4m 단면, 기본 128셀, 원료 3종, 기본 총량 30kg. 처음 20% 구간에 분말을 배치한다.
- 셀별 원료 질량을 보존적으로 이동한다. 셀 용량과 닫힌 밸브가 전달량을 제한하고, 닫힌 양 끝에서는 질량이 빠져나가지 않는다.
- 통로 방향 중력과 선형 항력으로 기본 운반 속도를 계산한다. 항력 속도식은 해석적 완화식, 질량 수송은 1차 상류 유한체적 방식이다. CFL 기준으로 내부 시간 간격을 분할한다.
- 공급/칭량/이송/수취/혼합 구간 표시는 연결 골격이다. 아직 같은 통로의 구간 이름이며 실제 장비들의 서로 다른 물리 모델이 아니다.
- 1,500개 흐름 표식을 화면에 표시한다. 표식은 질량을 소유하지 않으며 셀 전달량에서 얻은 속도를 따른다. 중력에 따라 바닥으로 가라앉고, 통로와 밸브 경계에서 위치를 제한한다.
- 표시 구의 직경은 가시성을 위한 3cm이며 실제 분말 입경이 아니다. 표식끼리 겹칠 수 있고, 실제 충돌/접촉/층 높이를 계산하지 않는다. 원료별 색상 구분은 표시를 위한 것이며 공간 조성의 정량 판독은 셀 데이터로 한다.
- 마찰·응집·자연 아치 막힘·입도 분리·압력망·공기 질량수지·혼합 법칙·임의 메시 접촉은 미구현. 직선 통로 가정을 벗어난 장비에 붙여서 물리적으로 올바르다고 주장하지 않는다.

## 성능·검증

코어 시험: 10/30/50kg × 64/128/512셀 × 3회 = 27조건. 각 물리시간 60초, 기본 dt=0.005초, 매 단계 1500개 표식 위치 갱신 포함. 10초에 밸브 개방, 40초에 공기 속도를 반전하는 입력을 사용했다.

- 최저 계산 배속: **33.461배**. 중앙값 257.933배.
- 원료별 최대 질량 오차: 2.842e-14 kg.
- 코어 전체 46/46 통과. 최종 표시 경계 및 시간 간격 축소 시험도 통과.
- Unreal 전체 Powder.DEM 17/17 통과. 시제품의 1,500개 인스턴스·닫힌 밸브·개방 후 이동·pause/reset 검증 포함.
- 실제 게임 화면 8초 짧은 실행: 물리시간 0.800000초, 측정 배속 0.097525배. 이 값은 정밀한 장기 인수 결과가 아니다. 프레임/물리 단계 양자화와 시작 지연이 포함될 수 있다.

코어 속도는 렌더·센서·전체 공정·저장을 포함하지 않는다. 상세 DEM과 같은 정확도의 가속 배율이 아니다. 28의 계산량이 목표 범위에 들어갈 여지를 확인한 것으로만 판단한다. 최종 성능/정확도 인수는 36에서 수행한다.

표시 독립성(표식 0개/2500개 동일 질량 배열), 질량 비음수/용량 상한, 항력 해석해, 무외력 정지, 시간 간격 반감 시 질량 중심 변화 2cm 이내, 닫힌 밸브의 질량/표식 통과 차단을 확인했다. 이것은 실물 수송 정확도나 공간 해상도 수렴 인증은 아니다.

## 사용법

1. `/Game/L_BulkPrototype` 레벨에서 Play. 기본 30kg, 목표 0.1배속으로 분말 흐름이 보인다.
2. 기존 카메라 컨트롤러를 사용한다. 우클릭과 이동 키로 관찰 위치를 바꿀 수 있다.
3. PIE에서 Eject 후 `BulkPrototype_30kg_0p1x` 액터의 Bulk 항목에서 `Valve Open`, `Air Speed`, `Running`, `Target Rate`를 변경한다. 이는 현재 실행 인스턴스에 적용한다.
4. `Total Kg`/`Display Count`/액터 회전을 바꾼 뒤에는 `Reset Simulation`을 실행한다. 무효 입력은 Error에 표시하며 실행을 멈춘다.
5. 기본 시작 맵과 기존 레벨은 변경하지 않았다. 원래 상세 DEM 시험도 남아 있다.
