# 최적화 03 — 공간 격자 접촉 후보·안전 검사 완료 기록

- 날짜: 2026-10-22
- 브랜치: `PowderSimulationOptimization`
- 결과: 구현·정확도 검증 완료. 규모별 성능 개선 및 소규모 회귀를 함께 기록. 대량 분말 0.1배속 목표는 미달성.

## 구현

- `ClumpWorld`의 힘 계산 전과 적분 후 겹침 검사에 각각 새 공간 격자를 구성한다. 이전 위치의 후보를 그대로 재사용하지 않으므로 새로 접근한 입자도 사후 검사에 들어간다.
- 셀 폭은 최대 구성 구 직경의 1.01배다. 다분산 구의 접촉 거리 상한보다 크므로 인접 27셀 범위가 보수적 후보를 포함한다. 동일 몸체 내부 구는 후보에서 제외한다.
- 각 셀과 서로 다른 이웃 셀 쌍은 한 번만 방문한다. 후보를 노드 인덱스 순서로 정렬해 기존 힘 누적 순서를 유지한다.
- 셀 전체 부피가 `16 × 구성 구 수 + 64` 이내이면 연속 배열과 연결 인덱스로 직접 조회한다. 넓게 흩어진 장면은 해시 격자를 사용해 빈 영역 메모리 할당을 피한다.
- 셀 좌표가 ±1e12를 벗어나거나 폭/좌표 환산이 유한하지 않으면 전수 후보로 안전하게 돌아간다. 기존 지원 좌표를 새 격자 때문에 거절하지 않는다.
- 상태 커밋 시 몸체마다 선형 ID 검색을 반복하던 코드를 ID→인덱스 표 조회로 바꿨다. 재료 표의 종류별 검증 및 변경 감지는 최적화 02 캐시 구현을 유지한다.
- `use_spatial_search=true`가 Unreal 포함 기본 경로다. false는 전수 후보 비교용이다. 시간 간격·힘·회전·마찰·벽 검사·겹침 한계·300몸체/1024구 상한은 바꾸지 않았다.

## 정확도 검증

- 사전 기준: 전수 검사 대비 접촉 집합 동일, 동일 입력의 물리/상태/배출 이벤트 CSV 바이트 일치. 이번 변경에는 수치 오차 허용 확대가 없다.
- 최초 코어 전체 23개 통과. 격자 구현 보완 후 영향을 받는 강체·정적 메시·가동 벽·혼합·최적화 8개 테스트를 다시 실행해 모두 통과.
- 새 `optimization_spatial`: 고정 시드 100개 다분산 장면, 음수/양수 셀 경계, 크기 비 1000:1, 희소 해시, 단일 셀 밀집, 극단 좌표 전수 대체, 동일 몸체 제외, 생성/삭제/재정렬을 검증했다.
- 구형 및 비구형 월드 각각 3,000스텝에서 전수 검사와 상태·접촉 수·이력 수 정확 일치.
- 처음에는 접촉하지 않지만 한 스텝 후 Hertz 겹침 한계를 넘는 빠른 접근을 사후 격자가 탐지하고 상태/시계/이력을 원자적으로 유지하는 것을 확인했다.
- 최적화 02 보관 실행 파일과 최종 버전 각각 3회 비계측 교대 실행, 각각 1회 계측 실행. 31개 물리 CSV가 모든 실행에서 바이트 일치했다.
- Unreal Editor Development 재빌드 및 `Powder.DEM.*` 13개 자동화 테스트 통과. NullRHI이며 GPU 렌더 성능 측정은 아니다.

## 최적화 02 대비 성능

Release CPU 단일 해석 경로, 같은 입력·물성·dt. 루프 시간에는 안전 검사와 시험 관측량 수집을 포함하고 초기화·CSV 저장은 별도 기록했다. 표의 값은 비계측 3회 중앙값이며 1 미만의 개선 배수는 느려졌다는 뜻이다. 비교 기준은 새 후보 배열 비용이 섞이지 않도록 최적화 02 당시 실행 파일(보관 SHA256 검증)을 그대로 사용했다.

배속은 물리초/실제초다. 20mm 조건과 1mm 조건은 dt·밀도·계수가 다르므로 서로의 배속 차이를 최적화 효과로 해석하지 않는다. 같은 행 전후만 비교한다. `mixing_32`는 기존부터 겹침 5% 한계 부적합인 30RPM 진단 사례이며 유효 정확도 기준이 아니다.

최초 해시 방식은 후보 수 감소에도 조회 비용이 커 소규모 성능이 떨어졌다. 셀 단위 방문과 제한된 배열 격자로 보완했다. 최종 상태에서도 일부 소규모 조건은 기존 전수 검사보다 느리므로 모든 장면이 빨라졌다고 해석하면 안 된다. 다음 최적화 04의 이웃 목록 재사용·자료 배치에서 매 스텝 두 번 구성하는 비용을 줄일 예정이다.

## 제한·다음 작업

- 300몸체/1024구 상한 유지. 1천·1만·10만·목표 약 159만 입자 조건은 계속 미지원이다.
- 밀집 단일 셀 및 큰 입자/작은 입자가 심하게 섞인 조건은 후보 수가 제곱으로 증가할 수 있다. 항상 선형 성능을 보장하지 않는다.
- 이웃 목록의 시간 방향 재사용은 아직 구현하지 않았다. 매 스텝 힘/안전 검사 각각 새 탐색한다.
- 짧은 소규모 시험이다. 0.1배속 지속 실행·kg 규모 공정·실물 분말 정확도를 입증한 것이 아니다.
- 다음: 최적화 04 — 이웃 목록 재사용과 자료 배치.
- 커밋·푸시는 수행하지 않았다.
