# 최적화 11 — 대표 입자 모델 계약과 질량·조성 구조

완료일: 2026-10-22  
브랜치: `PowderSimulationOptimization`  
상태: **계약·자료 구조·수치 검증 완료. 대표 입자 런타임 연결은 최적화 12.**

## 구현 결과

`Physics/PowderCore/include/powder/representative.hpp`에 물리 입도 구간, 대표 입자 구간, 원료 그룹별 재고, 물리/계산 접촉 계수를 분리하는 구조와 검증 함수를 추가했다. 입도 분포는 **개수 기준의 명시적 구간 목록**으로 입력하며 평균 입경 하나로 합치지 않는다. 임의 난수 입도 생성, kg 투입량의 입자 수 반올림, 위치 생성은 이 API의 범위가 아니다.

원료 그룹/입도 구간별 실제 입자 수와 질량을 보존한다. 하나의 대표 입자에는 하나의 원료 그룹과 하나의 입도 구간만 속한다. 서로 다른 원료를 미리 혼합해 하나의 대표 입자로 집계하지 않는다. 원료 그룹의 밀도는 하나로 고정하며 밀도가 다른 원료는 다른 그룹으로 정의한다. 동일 그룹/구간 키 중복은 거부한다.

**Core 34/34 통과**, CSV 내보내기 독립 재검산 통과. 기존 해석기/Unreal 런타임 코드와 레벨·기본 물성·dt는 변경하지 않았다. 새 헤더는 아직 Unreal에서 사용하지 않으므로 이번 작업에서 Unreal 재빌드/자동화 재실행을 하지 않았다. 이전 단계의 Unreal 결과를 이번 실행 결과로 재기록하지 않았다.

## 축약비와 SI 단위

`q`는 대표 입자 1개가 나타내는 **실제 입자 개수**다. `lambda = cbrt(q)`는 길이 배율이다. 두 수를 같은 축약비로 혼용하지 않는다. q=8이면 길이 2배, q=27이면 길이 3배다.

| 항목 | 관계 | 단위 |
|---|---|---|
| 물리 입경 | 입력 `physical.diameter_m` (반지름 아님) | m |
| 계산 입경 | d_c = lambda * d_p | m |
| 밀도 | rho_c = rho_p | kg/m³ |
| 실제 입자 수 | N_p | 정수 |
| 계산 입자 수 | N_c = N_p / q | 정수 |
| 구 1개의 질량 | m_p = rho*pi*d_p³/6 | kg |
| 계산 구 질량 | m_c = q*m_p | kg |
| 그룹/구간 질량 | N_c*m_c = N_p*m_p | kg |
| 계산 구 관성 | I_c = q*lambda²*I_p | kg·m² |

질량과 관성은 기존 `sphere_properties()`로 계산한다. 밀도를 인위적으로 늘리지 않는다. 계산 지름으로 얻은 구 질량과 대표 개수에서 요구되는 질량이 상대 1e-12 이내인지 검사한다. 이 관성은 **계산 구의 관성**이며, 실제 작은 입자 군집의 임의 배열·내부 운동을 보존했다는 뜻이 아니다.

입자 수와 q 및 전체 합은 double로 정수를 정확히 표현할 수 있는 2^53-1 이하로 제한한다. 빈 분포, 0개 구간, 0/음수/NaN/무한 입경·밀도, 개수 합 및 질량 overflow를 거부한다. q가 유효해도 그 축약비의 물리 정확도가 검증된 것은 아니다.

## 고정 q와 잔여 입자

이번 계약은 **전체 원료·구간에 같은 q**를 적용한다. 모든 구간의 N_p가 q로 나누어떨어져야 한다. 나머지가 있으면 거부하며, 입자/질량을 버리거나 임의 반올림하거나 서로 다른 구간의 잔여 입자를 합치지 않는다. 다른 가중치/다른 크기의 잔여 대표 입자도 자동 생성하지 않는다.

따라서 현재 10kg 기준에서 원료당 795,775개를 q=8로 나누는 요청은 거부한다. 최적화 12의 첫 비교 시험은 q로 정확히 나누어지는 명시적 투입 개수로 구성해야 한다. 실제 목표의 잔여 개수 처리는 별도 모델 계약 없이 은폐하지 않는다. 분할/병합과 가변 q는 이번 범위에 없다.

## 접촉 환산 후보

`RepresentativeContact`는 원래 `MaterialContact physical`과 별도의 `computational` 복사본을 보존한다. q=1은 검증된 기존 접촉 모델을 **그대로 복사**한다. q>1에서는 건조·비응집·구름저항 없음·선형 구형 접촉의 `DryBulkCandidate`만 허용한다. 재료쌍마다 주어진 계수를 환산하며 임의 평균/재료 혼합 법칙을 도입하지 않는다.

| 계수 | 계산 후보 | 단위 |
|---|---|---|
| kn, kt | lambda 배 | N/m |
| cn, ct | lambda² 배 | N·s/m |
| 미끄럼 마찰 mu | 그대로 | 무차원 |
| 밀도 | 그대로 | kg/m³ |

이 후보의 차원 관계는 다음과 같다. 길이와 접촉 이력을 lambda배, 같은 상대 속도에서 접촉 시간을 lambda배로 비교하면 선형 탄성·감쇠 힘이 lambda²배, 토크가 lambda³배다. 질량은 lambda³배이므로 c/sqrt(k*m)는 유지된다. 이는 이 코드의 선형 힘 식에서 직접 확인한 관계이며, 다중 접촉·클리핑을 포함한 모든 충돌의 반발계수나 벌크 거동이 같다는 보장이 아니다.

**실제 중력은 자동 변경하지 않는다.** 고정 g에서 중력은 lambda³배, 위의 접촉 힘은 lambda²배이므로 모든 무차원 조건을 동시에 보존하지 못한다. 장비 크기와 좁은 틈도 고정되어 있다. 따라서 후보는 `requires_bulk_validation=true`로 표시하며, 대표 입자를 적용한 충전·배출·혼합 비교는 최적화 12~13에서 통과해야 한다. dt 증가도 자동 적용하지 않는다.

최적화 08의 강성 완화와 이번 입경 환산을 자동 조합하지 않았다. 입력 접촉 계수의 출처는 호출자가 관리해야 하며, 완화된 계수를 실제 측정 물성으로 재표기하면 안 된다.

## 적용/미적용 범위

| 항목 | q=1 | q>1 |
|---|---|---|
| 기존 선형/Hertz, 기존 마찰·구름·응집 | 기존 모델 복원 | 선형 미끄럼 마찰 후보만 허용 |
| 선형 입자쌍/평면벽 접촉 | 기존 경로 | 동일 q 후보의 힘/토크 관계만 검증 |
| Hertz 환산 | 변화 없음 | 거부 |
| 구름저항·응집 환산 | 기존 경로 | 거부 (사용되지 않는 중첩 설정도 보수적으로 검사) |
| 항력/공기 모델 요청 | 거부: 기존에 미구현 | 거부 |
| 좁은 관·막힘, 입도 분리, 충격/변형 목적 | 기존 모델 | scope로 거부 |
| 비구형/복합 입자 축약 | 이 API는 PSD 구형 자료만 취급 | 변환 기능 없음 |
| 이동 벽·공정 전체·혼합 품질 | 기존 기능과 별도 | 이번 단계에서 검증하지 않음 |

구간 물리 입도와 계산 입도를 따로 저장해야 하며, 실제 입도 분리/통과를 계산 입경으로 이미 정확히 재현한다고 해석하지 않는다. `representative_inventory()`는 자료 계약이므로 독립적으로 재고 계산이 가능하지만, 이것만으로 금지된 접촉/공정 실행이 허가되는 것은 아니다. 최적화 12의 실행 연결에서 접촉/범위 검증과 동일 q 검사를 함께 사용해야 한다.

## 문헌 근거와 해석 범위

1. [Zhang, Huang, Zhao (2021), Comparison of Coarse Graining DEM Models Based on Exact Scaling Laws](https://www.techscience.com/CMES/v127n3/42603/html), DOI 10.32604/cmes.2021.016018. 길이·시간·밀도 배율을 구분하는 기준을 참고했다. 위 선형 k/c 관계는 이 프로젝트의 힘 식에 차원 관계를 대입한 후보다. 논문의 전체 스케일 변환을 고정 장비·고정 중력 공정에 그대로 충족했다고 주장하지 않는다.
2. [Thakur, Ooi, Ahmadian (2015), Scaling of discrete element model parameters for cohesionless and cohesive solid](https://arxiv.org/abs/1506.00439). 준정적 압축과 다른 접촉 모델에서 입경에 따른 강성 환산을 연구했다. 현재 선형 동적 분말의 실제 검증이나 응집 계수 환산 근거로 그대로 전용하지 않았다.
3. [Chen, Elliott (2020), On the scaling law of JKR contact model for coarse-grained cohesive particles](https://www.repository.cam.ac.uk/items/691f150d-168f-4d43-913c-e0382a6d9376), DOI 10.1016/j.ces.2020.115906. 응집 환산은 접촉 모델과 보존 조건에 의존하므로 이번 적용에서 제외했다. 현재 해석기의 접촉 한정 인력은 JKR 구현이 아니다.

공개 논문을 근거로 참고했으며 상용 해석기를 실행하거나 도입하지 않았다. 확인일 2026-10-22. 링크와 사용/비사용 범위는 `sources.json`에도 기록했다.

## 검증 결과

- 전체 Core 34/34 통과. 원료 2개 × 입도 구간 2개의 q=1/2/8 자료에서 그룹별 실제 개수·질량·질량 분율 보존. 비정수 길이 배율 q=2 포함.
- q=1의 입경·질량·관성 값 bit 동일. 실제 `ClumpWorld`에서 선형/Hertz 및 구름/응집을 포함한 100스텝 궤적·이력 수가 기존 모델과 동일.
- q=2/8/27의 입자쌍·평면 접촉에서 이력을 50회 갱신하면서 힘 lambda², 토크 lambda³, 접선 이력 lambda 관계 확인. 상대 허용오차 1e-10 + 절대 1e-24로 작은 관성도 검사.
- 밀도·단위·질량·관성·감쇠비, 잘못된 구간·중복·잔여·overflow·금지 scope 및 항력 요청 거부 확인.
- `inventory_q1.csv`, `inventory_q2.csv`, `inventory_q8.csv`를 Python에서 독립 재검산. 입력 실입자 120개는 q=8에서 계산 구 15개에 해당하지만, 이번 단계에서 이 15개를 장면에 배치해 실행하지 않았다.

성능 향상이나 전체 속도 목표 달성을 측정한 작업은 아니다. 실분말 검증도 아니다. 이번 결과로 축약비의 안전한 최대값을 선정하지 않는다.
