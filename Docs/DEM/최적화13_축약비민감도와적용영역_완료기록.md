# 최적화 13 — 축약비 민감도와 적용 영역 판정

완료일: 2026-10-22. 브랜치: PowderSimulationOptimization. 언리얼 에디터 기본 실행은 비축약 상태로 유지한다.

## 판정

**현재 공정에서 유지할 축약비는 q=1이다. q>1의 적용을 승인하지 않는다.** q는 계산 입자 하나가 대표하는 실입자 수이며 길이비는 q의 세제곱근이다. q=1은 비축약 기본 경로를 유지한다는 뜻이지 실물 정확도 인증이 아니다.

시험 범위의 최대 비율 필드: 1. 기준 해석의 수렴·표본·중첩 검사 통합 결과: False. 해당 통합 결과가 False이면 최대 비율의 1은 검증 완료 표시가 아니라 비축약 경로로의 보수적 복귀 값이다.

## 이번 작업

- 별도 powder_rep13 실행기: q=1/2/4/8, 원료 질량비 A:B=25:75/50:50/75:25, 초기 배치 seed=11/22/33. 36개 기본 실행 + 각 비율/원료비에서 seed=11의 dt/2 실행 12개. 단일 입자 통과/차단 제어 2개를 더해 총 50개.
- 별도 powder_aperture13 실행기: q=1의 대칭 두 입자 막힘과 두 입도 선별 제어 2개. 좁은 구간과 입도 분리의 q>1 실행은 기존 계약대로 거부한다. 금지 모델로 강제 실행하지 않는다.
- 대표 입자의 직경 때문에 물리적으로 가능하던 통과가 불가능해지는지 판단하는 representative_clearance와 경계/금지 범위 회귀 검사를 추가했다. 등호인 무여유 끼워맞춤은 통과로 인증하지 않는다.
- 판정 도구는 무효 셀, 누락 실행, NaN, 시간 불일치, 중간 비율 실패를 허용으로 처리하지 않는다.

## 조건과 비교 방법

실입자 128개, 직경 10mm, 밀도 2500kg/m³, 총량 약 0.16755kg. 계산 입자 수는 q에 따라 128/64/32/16개. 동일 원료 8개씩 16개 고정 관측 묶음을 정의해 두 계산의 표본 수와 질량 가중치를 맞췄다. 묶음 COM은 내부 분산을 숨길 수 있으므로 이 결과를 미세 입도 분리나 제품 혼합 품질로 해석하지 않는다.

같은 묶음 중심에 ±1mm의 결정적 초기 배치 변동을 주고 seed 홀짝으로 묶음 내부 x/y 방향을 바꾼다. 각 q에서 겹치지 않는 8/4/2/1개 구를 배치한다. 전역 질량·조성·묶음 중심은 같지만 구의 크기와 묶음 내부 공간 분포는 다르다. 이 배치 차이도 대표 입자 모델의 오차에 포함한다.

건조 선형 접촉 kn=10000 N/m, cn=0.2 Ns/m, kt=2500 N/m, ct=0.05 Ns/m, μ=0.1. 초기 대향 속도 ±0.5m/s, 물리 시간 0.12s. 기본 dt=0.5µs, 수렴 dt=0.25µs. 최적화 12의 강성 1000 N/m와 큰 중첩 조건을 그대로 정확도 기준으로 사용하지 않았다. 이는 가상 재료 시험이며 실제 물성 보정이 아니다.

21개 공통 시점, 동일 영역 x=[−0.22,0.22]m, y=[−0.5,0.5]m, z=[−1,0.5]m. 기본 2×1×1 셀은 점유 셀당 최소 4개 묶음, 비교 4×1×1 셀은 최소 2개 묶음이다. 비율 간에는 동일한 셀/표본 조건을 적용한다.

사전 기준: 양 셀 해상도의 혼합도 절대차 ≤0.1, 높이 차/ max(기준 높이 절댓값, 10mm) ≤0.1, 최대 중첩/반지름 ≤0.05. 시간 간격 절반 비교 한계는 혼합도와 정규화 높이 각각 0.02다. 부족한 표본이나 미완료 수렴 검사는 불합격으로 남기며 결과에 맞춰 한계를 늘리지 않는다.

## 좁은 출구·막힘·입도 분리

12mm 직선 슬롯에서 직경 10mm 실입자는 통과하고 14mm 실입자는 차단되는 실제 q=1 계산을 확인했다. q=2에서는 10mm 입자도 약 12.60mm가 되어 통과 가능성이 사라진다. q=4/8에서는 각각 약 15.87/20mm다. 작은 입자만 통과하는 크기 선별 자체가 없어지므로 해당 구간에서 대표 입자 적용을 금지한다.

추가 q=1 제어 시험 결과:
- bridge: 통과 0/2, 최대 중첩비 0.030671, 마지막 운동에너지 8.92865e-05 J.
- psd: 통과 1/2, 최대 중첩비 0.043960, 마지막 운동에너지 0.00567685 J.

bridge는 대칭 두 구가 슬롯 양쪽에서 0.3s 동안 통과하지 않는 시험이다. 마지막 운동에너지가 남아 있어 정적인 안정 아치로 판정하지 않았다. psd는 서로 떨어진 두 입도 흐름의 선별 시험이다. 장시간 안정 아치 확률, 실제 호퍼의 다입자 막힘, 진동에 의한 해소 또는 벌크 입도 분리 검증은 아니다. 이를 예측할 수 있다는 이유로 q>1 제한을 해제하지 않는다.

## 검증 및 재현

전체 Core 37개 통과. 새 C++ 적용 제한 검사와 Python 판정/CLI 검사 포함. 기준 파일 초기·시계열·셀·최종 상태의 반복 실행이 byte 단위로 일치했다. 이번 코드는 에디터 모듈에서 참조하지 않으므로 Unreal 빌드/자동화는 다시 수행하지 않았다.

```powershell
python -B Scripts/run_optimization13_validation.py --output Saved/Optimization13_new
python -B Scripts/run_optimization13_aperture_validation.py --output Saved/Optimization13_aperture_new
```

Release 빌드에 powder_rep13, powder_aperture13이 필요하다. 새 출력 경로만 허용한다. 결과는 Docs/DEM/optimization13/acceptance.json, aperture_controls/acceptance.json, contract.json, 개별 CSV/실행 로그, core_tests.log, source_snapshot.zip에 저장했다. 기본 비교 36개는 순차 실행했고, dt/2 수렴 계산 일부와 회귀/출구 제어 검증은 동시에 수행했다. 속도비는 기본 비교 실행끼리만 계산하며 dt/2 실행 시간으로 속도를 평가하지 않는다. 작은 시험의 단일 실행 속도는 kg 규모 목표 0.1s/s의 달성 근거가 아니다.
