# 작업 19 — 정적 삼각형 메시 접촉

상태: 완료 (2026-10-21). PowderCore 0.19.0.

## 구현한 범위

구–삼각형 접촉을 구형 `ParticleSystem`과 비구형 `ClumpWorld`에 연결했다. 정적 메시의 면·모서리·꼭짓점에서 최근접점을 구하고, 입자 중심을 향하는 접촉 법선 및 겹침으로 기존 선형/Hertz·접선 마찰·구름 저항·접촉 응집 모델을 평가한다. 비구형은 구성 구에서 받은 힘과 토크를 강체 무게중심에 합산한다. Chaos로 대신 계산하지 않는다.

`StaticTriangleMesh`는 생성 때 형상 검증·이음부 분류·AABB BVH 구축을 끝내며 이후 불변이다. 복사한 세계는 계산용 형상을 공유한다. 좁은 접촉 탐색은 BVH 후보에 대해서만 수행하고 전수 탐색 비교 옵션도 제공한다. 닫힌 고체 내부 판정은 바운딩 박스 안에서 삼각형 입체각 합으로 계산한다. 이 내부 판정은 전수 계산이므로 대형 닫힌 장비 메시의 성능까지 최적화한 것은 아니다.

## 단위·표면·경계 계약

- 좌표 입력은 `metres_per_unit`을 반드시 명시하며 계산·저장 좌표는 m다. 예상 SI 바운딩 박스 대각선의 하한/상한도 요구한다. 예상 치수를 잘못 지정하면 단위 오류를 자동 추론할 수 없으므로 장비 도면 치수와 별도로 대조해야 한다.
- 닫힌 고체는 하나로 연결된 폐곡면·일관된 바깥 방향·양의 체적을 요구한다. 고체 내부 또는 표면 위의 입자 중심은 거부한다. 여러 고체는 별도 표면으로 넣는다.
- 열린 메시를 쓰면 두께 0인 **양면 벽**으로 해석한다. 열린 모든 모서리를 `inlet`·`outlet`·`perimeter` 중 하나로 명시해야 한다. 미분류 경계는 의도하지 않은 틈일 가능성으로 거부한다. 입출구 표시는 열린 경계의 의미이며, 물질 공급·배출 통계를 자동 생성하는 기능은 아니다.
- 중복 면(뒤집힌 면 포함), 중복 정점, 퇴화/매우 가는 삼각형, 인덱스 오류, 3개 이상 면이 붙은 모서리, 뒤집힌 이웃 면, 불필요한 경계 라벨 등을 검사한다.
- 언리얼 렌더 메시의 UV/법선 이음부에서 같은 위치가 중복된 정점은 **정확히 같은 로컬 좌표만** 합친다. 가까운 정점을 임의로 붙여 실제 틈을 막지 않는다.
- 얇은 벽은 두께 0 양면 표면으로 명시하거나 실제 두께를 가진 닫힌 메시로 입력한다. 진단에는 양면 표면 여부·최소 모서리 길이·전체 크기·패치 수·경계별 개수가 남는다. 최소 모서리 길이는 일반 장비의 최소 벽 두께 측정값은 아니다.

## 이음부·안전한 시간 적분

연결된 공면 삼각형에 공통 패치 ID를 부여한다. 공면 이음선의 가짜 모서리 접촉을 제외하고 같은 접촉점을 중복 합산하지 않는다. 따라서 평면 위에서 삼각형을 넘어가도 마찰·구름 이력이 유지된다. 실제 오목한 모서리에서는 서로 다른 벽의 구속을 남긴다. 실제 날카로운 면/모서리/꼭짓점으로 접촉 특징이 바뀌면 이력 키도 바뀔 수 있다.

메시 접촉 개수를 기존 다중 접촉 dt 제한에 포함한다. 이동 후 중심 선분이 삼각형을 통과하면 계산 단계 전체를 거부한다. 너무 큰 이동, Hertz 겹침 제한, 고체 내부 위치도 검사한다. 실패 시 위치·속도·접촉 이력이 부분 반영되지 않는다. 이는 관통 상태를 감추지 않는 이산 적분 보호 장치이며 연속 충돌 시각을 풀어 자동으로 dt를 줄이는 CCD 해석기는 아니다.

## 언리얼 시험장

새 레벨 **`/Game/L_MeshTest`**:

- 바닥 1개, 경사판 1개, 사각 관 벽 4개. 각 도형의 실제 StaticMesh LOD0 정점·인덱스와 컴포넌트 위치/회전/스케일을 읽어 SI 해석 표면으로 변환한다.
- 현재 UE 5.8의 기본 Cube는 LOD0에서 48개 삼각형이다. 시험장 전체 **6개 표면 / 288개 삼각형 / 공면 패치 각 6개**가 사용된다. 상자 충돌로 대체하지 않는다.
- 구형 분말 3개와 두 구 이물질 3개, **6개 강체 / 9개 구성 구**를 높여 배치했다. 가상 물성은 작업 18과 같다.
- Play 후 일시정지로 시작한다. **Space** 실행/정지, **N** 한 단계, **R** 초기화, **O** 일시정지 상태 저장. 카메라는 기존 우클릭+WASD를 사용한다.
- `Triangle Mesh Rig`를 끄고 Reset하면 작업 18의 상자 바닥 모드로 돌아간다. 기존 `L_Main`, `L_ClumpTest`, 프로젝트 기본 시작 레벨은 바꾸지 않았다.
- 고정 dt=2e-6 s, 기본 최대 200단계/프레임과 약 4 ms 작업 예산을 유지한다. 실제 시간보다 느리게 진행될 수 있으며 프레임 시간으로 물리 dt를 바꾸지 않는다.

`Saved/DEM/Clumps/<GUID>/`의 상태 출력에 `surface_0.mesh`부터 실제 해석 표면들과 `geometry_diagnostics.txt`를 추가했다. 적용된 형상을 SI로 저장하므로 에셋 이름만 남기는 출력이 아니다. 설정의 `triangle_mesh_rig`와 기존 몸체/구성 구 상태도 저장한다. 재시작 체크포인트는 아니다.

## 검증 결과

- 코어 **17개 × 2회**, 언리얼 **9개 × 2회**, CLI/결과 검사 4묶음 × 2회 통과.
- 기존 **42조건 × 2회** 통과. 작업 18의 기준 CSV와 측정 시간 외 모든 수치·최종 상태가 일치했다.
- 삼각형 메시와 해석 상자의 면·모서리·꼭짓점 접촉 겹침 및 법선: 허용 오차 1e-12. 회전·이동·비균일 크기도 비교했다.
- 512개 삼각형 평면을 가로지르는 401개 위치에서 전수 탐색과 BVH 접촉이 일치했다. BVH 좁은 단계 검사는 **28,896회 / 전수 205,312회**였다. 이 비율은 본 입력의 후보 수이며 전체 실행 시간 배속이 아니다.
- 10,000단계 평면 마찰 이동: 메시/무한평면 최대 위치 차이 **1.17961e-16 m**, 기준 1e-10 m. 회전 결과도 기준 이내였다.
- 두 강체의 25,000단계 바닥 충돌: 메시/해석 상자의 최대 무게중심 z 차이 **0 m**, 기준 1e-10 m. 실제 벽 접촉과 바닥 비관통 확인.
- 실제 언리얼 288개 삼각형 시험장에서 150,000단계, 물리 시간 **0.3초** 실행: **31,370회 접촉 관측**, 총 질량 **1.819610464959208 kg**, 바닥 누출 없음. 접촉 관측 수는 단계별 합이며 서로 다른 충돌 사건 수가 아니다.
- 입구/출구 각 4개 모서리인 열린 사각 관: 중앙 경로는 열리고 벽 이음부는 접촉했다. 0.3초 동적 통과 시험의 최종 z=-0.0314647 m로 출구를 통과했다. 면 하나를 제거한 비의도적 틈은 입력 검증에서 거부했다.
- 두께 0 양면 벽, 두께 20 μm 닫힌 벽, 중복·퇴화·비다양체·뒤집힌 면·단위 오류를 검사했다. 벽을 넘는 잘못된 단계에서 입자와 이력이 보존됐다.
- 선형/Hertz와 구름 저항·응집을 켠 평면 접촉에서도 기존 벽의 힘·회전과 1e-12 이내로 일치했다.

개발 중 언리얼 `TObjectPtr`/인덱스 타입 컴파일 오류를 수정했다. 처음의 ‘Cube당 12개 삼각형’ 시험 기대값은 실제 에셋 추출 결과(48개)로 수정했다. 접촉 계산 결과를 기대값에 맞춰 바꾸지 않았다.

## 제한과 다음 작업

일반 CAD 메시의 자체 교차·부분적으로 포개진 면·서로 다른 컴포넌트 간 중복 면을 모두 찾아 수리하는 기능은 아니다. 외부 장비는 이 조건들을 검사한 해석용 메시를 입력해야 한다. 컴포넌트 사이를 자동 용접하지 않으며, 실제로 한 벽인 공면 이음부는 하나의 연결된 해석 메시로 준비한다. 열린 장비의 경계 라벨은 코어 형상 입력으로 지원하지만 언리얼 UI에서 임의 장비의 입출구를 선택하는 편집기는 아직 없다. 언리얼 변환 도우미는 현재 닫힌 고체를 대상으로 한다.

이번 전용 모드는 기존 구형 공급·통과 통계·Worker 결과 비교 계층과 별도다. 메시 접촉은 구형/비구형 코어 모두에서 사용 가능하지만 기존 `L_Main`을 메시 방식으로 일괄 전환하지 않았다. 장기 대량 퇴적, 실제 분말 보정, 장비 에셋 검증·가동 벽은 완료 범위가 아니다. 정적 형상은 Reset 때 고정되므로 실행 중 형상 이동은 지원하지 않는다.

다음 순차 작업은 **작업 20 — 처방된 가동 벽과 간단한 패들 시험**이다. 커밋·푸시는 하지 않았다.
