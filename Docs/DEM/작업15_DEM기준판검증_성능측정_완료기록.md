- 계산 코어: 0.14.0 유지. 물리식을 변경하지 않고 DEM_validation_v1 검증 도구를 추가했다.

## 구현과 실행

`Physics/PowderCore/app/benchmark.cpp`와 CMake의 `powder_bench` 실행 파일을 추가했다. `Scripts/run_dem_validation.py`는 빌드, 기존 단위 시험, CLI·결과 파서 시험, 선택적 언리얼 자동화 시험, 42조건 행렬을 반복하고 JSON/CSV/Markdown 보고서를 만든다. 기존 출력 폴더를 덮어쓰지 않으며 실패·미완료를 성공으로 표시하지 않는다. 입력 소스·실행 파일 SHA-256, 환경, 사전 허용 기준을 기록한다.

프로젝트 루트에서 재실행:

```powershell
python -B Scripts/run_dem_validation.py --output Saved/DEM_task15_validation_new --repeats 2 --unreal-editor "C:/Program Files/Epic Games/UE_5.8/Engine/Binaries/Win64/UnrealEditor-Cmd.exe"
```

별도의 CMake 설치는 `--cmake`, 빌드 폴더는 `--build`로 지정한다. 현재 도구는 Windows Release 빌드를 대상으로 한다. 언리얼 시험은 최신 Development Editor 모듈을 요구하며 코어 빌드와 별도로 검사한다.

## 검증 결과

- 코어 13개 × 2회, 언리얼 5개 × 2회 모두 통과.
- CLI·운동·접촉·결과 파일 검사 4묶음 × 2회 통과.
- 42조건 × 2회 모두 통과. 동일 빌드·기계에서 최종 입자 상태와 결정적 측정값이 정확히 일치했다. 접촉 이력은 개수만 비교하며 전체 이력 벡터나 다른 플랫폼의 비트 일치를 보증하지 않는다.
- 두 구 탄성 충돌의 속도 오차와 수집판 접촉의 위치 오차: dt 반감 시 오차 감소 비율 1.999747–2.000260. 기준 1.8–2.2 통과.
- 비정상적으로 큰 dt와 Hertz 허용 겹침 초과는 상태 변경 없이 거부됐다.

## 조건과 사전 허용 오차

| 시험 | 범위 | 기준 |
|---|---|---|
| 두 구 탄성 접촉 | 각 1 kg, 무마찰·무감쇠, k=1e3/1e4/1e5 N/m, 고정 구간 200/400/800 step | 위치 <1e-5 m, 속도 <1e-3 m/s, 상대 에너지 오차 <0.005, 질량·운동량 오차 <1e-12 |
| 실제 53상자 시험장 수집판 접촉 | 지름 0.04 m, 밀도 2500 kg/m³, 초기 압축 1e-5 m, k=4e5/4e6 N/m | 위치 <2e-8 m, 속도 <2e-4 m/s, 상대 에너지 오차 <0.005, 질량 오차 <1e-12 kg |
| 밀집 구 접촉 | 30/100/300개, k=4e5/4e6, dt=2e-7/1e-7 s, 중력·감쇠·마찰 없음 | 질량·운동량 오차 <1e-10, 겹침/반지름 <0.01, 접촉 발생 |
| 시험장 초기 자유낙하 | 30/100/300개, 같은 k·dt 조합, seed=42 | 위치 <3e-11 m, 속도 <1e-12 m/s, 질량·중력 충격량을 고려한 운동량 오차 <1e-10 |
| 시험장 단일 구 낙하 | 지름 0.2 m·1 kg 가상 구, dt=2e-6 s, 물리시간 1.5 s | 관 하부 통과·수집판 접촉, 최종 z>1.04 m, 최대 겹침 <0.005 m, 질량 오차 <1e-12 kg |

시간 간격 수렴 시험은 선형 탄성 모델이다. 기존 단위 시험이 Hertz·마찰·공급·추적 등을 별도로 검증하지만 모든 물성 조합의 수렴을 검증한 것은 아니다. 회전·마찰·벽 충격이 있는 모든 조건에 에너지 보존 기준을 적용하지 않는다. 해당하지 않는 지표는 빈 값/N/A이다.

## 성능과 화면에서의 움직임

300개, 53상자 시험장, k=4e6 N/m, dt=2e-7 s에서 100 step(물리시간 0.00002초)의 측정 시간 중앙값은 **0.712821초**, 범위 0.672245–0.753396초였다. 초당 약 140.74 step이다. 물리시간 진행이 매우 느려 육안으로 정지처럼 보일 수 있음을 설명하지만, 전체 퇴적 시간을 예측한 수치는 아니다.

확대한 단일 구의 1.5초 낙하는 중앙값 **14.9907초**였다. 300개가 모두 낙하·퇴적·배출되는 장시간 실험을 완료했다는 뜻은 아니다. 30/100/300개 성능 행렬의 관찰 시간은 20 μs이며 시험장 초기 배치에서는 아직 접촉이 없다. 별도의 밀집 접촉 행렬로 입자 간 접촉 비용을 측정했다.

계산 시간은 코어 stepping + 지표 수집만 포함하고 초기 배치·렌더링·파일 저장을 제외한다. 하드웨어·배경 부하에 영향을 받으며 고정 성능 합격 기준은 없다. 최대 겹침은 힘 평가 시점의 표본 최대값이지 연속 시간의 상한 보증은 아니다.
