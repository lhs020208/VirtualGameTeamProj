# 작업 08 — 유한한 상자 벽과 시험장 충돌 형상

완료일: 2026-10-21. PowderCore 0.8.0.

## 구현

- `geometry.hpp/.cpp`: 정적 회전 상자(중심·반크기·직교 축), 구–상자 최근접점, 면·모서리·꼭짓점 분류와 법선·겹침 계산.
- `ParticleSystem::boxes`: 기존 동시 힘·토크 합산과 선형/Hertz 접촉에 연결. 상자 접촉도 dt 제한과 단계 전후 기하 검사에 포함한다. 실패 시 입자 상태·이력은 반영하지 않는다.
- `weld_group`: 동일 조립체의 공면 벽 조각에서 중복 면·가짜 이음부 모서리 접촉을 제거하고, 공면 면의 접선 이력 키를 공유한다. 실제 직각 안쪽 모서리의 두 벽 접촉은 유지한다.
- `Scripts/export_dem_geometry.py`: `PowderRig` 태그가 있는 실제 BasicShapes/Cube 컴포넌트의 월드 변환을 내보낸다. 위치는 cm→m, 100cm 큐브 반크기는 스케일×0.5m로 변환한다. Euler 각을 재해석하지 않고 변환된 축을 사용하여 회전·비균일 크기·음수 크기를 반영한다.
- `fixtures/L_Main.boxes`: 버전 있는 SI 텍스트 입력. `read_boxes()`로 계산 코어에 읽는다. manifest JSON에는 액터 이름과 대응 ID를 기록한다.

현재 열린 에디터의 Python 원격 실행 노드는 발견되지 않았다. 별도 Unreal Python 명령줄 실행으로 **저장된 `/Game/L_Main`**을 읽어 53개 큐브(공급부 16, 깔때기 16, 관 16, 수집부 5)를 가져왔다. 레벨을 저장하거나 액터를 변경하지 않았다. 저장되지 않은 에디터 변경이 있다면 에디터 Python 콘솔에서 다시 내보내야 한다.

## 검증과 수치 결과

Release 빌드 및 전체 CTest 7개 대상, Python CLI·운동·평면 회귀 검사 3개가 통과했다. 별도 Unreal 명령줄 검증도 통과했다.

| 검증 | 기준과 결과 |
|---|---|
| 면·모서리·꼭짓점 | 독립 거리식 `0.5 - 0.2√n`, 정규화 법선과 절대오차 1e-12 이내 |
| 회전·크기 | 회전한 비등방 상자와 반사 축의 접촉 위치·법선 확인 |
| 실제 Unreal 변환 | cm→m, yaw 90°, 비균일·음수 크기, 복합 pitch/yaw/roll의 꼭짓점 변환을 1e-10m 이내로 확인 |
| 평평한 이음부 | 201개 위치에서 접촉 1개, 겹침 일정, 가짜 횡방향 법선 없음, 동일 이력 키 |
| 동적 이음부 | 마찰·회전을 켠 구가 이음부를 넘어감. 무한 평면 기준과 위치·속도·각속도 전 성분 1e-10 이내 |
| 겹친 벽·실제 코너 | 공면 중복 1개로 정리, 직각 코너는 2개 접촉 유지 |
| 모델 연결 | 모서리 선형 힘의 해석값, Hertz 면 반력, 잘못된 dt의 상태 보존 확인 |
| 관 구멍 | 중앙 z=2.2~5.8m를 0.02m 간격으로 검사해 가상 뚜껑 없음 |
| 관 벽 이음부 | 반지름 0.119m 원주를 1° 간격으로 검사해 접촉 누락 없음, 접촉 수 1~2개 |
| 전체 시험장 낙하 | 공급부에서 관을 통과하고 수집부와 충돌함 |

전체 낙하는 **수치 검증용** 지름 0.2m, 질량 1kg의 구를 z=5.5m에서 중력 9.81m/s²로 떨어뜨렸다. kn=4e6N/m, cn=800Ns/m, kt=1e6N/m, ct=200Ns/m, 마찰계수 0.3, dt=2e-6초, 750000step=물리 시간 1.5초다. 실제 분말 물성을 나타내는 시험은 아니다.

- 관 하단을 통과하고 수집부 충돌을 검출했다.
- 최대 겹침 0.00349938m: 반지름 0.1m의 약 3.50%, 시험 기준 5% 미만.
- 최종 z=3.51182m: 충돌 후 반발 중이다. 이번 시험은 통과·충돌 검증이며 정적 안착 시험이 아니다.
- 전체 CTest 약 34.04초 중 box_geometry 약 22.99초. 한 번의 실행 비용이며 실시간 보장은 하지 않는다.

## 발견한 문제와 수정

- Unreal Python에서 노출되지 않은 명령줄 감지/Transform 생성 함수를 사용한 초기 검사 실패: 노출된 get_command_line 및 Transform 생성자로 수정하고 실제 엔진에서 재검증했다.
- 초기 선형 시험에서 기본값인 Hertz 모델이 선택되어 dt 제한에 걸림: 선형 시험 모델을 명시했다.
- 약한 선형 강성으로 실시한 초기 낙하에서 최대 겹침이 약 70.6mm였다. 그대로 통과 결과로 사용하지 않고 강성을 높이고 dt를 줄여 5% 반지름 기준을 추가한 뒤 통과했다.

## 범위와 제한

코어의 형상은 정적이다. 실시간 이동 벽, 임의 메시, 전단 변환, 연속 충돌 검출은 지원하지 않는다. 중심이 상자 내부/표면에 들어간 초기 상태는 명시적으로 거부한다. 아주 얇은 벽의 고속 통과에 대해서는 이동량 제한만으로 CCD를 보장하지 않는다.

날카로운 모서리·꼭짓점은 최근접점 방향의 등가 접평면으로 기존 접촉 법칙에 연결한다. 특히 그 위치의 Hertz 힘은 구–평면 반지름을 쓰는 근사이며 실제 날카로운 모서리의 응력 해법이 아니다. 현실적인 모서리 거동에는 향후 라운딩/별도 접촉 법칙과 실험 보정이 필요하다.

이음부 처리는 같은 weld_group의 공면 조립 벽과 내부에 가려진 접촉점을 대상으로 한다. 임의의 중첩 상자 전체에 대한 일반 Boolean 합집합 접촉 해법은 아니다. 동일 그룹의 공면 조각은 하나의 연속 표면이라는 가정을 사용한다. 관의 서로 다른 경사면 접촉은 유지한다. 실제 다입자 막힘이나 안식각을 검증한 것은 아니다.

상자 탐색은 현재 전수 검사하며 이음부 결합은 접촉 시 추가 벽 비교를 수행한다. 53개 시험장 범위에서 검증했고 대규모 벽 가속 구조는 아직 없다.

Unreal 화면 입자를 자체 DEM 결과로 구동하는 연결은 다음 **작업 09 — Unreal 단일 입자 연결과 계산 조작**이다. 이번 작업은 커밋·푸시하지 않았다.
