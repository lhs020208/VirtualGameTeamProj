# 최적화 08 완료 — 접촉 강성 완화 모델 검증

2026-10-22 / `PowderSimulationOptimization`

## 결정

선형 벌크 접촉의 강성 완화 실험 경로를 구현하고 **4개 시험 × 강성 비율 6개 × 시간 간격 5개 = 120조건**을 검증했다. 단기 패들 시험에는 통과 후보가 있으나 **적층·혼합·mm 입자·배출을 모두 만족하며 더 빠른 공통 후보는 없다. 따라서 에디터 기본 재료와 dt를 유지한다.**

시험별 결과:

| 시험 | 물리 시간 | 정확도 결과 | 완화하지 않은 최선 간격보다 빠른 통과 후보 |
|---|---:|---|---|
| 반지름 20mm, 32입자 적층 | 0.04s | 강성 90%도 에너지 기준 탈락 | 없음 |
| 반지름 20mm, 32입자, 5RPM 패들 | 0.1s | 강성 90%·80% 통과 | 8µs (원래 강성의 4µs와 비교) |
| 반지름 1mm, 32입자 적층 | 0.0004s | 90%·80%는 정확도 통과, 80ns는 기존 안전 제한 거절 | 없음; 40ns까지 |
| 반지름 20mm, 16입자, 넓은 수직 통로 배출 | 0.16s | 90%는 통과, 80% 이하는 접촉 지속시간 기준 탈락 | 없음; 4µs까지 |

단기 혼합 후보는 `optimization08/validated_profiles.json`에 **runtime_enabled=false**로 저장했다. 실제 레벨에 자동 적용하는 프리셋이 아니다. 현장 원료/실험 자료로 보정한 모델도 아니다. 다음 최적화 09는 기본 모델을 유지하며 CPU 병렬화를 검증하면 된다.

## 모델과 구현

`include/powder/softening.hpp`의 `soften_linear_bulk`는 원본과 계산용 계수를 별도 값으로 보관한다.

- `kn' = alpha·kn`, `kt' = alpha·kt`.
- `cn' = sqrt(alpha)·cn`, `ct' = sqrt(alpha)·ct`.
- 질량이 고정되면 `c/sqrt(k·m)`의 비율을 보존한다. 다중 접촉·마찰·힘 잘림이 있는 실제 계산의 반발계수가 같다는 보장은 아니다.
- 밀도·입경·질량·마찰계수·중력·형상·겹침/관통 제한은 유지한다. 원본 물성/계수 객체를 수정하지 않는다. 현재 값은 가상 원료의 기준 계수이며 실측값이라는 뜻이 아니다.
- 선형 접촉의 벌크 실험만 지원한다. Hertz, 응집력, 구름 저항이 켜진 모델의 완화는 거절한다. 비율 1은 기존 모델 그대로 동작한다.
- `SofteningScope::ClearanceOrClogging`, `ImpactOrDeformation`에서는 비율 1 미만을 거절한다. 이 scope는 호출자가 명시하는 적용 계약이며 메시에서 위험한 간극을 자동 판별하는 기능은 아니다.
- 별도 CLI `powder_soft08 CASE ALPHA DT NEW_DIRECTORY`와 검증/벤치마크 스크립트를 추가했다. 기존 Unreal 계산 경로에는 연결하지 않았다.

각 결과의 `materials.csv`는 3개 재료 쌍과 2개 벽 재료별 원본/계산용 kn·kt·cn·ct·마찰·Young 값과 비율을 기록한다. 선형 모델의 Young 값은 원래대로 보존되며 이 실험에서 강성으로 사용되지 않는다. `initial.csv`에는 밀도·질량이, `summary.csv`에는 반지름이 기록되어 계산 계수와 구분할 수 있다.

## 시험과 사전 계약

계약: `Physics/PowderCore/fixtures/optimization08_contract.json`.

- 강성 비율: 1, 0.9, 0.8, 0.5, 0.25, 0.1.
- dt 배율: 기준의 0.5, 1, 1.5625, 2, 4. 20mm 기준 2µs, 1mm 기준 20ns.
- 먼저 원래 강성의 기준 dt가 절반 dt와 수렴하는지 확인한다. 완화 모델의 가장 작은 dt를 원래 강성의 가장 작은 dt와 비교해 모델 오차를 판단한다. 큰 dt는 자신의 작은 dt와 수렴하면서 원래 강성 대비 벌크 계약도 만족해야 한다.
- 공통 물리 시각 21개에서 질량 중심 높이·운동에너지·벽의 일·토크 적분·혼합 지표·출구 질량 곡선을 비교한다. 배출은 모든 ID의 통과 시각·평균 및 95백분위 체류시간을 기록한다. 유형별 활성+배출 질량 보존도 검사한다.
- 모델 오차 허용: 벌크 에너지/벽의 일/토크 적분/접촉 지속시간 10% 상대 항 + 사전에 명시한 작은 절대 항, COM 높이 반지름의 10%, 혼합 지표 절대 0.02, 겹침 증가 반지름의 1%p 이내이면서 절대 겹침 5% 미만, 체류시간 5%+0.1ms, 배출 질량 곡선 5% 이내.
- 시간 간격 오차에는 더 엄격한 2% 벌크 기준, COM 반지름의 0.5%, 체류시간 1%+0.01ms 등을 적용한다. 개별 입자 궤적의 동일성은 완화 모델 채택 기준이 아니다.
- 접촉이 없는 단순 자유낙하만으로 통과하지 않도록 접촉 누적량이 양수여야 한다. 배출 시험은 약 6입경 폭의 열린 수직 통로와 벽 접촉을 포함하며 16개가 모두 출구를 통과해야 한다. 좁은 출구·호퍼 막힘 시험을 대신하지 않는다.

최초 64조건은 `initial_sweep/`에 보관했다. 이후 10%·20%만 완화한 경우와 최적화 07의 3.125µs 대응 간격을 추가했다. 허용 오차는 변경하지 않았다. 기존 64조건은 같은 실행 파일 해시·같은 입력임을 확인해 재사용하고 신규 56조건을 계산했다. 최종 120조건의 입력·물성·출구 기록을 다시 검사했고 판정과 수치 지표는 동일했다.

## 통과한 단기 혼합 후보

반지름 20mm, 밀도 2500kg/m³, 32입자, 5RPM, 0.1초, 시험 코드의 바닥/패들 형상에만 해당한다.

- alpha=0.9, 감쇠 배율 약 0.948683, dt=8µs.
- 기준 kn=10000N/m → 9000N/m, kt=2500 → 2250N/m, cn=8 → 약 7.58947Ns/m, ct=2 → 약 1.89737Ns/m.
- 최대 겹침 약 1.38037% (기준 가장 작은 dt 약 1.30758%).
- COM 최대 차이: 반지름의 약 0.171%. 토크 적분 최대 차이 약 0.00046554N·m·s, 벽의 일 최대 차이 약 0.00024375J로 계약 이내.
- 혼합 지표 차이는 0이지만 짧은 시험에서의 결과이며 장시간 혼합 효율 입증이 아니다.
- 관측 최소 접촉 제한 약 8.017µs에 가까운 간격이다. 새 접촉·형상·장시간 조건으로 확대할 여유를 입증한 것이 아니며 기존 안전 검사는 계속 적용된다.

완화하지 않은 검증 간격 4µs(25,000단계)와 8µs(12,500단계)를 3회 교차 실행했다. 각 경로의 물리 CSV는 반복마다 정확히 일치했다. 최초 비교 중앙값 약 **1.95배**, 재현 스크립트 비교 약 **1.92배**였다. 재현 측정 중앙값은 기준 약 1.08237초, 후보 약 0.56377초다. 측정은 데이터 수집을 포함한 Core CPU 루프이며 GPU/Unreal 프레임 비용은 포함하지 않는다.

이 시험은 20mm 구 32개를 다루므로 총질량이 약 2.68kg이어도 **mm 입자 수 kg 조건의 성능 증거가 아니다.** 대량 0.1배속 목표는 아직 미달이다.

## 탈락 원인과 적용 금지 범위

- 20mm 적층: alpha=0.5에서 겹침이 약 1.415%→2.832%, alpha=0.25에서 약 5.665%로 증가했다. 0.9/0.8도 에너지 기준에서 탈락했다.
- 5RPM 패들: 0.5 이하는 에너지·벽의 일·토크 적분 등의 차이가 커서 탈락했다.
- mm 적층과 배출: 일부 조건은 겹침/배출량/체류시간이 허용 범위여도 접촉 지속시간 차이로 탈락했다. 접촉 시간은 강성 완화로 변할 수 있으므로 이 보수적 계약에서의 탈락을 모든 벌크 완화가 불가능하다는 결론으로 해석하지 않는다. 결과를 보고 기준을 완화하지 않았다.
- 좁은 관, 입경에 가까운 틈, 체/필터, 목 부분, 걸림·브리징·막힘 확률, 압축/충격/파손 및 실제 최대 충돌력 평가에는 적용 금지다. 형상이나 입경 변경 후 기존 프로필을 재사용하지 않는다.
- 07의 30RPM 부적합 사례를 완화로 해결한 것으로 주장하지 않는다. 이번 시험은 5RPM 별도 조건이다.

## 검증과 유지한 동작

- Core **30/30** 통과. 계수 분리, 정규화 감쇠 비율, alpha=1 경로, 금지 scope/모델/잘못된 수치, 판정기의 지표·질량·출구 누락·비정상 값 거절 포함.
- alpha=1의 초기/최종 상태와 공통 시각 상태 **45개 CSV가 최적화 07과 byte-identical**. 기존 물리 경로의 결과가 유지된다.
- 별도 벤치마크 재현 스크립트로 동일 물리 결과와 반복 성능 확인.
- 이번 변경은 별도 실험 모델·실행기이며 Unreal 런타임 소스는 변경하지 않았다. 현재 에디터를 닫거나 재설정하지 않았다. 기본 강성/dt/접촉 안전 검사와 300몸체/1024구 상한을 유지한다.
- 커밋·푸시는 수행하지 않았다. 최적화 07의 미커밋 변경도 보존했다.
