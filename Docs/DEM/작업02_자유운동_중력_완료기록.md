단위는 SI, 기본 중력은 (0,0,-9.81)m/s²이다. 구 질량은 지름과 밀도로 계산한다.

적분법은 반암시적 오일러: `v_next = v + F/m * dt`, `x_next = x + v_next * dt`.
힘은 한 단계 안에서 합산하고 성공 후 지운다. 지속 하중은 매 단계 다시 적용한다. 유효하지 않은 입력이나 계산 결과는 입자와 힘을 갱신하기 전에 오류로 반환한다.

## 사전 검증 기준

- 등속 위치, 일정 가속도 속도, 예측한 이산 위치 오차: 절대오차 1e-10 SI 이내.
- 일정 중력에서 dt를 절반으로 줄일 때 위치 오차 비율: 2에 대한 절대오차 1e-8 이내.
- 기존 작업 01의 상대오차 기준 1e-12와 CLI 검사를 유지.

## 문제 수정과 제한

빌드·실행 검증에서 실패는 없었다. JSON에 실제 최종 상태와 초기 조건을 기록하도록 기존 고정값 출력을 변경했다.

충돌·마찰·회전 적분은 아직 없다. 바닥도 없으므로 Z=0 아래로 자유롭게 이동할 수 있다. 회전을 계산한 것처럼 보이지 않도록 0이 아닌 각속도 입력은 현재 적분 API에서 거부한다. 입력 힘은 한 step 동안 일정하다고 가정하며, 향후 접촉력은 매 step 다시 계산해야 한다.

반암시적 오일러의 물리 간격은 정확도 요구에 맞게 선택해야 한다. 현재 기본 간격은 접촉 계산의 안정성을 보장하는 값이 아니며 작업 03에서 접촉 시간·강성과 함께 검토한다.
