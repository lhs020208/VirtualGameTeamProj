# 최적화 15 — GPU 이웃 탐색과 구형 접촉

상태: 건조·선형·단일 공통 접촉계수의 구형 경로 구현 및 기준 시험 완료.

공간 키 정렬(bitonic), 인접 27셀 탐색, ID 기반 접선 변위/법선 이력, Coulomb 마찰, 힘·회전 토크, 적분과 사후 검사까지 GPU에서 실행한다. 이력은 두 버퍼로 보존하며 오류 스텝은 상태·이력을 커밋하지 않는다. 배치 중 성공한 앞부분만 시계에 반영한다. 후보/접촉 슬롯 초과, 겹침, 좌표 범위, dt/이동 한도는 명시적 오류다. 쌍 접촉은 양방향 계산하므로 부동소수 atomic 합산을 사용하지 않는다.

`gpu_contact_tests`: 64개 다분산·밀도 차이가 있는 구, 32개 초기 접촉쌍, dt=1e-7s, 10,000스텝. CPU 상태 최대차 2.22045e-14, 운동량 잔차 2.43522e-21. 활성 이력을 유지하면서 멀리 떨어진 입자를 추가해 65개 정렬 실행 후 삭제하고 기준 결과와 비교했다. 슬롯 부족·후보 부족·과대 dt의 거부와 실패 후 재시도를 확인했다. 최종 결과 `optimization15/final/result.csv`.

지원하지 않는 모델: Hertz, 응집, 구름저항, 비구형 clump, 서로 다른 접촉계수 테이블. 이를 동일 물성으로 몰래 바꾸지 않는다. 벽이 있는 장면의 동적 생성/삭제도 현재 거부한다. 다분산이 넓으면 최대 입경 기준 셀 때문에 후보 수가 커져 예산 초과로 정지할 수 있다.

10,000스텝 시험은 물리시간 0.001초이며 수초~전체 공정 장시간 통계 검증은 아니다. 장시간 대량 혼합/제품 품질 검증은 미완료다. 초기 버전 결과보다 `final` 결과를 사용한다.

검증 환경: 2026-10-22, Windows, RTX 4060 Ti 16GB, OpenCL FP64, MSVC Release /fp:strict, UE 5.8 Development Editor. 브랜치 PowderSimulationOptimization. 이번 요청에서 커밋/푸시는 하지 않았다.

Core 전체 41개 테스트 통과 후 변경된 GPU/인계 테스트를 재검증했다. Unreal 실제 RHI 활성화 환경의 16개 테스트 모두 통과했다. 재현은 프로젝트에서 `python Scripts/run_optimization14_18_validation.py --output Saved/Optimization14_18_new --full-target`. 이 스크립트는 Core/GPU 시험이며 Unreal 실행 결과는 별도다. 원본 로그와 코드 SHA-256은 `optimization14_18/`에 보관한다.
