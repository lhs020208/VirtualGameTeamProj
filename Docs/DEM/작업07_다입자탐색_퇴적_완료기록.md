# 작업 07 — 다입자 탐색과 정적 퇴적

완료일: 2026-10-21. 코어 버전: 0.7.0. 구현 위치: `Physics/PowderCore`.

## 구현

- 최대 입자 지름을 셀 크기로 하는 균일 공간 분할과 27개 이웃 셀 탐색. 음수 좌표와 서로 다른 지름 지원. 전수 쌍 검사도 기준 구현으로 유지한다.
- 입자 ID로 접촉 쌍을 정렬하여 중복을 없앤다. 호출자가 입자 배열 순서를 바꾸어도 같은 순서로 힘을 합산한다.
- 기존 접촉 함수를 힘·토크 평가와 적분으로 분리했다. 모든 접촉을 동일한 시점의 상태에서 평가하고 중력을 한 번 더한 뒤 각 입자를 한 번만 적분한다.
- 입자 쌍 및 입자–정적 무한 평면의 접선 변위 이력을 별도로 관리하고, 다음 평가에서 사라진 접촉을 정리한다.
- 선형 및 Hertz–Mindlin 단순화 이력 모델을 다입자 계산에 연결했다. 상태·이력은 전체 단계가 성공했을 때만 반영한다.
- 질량, 접촉 수, 겹침, 최고 속도, 거리 검사 수를 반환한다. 접촉·겹침은 적분 전, 속도는 적분 후 값이다.

## 검증 결과

Release 빌드, CTest 6개 대상(core_contract, plane_contact, sphere_pair, rotation_friction, hertz_mindlin, many_body), Python CLI·운동·평면 회귀 검사 3개를 모두 통과했다.

402개 입자(서로 다른 지름·음수 좌표·셀 경계 포함)의 접촉 52쌍이 전수 검사와 정확히 일치했다. 거리 검사는 전수 80,601회에서 공간 분할 1,343회로 감소했다. 중복 쌍이 없었다.

선형 3입자 다중 접촉에서 공간 분할/전수 검사/배열 역순의 위치·속도·각속도·자세 전 성분이 절대오차 1e-12 이내로 일치했다. 운동량 보존, 과대 dt 거부 시 상태 보존, 접촉 종료 시 이력 제거와 Hertz 다중 접촉도 검사했다.

### 정적 퇴적

수치 검증용 지름 1m·질량 1kg 구 3개를 무한 평면 위 z=0.51, 1.52, 2.53m에 놓았다. 실제 분말 물성에 대한 검증은 아니다. 중력 9.81m/s², kn=10000N/m, cn=40Ns/m, kt=2500N/m, ct=10Ns/m, 마찰계수 0.3을 사용했다.

물리 시간 5초, dt=2e-5초 결과:

| 항목 | 결과 |
|---|---:|
| 입자 수 / 총질량 | 3 / 3kg |
| 하단 높이 | 0.497056911845m |
| 중단 높이 | 1.49509484115m |
| 상단 높이 | 2.49411380192m |
| 마지막 최대 속도 | 1.83772e-5m/s |
| 계산 중 최대 겹침 | 0.00802660m |

독립 정적 평형 높이는 0.497057, 1.495095, 2.494114m이다. 높이 허용오차 2e-5m, 정지 기준 1e-4m/s, 최대 겹침 0.03m 기준을 통과했다. dt=1e-5초로 같은 5초를 계산한 높이와도 1e-6m 이내로 일치했다.

최초 3초 시험은 잔류 진동 때문에 상단 높이·정지 기준을 만족하지 못했다. 허용오차를 유지하고 물리 시간을 5초로 늘려 통과했다. 이는 수직으로 정렬된 3구의 퇴적 검증이며 무작위 분말 더미의 안식각 검증은 아니다.

### 규모 및 비용

한 번의 측정이며 하드웨어·부하에 따라 달라진다. 실시간 성능 보장은 하지 않는다.

| 시험 | 규모 | 비용 |
|---|---:|---:|
| 공간 탐색 | 100 | 거리 검사 342회, 약 0.19ms |
| 공간 탐색 | 300 | 거리 검사 2,594회, 약 0.69ms |
| 공간 탐색 | 1000 | 거리 검사 10,476회, 약 2.83ms |
| 다중 접촉 100step | 27 | 약 0.015초 |
| 다중 접촉 100step | 125 | 약 0.115초 |
| 다중 접촉 100step | 300 | 약 0.318초 |
| 3구 퇴적 250000step | 3 | 약 2.32초 |

100step 시험은 무중력, 초기 약 0.001m 겹침, dt=1e-5초 조건에서 질량·입자 수·운동량을 확인했다. 300개 입자가 장시간 쌓이는 실험을 완료했다는 의미는 아니다. 보고되는 거리 검사 수는 주 탐색만 포함하고, 단계 전후 기하 검사 비용은 실행 시간에 포함된다.

## 안전 범위 및 다음 작업

접촉 수·최소 질량·강성·감쇠 기반의 보수적 dt 제한을 사용한다. Hertz는 허용 겹침에서의 최대 강성을 사용한다. 이는 모든 조건의 안정성을 증명하지 않으므로 새 조건마다 시간 간격 축소 검증이 필요하다. 한 단계 이동량을 최소 반지름의 10%로 제한하지만 연속 충돌 검출(CCD)을 구현한 것은 아니다.

지금은 공유 재료 모델과 정적 무한 평면을 지원한다. 모델·물성·벽 형상 변경 또는 ID 재사용 시 `reset_history()`를 호출해야 한다. 유한 벽, 회전 상자·관, 임의 메시, 입자별 재료 조합, 응집, 실제 분말 보정은 후속 범위다. 지름 분포가 매우 넓으면 최대 지름 셀의 효율이 떨어질 수 있다.

Unreal의 기존 Chaos 실험장은 그대로이며, 자체 DEM은 독립 C++ API와 테스트 실행 파일로 검증했다. 단일 입자 CLI에 다입자 입력은 아직 추가하지 않았다.
