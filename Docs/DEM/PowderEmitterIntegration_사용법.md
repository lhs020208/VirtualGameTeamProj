# 생성기 기반 GPU 분말 시뮬레이션 사용법

## 현재 테스트 레벨
`L_MX301_Test`를 열고 Play한다. `Powder_Red_Lower_25000`과 `Powder_Blue_Upper_25000` 두 생성기가 각각 25,000개를 공급한다. 기존과 같은 초기 좌표, 총 50,000개이며 질량은 약 64.8kg이다. 시험용 혼합기이고 최종 공정 장비가 아니다.

## 일반 격자 생성기 추가
1. `Content/DEM/Emitters/BP_DEMEmitter`를 배치한다.
2. `DA_DEMParticle_GPU_Default`를 복제해서 Particle Settings로 지정한다. GPU Approximation을 켠다.
3. Particle Count, Columns X/Y, Surface Gap(m), 위치/방향, Initial Linear Velocity(m/s)를 설정한다. Actor Scale은 1이다. GPU Group 0은 빨강, 1은 파랑이다.
4. 혼합기 액터에서 Use Emitters를 켜고 Emitters 배열에 생성기를 명시적으로 등록한다. 목록 순서가 입자 ID 순서다. 생성기 개수 합계가 실제 입자 수이며 믹서의 수동 개수는 사용하지 않는다.
5. Play 또는 믹서 Reset Simulation으로 적용한다. 생성기 단독으로는 정지 표시만 한다.

현재 MX301 생성기는 곡면과 날개를 피한 **명시적 좌표 배열**을 사용한다. 배열이 비어 있으면 일반 격자다. 기존 테스트 생성기의 개수를 바꾸려면 Initial Local Positions Meters 배열을 비우고 격자 설정을 조정해야 한다. 배열을 유지하면 Particle Count와 배열 길이가 같아야 한다. 생성기의 이동/회전은 명시적 좌표에도 적용된다.

## 설정과 제한
- 모든 생성기는 동일 반지름·밀도·마찰을 사용한다. 서로 다른 재질/메시/색은 가능하다. 믹서 Particle Settings는 비우거나 같은 물성 에셋을 지정한다.
- GPU 반지름은 1mm 초과 30mm 미만, 입자/벽 마찰은 같은 0~1 값이다. 밀도는 질량 집계에 쓰며 GPU 동역학의 물성 보정을 뜻하지 않는다.
- 강성·감쇠·초기 회전은 GPU 모델에서 지원하지 않는다. GPU 모드에서는 강성/감쇠 편집이 비활성화되고 비영 초기 각속도를 거부한다.
- 생성기당 최대 100,000개, 합계 최대 1,000,000개는 입력 상한이다. 그 규모의 성능/안정성 보장이 아니다.
- 혼합기 위치와 수평 회전은 지원한다. 기울기와 비단위 스케일은 거부한다. 임의 새 장비 메시가 자동 충돌 경계가 되지는 않는다.
- 시작 시 용기/날개/입자 간 겹침을 검사한다. 틀린 배치는 제거하거나 자동 보정하지 않고 오류로 알린다.

## 미리보기·재생·변경
편집기 미리보기는 생성기당 최대 2,048개이며 실제 계산 개수를 줄이지 않는다. Play에서는 전체 입자를 표시한다. 에셋 편집 후 Refresh Preview로 갱신한다. 사용자 재질이 없으면 그룹 색을 사용한다.

실행 중 생성기 변경·삭제·Generate/Clear·혼합기 이동은 계산을 멈추고 Reset을 요구한다. Reset은 현재 설정/배치를 다시 읽고 시간·속도 상태를 초기화한다. 연속 방출은 지원하지 않는다. 기존 데이터를 재생하는 녹화 방식이 아니라 현재 GPU가 매 시간 단계를 계산한다.

비교용 기존 자동 배치 레벨: `Content/DEM/Tests/L_MX301_LegacyBaseline`.
검증 결과와 성능은 `emitter_integration06/acceptance.json` 및 통합 계획서를 참조한다.
