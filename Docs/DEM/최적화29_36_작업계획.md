35. 별도 Unreal 레벨에서 저장 용기·연결 통로·혼합 분포·센서·실시간 조작과 기록을 연결. 표시 입자는 흐름 표식임을 구분.
36. 10/30/50kg 전체 사이클 반복, 코어/뷰포트 포함 속도·질량·오류·정기 저장 검증. 실제 공정 정확도와 가상 장면 성능을 별도 판정.

가상 시나리오의 구현 완료와 실제 장비의 디지털 트윈 인수는 구분한다. 실제 보정 데이터 부재를 숨기거나 합성 자료를 실험값으로 취급하지 않는다. UI 및 입력에 노출하는 계수는 가상 기본값이다. 상용 해석기는 사용하지 않는다.
