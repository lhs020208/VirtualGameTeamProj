# 경량 재질 상태의 30FPS 배속 검증

2026-10-28, 기준 커밋 `8481a3a`. 결론: **현재 5만 개 입자, 시험 창 전면 실행 조건에서는 0.20배속을 권장**한다. 실제 1초당 시뮬레이션 0.20초이며 기존 0.1배속의 2배다. 보편적·무기한 최소 속도 보장은 아니다.

## 고정 조건

- `/Game/DEM/Tests/L_MX301_BinaryMaterials`, 간소화한 Unlit 재질과 후처리 설정.
- 50,000개, 동일 초기 위치 SHA, 동일 A/B 물성 및 총 약 40.838kg.
- dt=0.000375초, 접촉 16회, RPM=30. 물리 계산/충돌 형상 변경 없음.
- 1280×720 렌더링(저장된 실행 스크린샷 크기로 확인), `t.MaxFPS 30`. 기존 에디터는 열어 두었다.
- 목표 속도는 시험 프로세스에서 `set PowderGranularMixer TargetRate ...`로만 변경. 레벨의 저장된 0.1 목표 및 기본 화면 설정은 변경하지 않았다.

## 결과

0.22 시험은 에디터가 앞에 있고 시험 창이 뒤에 있는 동안 크게 느려졌다. 물리 약 18.4초 지점에서 시험 창을 전면으로 가져온 뒤 회복했다. 전환 후 충분한 시간이 지난 active_wall>=180초 구간의 5초 단위 처리량도 0.203488~0.216782(중앙값 0.210710)이어서 0.22 유지로 판정하지 않았다. 창 전환과 성능 변화의 연관은 관측했으나 OS 스케줄링, 다른 창의 렌더링 부하 등을 각각 분리한 원인 실험은 아니다.

최종 0.20 시험은 Running=false로 시작해 전면으로 가져온 뒤 콘솔로 Running=true로 전환했다. 의도적 일시정지 시간은 solver active wall에서 제외된다. 30.009초 물리 계산에 약 150.05초가 걸렸다.

## 화면 FPS와 충돌 검사

- 최종 시험에서 활성 계산 중 캡처한 1,725프레임(약 57.88초): 평균 **29.80FPS**, 프레임 시간 중앙값 33.34ms, 95백분위 37.57ms.
- 최대 프레임 시간은 421ms, 50ms 초과는 약 0.116%. 스크린샷/감사를 포함한 시험으로, 모든 프레임이 정확히 30FPS라는 보장은 아니다. 프레임 자료는 전체 150초를 모두 포괄하지 않는다.
- CSV에 콘솔 시작 이벤트가 기록되지 않아, 화면에서 실행 중 카운터 1,978을 확인한 뒤의 2,100번째 행부터 FPS를 집계했다. 일시정지 프레임은 제외했다. `frame_times_ms.csv`에 집계한 표본을 보존했다.
- 3개 실행의 초기 입자 SHA 동일. 최대 처리량 16개, 0.22 실행 31개, 최종 0.20 실행 16개 시점의 독립 기하 감사 통과.
- 최종 시험 최대 입자 겹침/작은 반지름은 약 **7.35%**(기존 합격 기준 10% 이하). 벽·날개 침범은 최대 약 5.64e-8m / 4.71e-8m로 기준 1e-4m 이하였다. 입자 겹침이 0이라는 뜻은 아니다.
- GPU 안전 오류/입자 수·성분 손실 없이 종료. 표본 사이 모든 순간이나 실측 분말의 물리 정확도를 증명하지 않는다.

## 하드웨어와 적용 범위

- 최종 0.20 시험 최고 관측 58°C / 118.19W. 전체 시험 최고 62°C / 129.01W.
- 온도 75°C, 전력 155W, 계측 실패 시 자신이 실행한 프로세스를 중단하도록 감시했다. 오버클럭·전력 제한 변경 없음.
- 다른 해상도, 확대 시점, 다른 GPU 작업 또는 시뮬레이션 창이 배경에 있는 경우에는 재측정이 필요하다. 특히 이번 배경 실행에서는 약 0.10배속 구간도 관측됐다.
- 아직 레벨 설정을 0.20으로 저장하거나 30FPS 제한을 영구 적용하지 않았다. 이번 요청은 가능한 속도 확인이며 실제 설정 변경은 별도다.
