# 작업 25 — 입자 체적 분율과 공기로의 반작용

완료: 2026-10-22. 모듈 버전 `0.4.0-dilute-two-way`.

**희박한 구형 입자의 체적을 격자에 보존적으로 배분하고, 항력의 반대 힘을 실제 공기 운동량 계산에 넣었다.** 힘의 양방향 교환이 구현됐으나, 밀집 분말을 해석하는 유한 공극률 CFD–DEM 전체가 완성된 것은 아니다. 출력에는 `model:dilute_regularized_point_force`, `finite_porosity_equations:false`를 명시한다.

## 1. 선택한 모델과 완료 범위

작업 24의 무거운 비회전 구형 입자·Stokes 항력과 작업 23의 2D 비압축성 공기를 사용한다. 입자 체적 분율 α는 **공간 필터를 적용한 체적 분율 진단값과 적용 범위 검사**다. α≤0.001인 희박 근사로 제한하며, 공기 방정식의 공극률 ε를 1로 근사한 운동량 소스 모델이다.

이번 단계에서 구현하지 않은 식은 `∂ε/∂t + div(εu)=0` 및 이에 일관된 유한 공극률 운동량식이다. 따라서 체적 분율을 파일에 저장한다는 사실을 곧바로 공극률 변화에 따른 기체 체적 배제 계산으로 해석하면 안 된다. 높은 α를 잘라서 계산하지 않고 적용 범위 밖으로 판정한다.

구현:

- 압력 셀별 입자 체적 분율과 공극률 출력, 전체 입자 체적과 격자 적분 체적 비교.
- 같은 공간 배분 가중치를 사용하는 유속 취득과 반작용 분배.
- 공기 예측 운동량에 실제 반작용 소스 적용 후 압력 투영.
- 공기와 입자를 같은 하위 시간 간격으로 진행하는 양방향 계산.
- 항력 충격량과 실제 공기에 주입한 충격량의 수지 검사.
- 격자·연성 시간 간격·입자 순서·희박 극한·실패 복구·저장 결과 재현성 검사.

기존 DEM 병진 입자·힘 적분을 재사용한다. 접촉 World, 회전·응집·가동벽, Unreal 레벨·세션에는 아직 연결하지 않았다. 상용 해석기를 호출하지 않는다.

## 2. 공간 배분 계약

물리 길이 h를 갖는 분리형 tent 함수 `φ(r)=max(0,1−|r|)`를 사용한다. 각 압력 셀 또는 MAC 면 위치에서 `φ((x−xp)/h)φ((y−yp)/h)`를 평가하고 해당 격자 집합의 합으로 정규화하여 양의 무차원 가중치 W를 만든다. 압력·u·v는 서로 위치가 다르므로 각 집합의 가중치를 따로 구성한다.

```text
V_cell = dx dy D
α_i = Σ_particle V_particle W_pressure(i) / V_cell
Σ_i α_i V_cell = Σ_particle V_particle
u_sampled = Σ_face W_velocity(face) u_face
F_gas(face) = −Σ_particle W_velocity(face) F_drag_particle
```

D는 `reporting_depth_m`이다. 공기만 계산하던 단계에서는 유량 환산용이었지만, **이번 힘 결합에서는 대표 슬래브의 기체 질량·힘 밀도에도 사용**한다. 실제 힘 N을 `ρ_air dx dy D`로 나누어 가속도를 계산하므로 D를 바꾸면 반작용의 크기가 바뀐다. z 방향 유동과 벽은 없다. 이 2D 슬래브 평균화 모델을 실제 3D 단일 구 주변 유동으로 해석하지 않는다.

정규화된 배분은 구와 각 셀의 실제 기하학적 교차 부피를 계산하는 방법이 아니다. 구의 전체 체적은 정확히 보존하지만 주변 여러 셀에 분산한 필터 체적 분율이다.

기본 h=0.0025 m이며 격자 세분화 시험에서도 물리 길이를 고정한다. h≥2 max(dx,dy), h<H/2를 요구한다. 입자 중심은 모든 열린 면·벽에서 `h+max(dx,dy)` 이상 떨어져야 하므로 배분이 경계에서 잘리지 않는다. 경계에 걸린 가중치를 다시 정규화하여 힘을 숨기는 처리는 없다.

같은 가중치를 유속 취득과 힘 분배에 사용하면 `Σ F_gas·u_gas = −F_particle·u_sampled`가 성립한다. Stokes 항력의 순간 교환 일률은 `−β|u_sampled−v_particle|²`로 소산 방향이다. 이는 공간 교환 연산자의 성질이며 열린 채널 전체의 에너지 보존을 주장하는 것은 아니다.

## 3. 입자·시간 간격·희박 조건

작업 24의 Re_p≤0.1, 추정 Kn(d)≤0.01, 밀도비≥100, d≤0.1 min(dx,dy), 비회전·z=0 조건을 유지한다. 벽 중심 거리≥50d, 입자 간 거리≥50×큰 입자의 지름, 최대 32개 고립 시험 입자로 제한한다. 국소 α>0.001은 즉시 거부한다. 이 수치들은 초기 기준판의 범위 제한이며 보편적인 정확도 보증 기준은 아니다.

기본 중력은 0이다. API에서는 xy 평면 중력(크기≤9.81 m/s²)을 지정할 수 있지만 열린 면 역류 금지·커널 경계·Stokes 적용 범위도 통과해야 한다. 부력·양력·이력력·부가질량·배경 압력 기울기 힘·벽 및 다입자 항력 보정은 구현하지 않았다.

하나의 외부 시간 간격 dt를 N개의 동일한 연성 하위 단계로 나눈다. **공기와 입자 모두 dt/N으로 계산**하며, 공기를 한 번 계산한 뒤 반작용만 나중에 얹지 않는다. N은 1–10000이다.

각 단계 시작 상태에서 같은 항력을 계산하여 입자에는 +F, 공기에는 −F를 준다. 하위 단계마다 공기 대류·점성·압력 투영과 입자 이동을 수행하고 범위를 검사한다. 외부 단계가 끝난 뒤 정수 시계를 원래 dt 기준으로 환산한다. 중간에 한 번이라도 실패하면 공기장·입자·외부 시각 전체가 이전 수락 상태로 복원된다.

시간 간격은 입자의 τ뿐 아니라 유체 반작용의 추가 교환 속도도 제한한다.

```text
β = 3πμd
m_gas_face = ρ_air dx dy D
rate = [1 + (m_particle/m_gas_face) max(ΣWu²,ΣWv²)] / τ_particle
(dt/N) rate max(1,particle_count) ≤ 0.05
```

입자 수 인자는 여러 배분 영역이 겹치는 경우를 보수적으로 제한한다. 반작용을 끈 대조 계산에서는 유체 질량 항이 0이다. 입자는 하위 단계당 최소 셀 폭의 0.1 이하로 이동해야 한다. 입자 ID 순으로 배분하여 입력 배열 순서에 따른 덧셈 순서 차이를 없앴다.

## 4. 힘 교환 수지의 의미

공기에는 힘 밀도가 아니라 **각 MAC 제어체적에 배분한 총 힘 N**을 전달한다. 열린 면·벽의 경계 속도 면에는 직접 소스를 넣지 못한다. `advance_with_source`는 예측 속도에 힘을 적용한 전후 차이로 실제 주입 충격량을 계산한다.

```text
I_particle = Σ F_drag dt_sub
I_gas = Σ m_gas_face (u_predictor_after_source − u_predictor_before_source)
exchange_error = |I_particle + I_gas|
허용 오차: 1e−20 N·s + 1e−9 |I_particle|
```

이 수지는 **항력 교환만의 수지**다. 압력 투영·점성·열린 입출구의 운동량 유출입·중력은 별도 항이다. 열린 채널의 공기+입자 전체 운동량이 일정하다고 보고하지 않는다. 반작용을 끈 대조 계산은 교환 보존을 주장하지 않으며 `reaction_enabled:false`로 표시한다.

기존 무소스 `advance`는 유지했다. 0으로 채운 소스를 넣은 결과와 기존 호출 결과가 일치하는지 시험했다.


CLI 선택 인자는 연성 하위 단계 수와 반작용 0/1이다. 출력은 새 폴더여야 하고 부모 폴더는 존재해야 한다. CLI는 기본 30 μm·1000 kg/m³ 단일 입자, 중앙 배치, 초기 속도 0, 중력 0, h=2.5 mm를 사용한다. 여러 입자·다른 h·중력은 C++ API에서 설정한다. 입력 조건에 따라 범위 검사가 거부할 수 있다.

- `input.flow`, `coupling.json`: 공기 입력과 입자·커널·연성 설정, 유한 공극률 식 미구현 표시.
- `exchange.csv`: 수락 외부 단계마다 위치·속도, 입자/기체 충격량, 해당 구간 최대 교환 잔차·체적 분율·Re·교환 시간 간격 비. 발산 열은 마지막 하위 단계 값이며 모든 하위 단계는 각각 수락 검사를 받는다.
- `volume_pressure.csv`: 마지막 수락 상태의 셀별 α, ε=1−α, 압력 게이지값.
- `air_velocity.csv`: 마지막 수락 MAC u/v 속도.
- `result.json`: 성공·실패, 마지막 수락 시각·단계 수, 체적 보존량, 최대 잔차와 반작용 활성 여부.

종료 코드 0=완료, 2=입력/파일 오류, 3=계산 실패. 계산 실패는 마지막 수락 상태를 남긴다. 파일 오류는 결과 파일 자체의 기록을 방해할 수 있으므로 종료 코드도 확인한다.

## 7. 정확도와 다음 단계의 구분

양방향 계산에서 입자 위치의 유동은 입자 자신이 만든 교란도 포함한다. 현재는 같은 커널의 필터 평균 속도로 항력을 계산하며 **교란 없는 배경 속도 복원이나 자기 교란 보정은 없다**. 고정 h의 수치 수렴이 실제 3D 구의 항력 정확도를 보장하지 않는다. 관련 원문: [Horwitz & Mani, Accurate calculation of Stokes drag for point-particle tracking in two-way coupled flows](https://arxiv.org/abs/1509.07542), [Khanwale et al., Effect of interpolation kernels and grid refinement on two way-coupled point-particle simulations](https://arxiv.org/abs/2303.17756). 이 자료를 문제 설정의 근거로 사용했으며 보정법을 구현했다고 주장하지 않는다.

조건부 확장 **25-E1**로 유한 공극률 연속·운동량식, 그 식에 일관된 압력/응력 분담, 농도 의존 항력, 자기 교란 보정 및 독립 검증을 분리한다. 현재 α 제한을 해제하는 것만으로 밀집 분말을 지원할 수 없다.

다음 **작업 26 — 단순 관로 양방향 연성 기준 시험**은 현재 희박 모델의 범위에서 시작한다. 공급·배출 경계와 커널이 만날 때 체적·힘 배분을 보존하는 처리, 입자 출입 수지와 체류시간 연결을 우선해야 한다. 이번 커널 내부 영역 검사를 우회해 관 밖 입자를 경계에 붙이는 방식은 허용하지 않는다.

기존 Unreal 소스·레벨과 PowderCore 소스는 수정하지 않았다. 이번에 변경한 공기 운동량 경로의 회귀는 독립 CMake 검사로 확인했으며 Unreal 통합 검증은 하지 않았다. 화면에 새 반작용 시각화가 나타나지는 않는다. 실제 진공·3차원 관로·밀집 분말·기존 DEM 접촉 World 연결은 별도 후속 작업이다.
