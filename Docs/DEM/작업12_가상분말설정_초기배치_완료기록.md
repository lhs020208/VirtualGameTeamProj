# 작업 12 — 가상 분말 설정과 초기 배치

상태: 완료. 작성일: 2026-10-21. 자체 DEM 작업 11에 이어 구현했다. 프로젝트 `D:/GitHub/VirtualGameTeamProj`, 브랜치 `PowderSimulation`.

## 구현한 설정

계산 코어의 `PowderSettings`를 Unreal 편집 항목과 연결했다. 설정·배치 알고리즘을 엔진 없이 시험할 수 있다.

| 항목 | 지원 내용 |
|---|---|
| 입도 | Mono: 단일 지름 / UniformNumber: 지정 지름 구간의 **개수 기준 균등 분포** |
| 밀도 | 전체 입자에 공통인 양의 밀도, kg/m³ |
| 투입량 | Count: 1~300개 / Mass: 목표 kg와 절대 허용 오차 kg |
| 시드 | 0~signed int64 최댓값, 기본 42 |
| 접촉 모델 | Linear / 기존 Hertz–Mindlin 모델 |
| 탄성 물성 | 입자와 벽의 Young 탄성계수(Pa), Poisson 비를 별도 지정 |
| 접촉 계수 | 입자–입자와 입자–벽 각각 선형 kn·cn·kt·ct·μ, Hertz 감쇠·μ·겹침 상한 |
| 초기 조건 | 생성 영역 중심·반크기, 초기 속도, 중력, 간격 계수, 벽 여유 거리, 후보 탐색 한도 |
| 시간 | 고정 물리 dt(s), 기존 안정성 제한 유지 |

UniformNumber는 질량 기준 분포, 로그정규 분포 또는 실측 입도곡선이 아니다. 지정한 지름 구간에서 각 입자의 지름을 독립적으로 뽑는다. 단일 분말군의 공통 밀도·탄성 물성을 사용하며 여러 재료군의 혼합은 이번 범위가 아니다.

선형 접촉에서는 강성·감쇠·마찰 계수를 직접 사용한다. Young/Poisson 입력은 Hertz–Mindlin 모델에 반영된다. 감쇠 계수는 Ns/m이며 반발계수가 아니다. Hertz 접선 모델과 비응집·작은 겹침 가정은 작업 06과 같다. 저장된 두 모델의 계수 모두 유효성을 검사한다.

## 입자 수와 질량의 일관성

구의 질량과 관성은 기존 구 물성 함수로 계산한다.

```text
m = ρ π d³ / 6
I = (2/5) m (d/2)²
```

Count 모드는 수량을 지정하고 총질량을 결과로 얻는다. Mass 모드는 목표 질량과 허용 오차를 지정하며 개수를 결과로 얻는다. 저장 형식에는 활성 투입 방식 하나만 기록한다. 코어는 count 모드에 별도 질량 요청이 섞이거나 mass 모드에 count가 함께 지정된 모순된 입력을 거부한다.

질량 모드에서는 시드로 정해진 지름 순서를 유지하며 입자를 하나씩 추가한다. 목표를 처음 넘는 시점에 직전/현재 접두 배치 중 질량이 더 가까운 쪽을 선택한다. 동률이면 직전 배치를 선택하고, 빈 배치는 허용하지 않는다. 300개 한도를 적용하며 최종 오차가 허용 범위 밖이면 이유와 실제 가능한 접두 질량을 알리고 실패한다.

이는 모든 입자 조합을 최적화하는 알고리즘이 아니다. 부분 입자, 마지막 입자의 지름·밀도 조절, 자동 질량 보정은 하지 않는다. 목표 질량보다 조금 많거나 적을 수 있으며 HUD의 target/delta와 초기 보고서에 요청값·실제값·오차를 남긴다. 허용 오차는 0 이상, 목표 질량보다 작아야 한다.

## 초기 배치와 재현성

알고리즘 ID는 `lattice_v1`이다. `mt19937_64` 정수 출력을 직접 매핑해 지름과 격자 순회를 만든다. 지름 생성용과 위치 생성용 난수 흐름을 분리했다. 표준 라이브러리의 구현별 `uniform_real_distribution`/`shuffle` 매핑에 의존하지 않는다.

- 실제 생성한 가장 큰 지름 × `SpacingFactor`로 축 정렬 격자 간격을 정한다. 간격 계수는 (1,10] 범위다.
- 구 전체가 생성 영역 안에 들어가는 격자만 사용한다. 시드가 정하는 시작점과 서로소 보폭으로 후보를 중복 없이 순회한다.
- 실제 구 반지름으로 입자–입자 간격을 다시 검사하고, 현재 평면·회전 상자와의 거리로 초기 벽 겹침도 거부한다.
- 단일 입자는 사용자가 지정한 생성 중심에 정확히 놓는다. 그 중심이 막혀 있으면 임의로 다른 위치로 옮기지 않고 실패한다.
- 생성 후보 한도는 기본 100,000, 최대 1,000,000이다. 전체 격자는 10¹² 셀까지만 지원한다.
- 공간 부족, 벽에 가려진 영역, 후보 한도 초과 등으로 전부 배치하지 못하면 시도 수·배치 가능했던 수와 수정할 조건을 알린다. **부분 배치를 실행 상태로 제출하지 않는다.**

격자 배치 실패가 모든 가능한 치밀 배치의 수학적 불가능성을 뜻하지 않는다. 큰 입자에 맞춘 간격이 작은 입자에도 적용되므로 다분산 고밀도 충전에 최적인 방법은 아니다. 무작위 조밀 충전이나 안정 퇴적 상태 생성 기능도 아니다.

같은 설정·시드·형상·알고리즘·빌드 환경에서 초기 ID/지름/위치를 재현한다. 설정 파일에는 레벨 형상이나 접촉 이력, 진행 중 상태를 저장하지 않으므로 형상이 달라지면 같은 파일이어도 배치가 달라지거나 실패할 수 있다. 서로 다른 모든 컴파일러·플랫폼의 비트 동일성까지 검증한 것은 아니다.

초기화와 배치 생성은 계산 스레드에서 한다. 후보 탐색 중 128회마다 종료/새 실행 요청을 확인한다. 새 실행 세대와 과거 결과는 섞이지 않는다. 잘못된 dt는 기존 코어 검증에서 거부하며 계산 속도를 위해 자동 확대하지 않는다.

## 입자와 벽 접촉의 분리

`ParticleSystem.model`은 입자–입자 모델이고 `wall_model`은 선택적 벽 모델이다. 기존 호출부는 `wall_model`이 없으면 이전처럼 공통 모델을 사용한다.

새 설정에서는 입자–입자 Hertz 유효 물성을 **입자/입자**, 입자–벽 물성을 **입자/벽**으로 만든다. 벽 탄성계수를 바꾸어도 입자끼리의 유효 물성이 바뀌지 않는다. 선형 계수·감쇠·마찰·Hertz 겹침 상한도 접촉 종류별로 적용한다. 시간 간격 제한은 두 접촉 모델을 모두 고려해 보수적으로 정한다.

벽 밀도는 추가하지 않았다. 현재 벽은 무한 질량의 정적 경계이며 벽의 질량·관성 운동을 풀지 않기 때문이다. 여러 벽 재료를 액터별로 지정하는 기능은 아직 없고 하나의 벽 재료를 공통 적용한다.

## Unreal 사용법과 저장 형식

Play 중 생성된 `PowderDEMTest` 액터의 Details에서 설정을 편집한다. 수량/질량 모드와 단일/분포 모드에 맞는 항목을 선택하고 뷰포트로 돌아와 R을 누르면 적용된다. Blueprint에서도 동일한 속성과 함수에 접근할 수 있다.

- **R:** 현재 편집 설정으로 새 배치 생성·초기화.
- **K:** 현재 편집 설정 저장. 시뮬레이션을 초기화하지 않는다.
- **L:** 파일을 검증해 불러오고 새 배치로 초기화.
- **Space / N:** 실행·일시정지 / 한 물리 단계. 기존 카메라 조작 유지.

기본 저장 위치는 `Saved/DEM/PowderSettings.dem`이다. `SettingsFile`에 다른 단순 `.dem` 파일명을 지정할 수 있다. 경로 이동 문자열은 거부한다. 파일은 버전 1의 UTF-8 텍스트이고 SI 단위·분포·활성 투입 방식·시드·배치 알고리즘·입자/벽 계수·생성 영역·초기 속도·중력·dt를 포함한다. 17자리 숫자 정밀도와 고정 숫자 로케일로 기록한다.

키 순서·버전·값·크기를 검사하며 알 수 없는/중복된/잘린 내용은 거부한다. 잘못된 파일을 불러오면 현재 편집값과 실행을 유지한다. 유효한 파일이어도 현재 시험장에 배치할 수 없다면 새 실행의 초기화 오류가 된다. 오류는 HUD와 Details의 Error/SettingsStatus에서 확인한다.

저장 시 입력을 먼저 검증하고 임시 파일을 쓴 뒤 교체한다. 유효하지 않은 설정으로 저장을 시도해도 기존 파일을 덮어쓰지 않는다. 디스크 실패·운영체제 장애까지 모든 경우의 트랜잭션 보장을 주장하지 않는다. 설정 파일은 실행 재개용 체크포인트가 아니다. Saved 경로는 Git에서 제외되므로 협업자가 사용할 파일은 별도로 공유하거나 추적되는 문서/프리셋 폴더에 복사해야 한다.

## 기본 배치 변경

기본 300개, 지름 0.04m, 밀도 2500kg/m³, dt=2e-7s는 유지했다. 초기 중심은 (0,0,485)cm, 생성 반크기는 (18.5,18.5,35)cm이다. 기존의 고정 5×5×12 배열 대신 시드가 있는 격자 순회를 사용한다. 생성 중심은 이전 코드의 첫 입자 높이와 의미가 다르다. 새 기본 영역은 공급통 안에 들어가며 0.03~0.05m 균등 분포 300개도 배치할 수 있다.
