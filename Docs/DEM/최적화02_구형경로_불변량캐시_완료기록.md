# 최적화 02 — 구형 입자 전용 경로·불변량 캐시 완료 기록

- 완료일: 2026-10-22
- 브랜치: `PowderSimulationOptimization`
- 범위: 동일 물리식의 CPU 구현 최적화. 시간 간격·물성·회전·접촉 모델·안정성 제한은 유지.
- 다음 작업: 최적화 03 — 접촉 후보 및 적분 후 겹침 검사의 공간 탐색화.

## 구현

1. `ClumpWorld`에서 원점에 정확히 중심을 둔 단일 구를 자동 판별한다. 구의 등방성 관성을 이용해 `ω = I⁻¹L`을 계산하고, 중간 각운동량으로 자세를 적분한다. 일반 관성 텐서 회전·중점 반복을 생략하며 회전 자체는 유지한다. 구형 구성 입자는 COM 위치·속도를 직접 사용하고 추가 지렛팔 토크가 없는 힘/토크 전달을 사용한다.
2. 질량·관성·역관성·경계 반경은 몸체 ID별로 최초 사용 시 검증·계산해 재사용한다. 일반 비구형도 같은 불변량을 재사용하되 기존 관성 텐서 및 중점 회전 적분을 유지한다. 공개 독립 함수의 기존 경로는 유지한다.
3. 활성 재료 종류와 접촉 재료 표를 검증한 스냅샷을 저장한다. 변경이 없으면 매 스텝 입자 수의 제곱만큼 수행하던 재료 검증을 반복하지 않는다. 접촉 힘 평가 내부의 기존 안전 검증은 유지한다.
4. `use_cached_sphere_path` 기본값은 true이며 Unreal의 Clump/Mesh/Paddle/Mixing 경로에도 적용된다. false는 기존 계산 비교용이다. 물리 캐시와 별도로 선택적 계측에 재계산·재사용·전용/일반 적분 횟수를 추가했다.

## 캐시 갱신·안전 조건

| 변경 | 처리 |
|---|---|
| 밀도·구 직경·구의 로컬 위치·구 개수 | 필드 단위 정확 비교 후 해당 몸체 불변량 재계산 |
| ID 추가·삭제·재정렬 | ID별 조회, 삭제 항목 정리, 새 ID 검증·계산 |
| 활성 타입·재료 표 키·모든 재료 필드 | 활성 타입 간 필요한 모델 존재 확인 및 재검증 |
| 위치·속도·각운동량·자세 | 캐시하지 않고 매 스텝 유한값·정규화 검증 |
| 명시적 초기화 | `invalidate_caches()`로 전부 무효화 |
| 월드 복사·실패한 스텝 | 캐시는 값 복사. 실패 시 위치·속도·접촉 이력·시계는 커밋하지 않음 |

해시 충돌이나 구조체 패딩 비교에 의존하지 않는다. 단일 구라도 로컬 중심이 정확히 0이 아니면 일반 경로로 처리한다. 설정을 바꾼 실험은 기존 사용법대로 Reset으로 새 실험을 시작한다. 캐시 무효화 자체는 접촉 이력을 임의 삭제하지 않는다.

## 검증

- 고정 오차 계약: `abs(a-b) <= 1e-12 + 1e-9 * max(abs(a),abs(b))`. 물리량은 SI, 자세는 무차원. 이산 접촉/스텝/도착/이력 개수는 정확 일치. 결과에 맞춘 허용치 완화 없음.
- 코어 전체 22개 통과, 최종 빌드의 최적화 관련 3개 재실행도 통과.
- 새 전용 테스트: 낙하·입자 쌍·평면·박스·Hertz·구름 마찰·부착·가동 벽·비구형 7조건, 각 4,000스텝에서 상태·에너지·접촉·벽 힘/토크/일을 기존 경로와 비교.
- 크기/밀도/형상/타입/재료 수정, 추가/삭제/재정렬, 복사, 명시 무효화, 잘못된 입력 및 dt 실패 원자성 시험 통과.
- 동일 입력 기준/최적화 각각 3회 비계측 교대 실행 + 각각 1회 계측 실행. 상태·질량·배출/체류·혼합·토크 등의 CSV 비교 통과. 각 경로 내 반복/계측 on/off 물리 CSV는 바이트 일치.
- 보관된 최적화 01 기준 물리 CSV와 이번 reference 경로도 바이트 일치.
- Unreal Editor Win64 Development 재빌드 성공, `Powder.DEM.*` 13개 자동화 테스트 통과. NullRHI 검증이며 GPU 렌더 성능 측정은 아님.

## 성능

## 남은 제한

- **대량 분말 0.1배속 목표 미달성.** 300몸체/1024구 제한과 접촉/적분 후 전수 쌍 검사는 그대로다.
- 최적화 01의 30 RPM 혼합 시험은 여전히 겹침 5% 기준 부적합 진단 사례다. 최적화로 정확해진 사례로 취급하지 않는다.
- mm 시험은 반지름 1mm·밀도 1500kg/m³·dt=2e-8초이며 기존 20mm 시험과 물성이 다르다. 서로의 배속 차이를 최적화 효과로 해석하지 않는다. 같은 행의 전후만 비교한다.
- 재료 표 반복 검증 제거는 이번 불변량 캐시 범위에서 수행했다. 최적화 03에서는 남은 거리 검사·접촉 후보·적분 후 검사 및 ID 탐색 비용을 다룬다.
- 커밋·푸시는 수행하지 않았다.
