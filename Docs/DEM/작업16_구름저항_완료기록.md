# 작업 16 — 구름 저항

상태: 완료 (2026-10-21). PowderCore 0.16.0, 설정 형식 POWDER_SETTINGS 3.

## 구현 범위

접촉 이력 기반 spring–dashpot–slider(SDS) 구름 저항을 자체 C++ 계산 코어에 추가했다. 구–구, 구–평면, 기본도형 상자 접촉 모두에 적용한다. 선형 및 Hertz–Mindlin 수직 접촉 모델과 함께 사용할 수 있다. 기존 접선 마찰과 별도 계수이며, 공중 회전 전체에 적용하는 회전 감쇠가 아니다. Chaos의 Angular Damping 설정은 이 계산에 사용하지 않는다.

입자 간과 벽 접촉의 stiffness(N/m), damping(N·s/m), friction(무차원)을 독립적으로 지정한다. 기본값은 1000, 1, 0이며 **friction=0이면 구름 저항 꺼짐**이다. 검증용 계수는 가상 재료 값이며 실제 분말 보정값이 아니다.

## 모델 계약

접촉 법선 n에 대해 상대 각속도의 접선 성분 Ωt를 사용한다. 유효 반지름 R은 구–구에서 RaRb/(Ra+Rb), 고정 벽에서 입자 반지름이다. 이력 ξ는 RΩt를 시간 적분한 길이 단위 벡터이다. 접촉 프레임이 회전하면 이력도 운반하고 법선 성분을 제거한다.

- 시험 토크: Mtrial = −R(kξ + cRΩt).
- 토크 크기 상한: μr Fn R. Fn은 현재 계산된 비음수 수직력으로, 수직 감쇠 성분도 포함한다.
- 상한을 넘으면 토크를 제한하고 스프링 이력을 다시 맞춘다.
- 구–구에 크기가 같고 방향이 반대인 토크를 적용한다. 추가 병진 힘은 없다.
- 접촉이 끊기거나 계수가 0이면 구름 이력을 제거한다. 설정 변경은 Reset으로 접촉 이력을 초기화한다.
- 법선축 비틀림 저항은 제외한다. 기하학적 비구형 입자 모델도 아니다.

참조: [LAMMPS 공식 granular rolling SDS 문서](https://docs.lammps.org/stable/pair_granular.html). 모델 구조와 프레임 운반을 참고했으며 외부 해석기를 실행하거나 연동하지 않았다. 구현은 각변위 방향의 길이 이력으로 표현하고 위 수직력 정의를 사용한다.

개별 접촉 및 다중 접촉에서 구름 강성·감쇠·유효 관성을 반영한 dt 상한을 검사한다. 다중 접촉에서는 최대 접촉 수와 보수적인 반지름·질량 경계를 사용한다. 초과 시 부분 상태를 반영하지 않고 오류를 반환한다. 작은 dt가 모든 비선형 조건의 정확도를 보장하는 것은 아니다.

## 언리얼 사용

1. PowderDEMTest 액터의 Details → DEM → PairRolling / WallRolling에서 값을 지정한다. 런타임 생성 액터라면 플레이 중 선택한다.
2. PairRollingFriction / WallRollingFriction을 0보다 크게 설정한다. 검증에 쓴 0.2는 예제이며 보정값이 아니다.
3. ResetSimulation으로 새 설정을 적용한다. 기존 K 저장 / L 불러오기 및 O 결과 내보내기에 계수가 포함된다.
4. 이전 v1/v2 설정 파일은 구름 저항이 꺼진 상태로 읽는다. v3는 입자·벽의 세 계수를 모두 기록한다.

에디터의 시험장 형상은 변경하지 않았다. 작은 dt 때문에 육안으로 변화가 느린 문제는 이번 물리 모델 추가와 별개이다.

- 구름 토크 방향·한계, 구–구 작용 반작용, 같은 각속도, 순수 비틀림 제외, 비접촉 회전 유지, 이력 회전·삭제, Hertz 연결, 잘못된 계수·dt의 원자적 거부 확인.
- 고정 중심 회전 진동자: I=0.1 kg·m², K=kR²=250 N·m/rad, 무감쇠. 해석해와 비교해 dt=1e-5→5e-6 s에서 각속도 오차가 약 절반, 스프링 포함 에너지 상대 오차 <0.001.
- 경사면 상당 중력: 경사 0.1 rad, 1 kg·지름 1 m 구, k=1000 N/m, c=80 N·s/m, 2초 계산. 저항 μ=0일 때 이동 1.39757 m·속도 1.39753 m/s. μ=0.2일 때 이동 0.00136729 m·속도 약 7.49e-15 m/s. dt 반감 위치 차이 <1e-4 m. 정지 허용 기준은 속도 <0.001 m/s·이동 <0.01 m였다.
- 6구 삼각 더미, 2초: μ=0의 최대 수평 반폭 2.82295 m·잔류 운동에너지 5.98424 J, μ=0.2의 반폭 1.00462 m·운동에너지 약 1.23e-12 J. 잔류 에너지 <0.01 J 및 꺼짐 대비 감소 기준 통과. 병진·회전 운동에너지와 중력 위치에너지의 합은 초기값+0.03 J를 넘지 않았다. 이 더미 지표에는 접촉 스프링 에너지가 포함되지 않으므로 완전한 에너지 수지 검사로 해석하지 않는다.
- 낮은 감쇠 c=4에서는 2초 뒤 작은 진동이 남는 것을 확인했다. 정지 기준을 완화하지 않고 c=80으로 명시한 감쇠 조건을 검증했다. 모든 c에서 2초 내 정지를 보장하지 않는다.
- 언리얼 새 시험은 계수 저장·복원과 내보낸 v3 설정을 검사한다. 실제 토크·운동 검증은 같은 코어를 쓰는 독립 C++ 시험에서 수행한다.
