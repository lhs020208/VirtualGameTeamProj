# 생성기·데이터 에셋 통합 검증 결과

2026-10-27 / PowderEmitterIntegration

## 완료 범위
입자 설정 에셋·격자/명시 좌표 생성기를 현재 GPU 근사 해석기에 연결했다. CPU DEMWorld/해석기는 가져오지 않았다. 생성기별 표시, 소유권, 재생/Reset, 초기 배치 충돌 검사를 포함한다. 사용법은 ../PowderEmitterIntegration_사용법.md를 참조한다.

## 성능
RTX 4060 Ti / i7-14700KF / RAM 32GB, 1280×720, 30FPS 상한, 50,000개 모두 표시, dt=0.000375s, 16회 반복, 32-step 배치. 요청 배속 2. 초기화/로딩을 제외한 운전 중 평균이다. 실행은 순차로 진행했고 성능 측정 중 다른 DEM 실행/빌드/전체 회귀 검사를 병행하지 않았다.

| 조건 | 해석시간 | 평균 배속 | 해당 해석시간의 운전 실시간 |
|---|---:|---:|---:|
| 기존 자동 배치 | 12.009s | 0.1954배 | 61.5s |
| 생성기 연결 | 12.009s | 0.1956배 | 61.4s |
| 생성기 연결 연장 | 30.008s | 0.1608배 | 186.6s |

각 조건 1회 측정이며 통계적 속도 우열을 주장하지 않는다. 12초 조건은 사실상 같은 수준이고 30초 평균은 접촉 상태 변화로 낮아졌다. 이번 5만 대표 입자·닫힌 혼합 시험에서 0.1배속 목표를 통과했다. 더 큰 입자 수/실제 미세 입자 전체 공정 성능은 보장하지 않는다.

기존 표시용 SM_GrainSphere가 생성기의 구 외곽 치수 검사를 통과하지 않아 연결 버전은 SM_DEMSphere를 사용한다. 물리 구 반지름·초기 좌표·그룹·시간 간격은 같다. 표시 메시가 다르므로 이 비교는 전체 사용 경로의 처리량 비교다.

## 수치 검사
세 실행 모두 5만 개, 빨강/파랑 각 25,000개, 약 64.8kg을 유지했다. 초기 위치/그룹은 기준 파일과 바이트 단위로 일치한다. 이후 GPU 이웃 삽입 순서와 기록 시점 차이로 최종 개별 궤적의 비트 일치는 요구하지 않는다.

| 조건 | 최종 저장 상태 시간 | 최대 겹침/반지름 | 용기 침범(mm) | 회전부 침범(mm) |
|---|---:|---:|---:|---:|
| baseline12 | 11.997s | 0.03615 | 0.000047 | 0.000043 |
| integrated12 | 11.973s | 0.07078 | 0.000043 | 0.000030 |
| integrated30 | 29.876s | 0.06181 | 0.000052 | 0.000036 |

잠정 기준: 최종 저장 상태 겹침/반지름 ≤0.1, 용기/회전부 침범 ≤0.1mm. 모든 시간 단계의 최대 침범을 증명하는 검사는 아니다. 실제 물성 실험과 대조한 물리 정확도 인증도 아니다. 혼합 지표는 현재 공간 bin 기준의 진단값이며 제품 혼합 품질을 인증하지 않는다.

## 구현·회귀 검증
- 외부 초기 상태가 기존 자동 생성에 의존하지 않고 GPU 버퍼에 전달된다.
- 이동/회전 좌표 및 선속도, 자유낙하, 그룹 유지, 초기 정지, 반복 Reset, 중복 생성기/겹침/혼합 밀도 거부, 소유권, 변경/삭제 정지를 자동화 검사한다.
- 기존 코어 회귀는 ctest.log, Unreal 회귀는 tests/index.json, 설정·미리보기 검증은 앞 단계 verification.json에 보관한다.
- 검증 스크립트는 Scripts/audit_emitter_integration06.py, Scripts/run_emitter_integration06.py이다.
- 화면 mix.png는 실제 GPU 시뮬레이션 중 캡처다. 파일 이름 discharge.png도 MX301에서는 닫힌 혼합 시험 10초 시점의 캡처이며 배출 시험이 아니다.

## 남은 범위
연속 투입, 서로 다른 물성/입경 혼합, GPU 강성·감쇠·입자 회전 모델, 실제 공정 전체 검증은 이번 통합 범위 밖이다. teamproj3.blend는 비최종 테스트 형상으로만 사용한다. 현재 충전량은 혼합기 반 충전 조건이 아니다.
