# 작업 18 — 비구형 입자와 이물질

상태: 완료 (2026-10-21). PowderCore 0.18.0.

## 이번 구현 경계

첫 비구형 표현인 강체 구 집합(clump)을 계산 코어에 추가하고 전용 언리얼 시험 레벨 **/Game/L_ClumpTest**를 만들었다. 기본 실험은 구형 분말 3개와 두 구를 묶은 이물질 3개, 총 **6개 강체 / 9개 구성 구**다. 이물질의 형상·질량·관성·접촉 물성이 실제 계산에 반영되며 색상만 구분한 입자가 아니다.

기존 L_Main과 구형 분말 해석 경로는 그대로 유지했다. 비구형 모드는 별도의 ClumpWorld/APowderClumpTest 경로다. 기존 300개 입자의 공급·배출 추적·체류시간·작업 14 비교 파일에 구성 구를 개별 입자로 섞지 않는다. 이 계층들과 강체 ID를 기준으로 통합하는 것은 후속 연결 작업이며, 이번에 완료했다고 표시하지 않는다.

## 질량과 관성 계약

구성 구는 균일한 강체 밀도를 공유하는 구이며, 1개부터 32개까지 지원한다. 첫 구현은 **겹치지 않는 구**만 허용한다. 접하거나 떨어져 있는 구 사이에는 질량 없는 강체 연결을 가정한다. 구 중첩의 합집합 체적/관성은 아직 지원하지 않으므로 중첩 입력을 거부한다(부동소수점 기하 허용오차는 지름의 1e-12).

질량 M=Σmi, 무게중심 c=Σmi ri/M. 각 구의 자체 관성에 평행축 항 mi[(di·di)1−di diᵀ]을 더해 **전체 3×3 관성 텐서**를 만든다. 대각항만 사용하는 근사가 아니다. 생성 시 구성 구 좌표를 무게중심 기준으로 옮긴다.

참고: [Yade 공식 DEM formulation의 clumps](https://yade-dem.org/doc/formulation.html?highlight=damping), [Rigid clumps 논문](https://doi.org/10.1016/j.cpc.2023.109034). 구 집합과 질량·관성 정의를 참고했고 외부 해석기를 실행하지 않았다.

## 운동·접촉

- 자유도는 몸체의 무게중심 위치·병진 속도·자세 quaternion·세계 좌표 각운동량이다. 구성 구는 독립적으로 적분하지 않는다.
- 구성 구의 위치/속도는 몸체 자세와 `vCOM + ω×r`로 계산한다. 몸체 내부의 구 쌍은 접촉 탐색에서 제외한다.
- 외부 구 접촉력과 구 중심 토크에 `rCOM×F`를 더해 몸체에 합산한다. 구–구·평면·정적 상자 접촉은 기존 선형/Hertz, 접선 마찰, 구름 저항, 접촉 응집 평가 함수를 재사용한다.
- 각운동량은 외부 토크로 갱신하고 세계 좌표 관성으로 각속도를 복원한다. 자세는 중간점 각속도를 반복 계산해 quaternion 지수 회전으로 갱신한다. 비대칭 회전에 필요한 관성 방향 변화를 포함한다.
- 다중 접촉 수·접촉 강성·감쇠·몸체 관성에 따른 보수적 dt 검사, 각도 한 단계 0.05 rad 제한, 구성 구 이동 0.1×최소 반지름 제한, Hertz 겹침 제한을 적용한다. 실패 시 몸체와 접촉 이력을 부분 반영하지 않는다.
- 현재 탐색은 단순 전수 비교다. 최대 300개 몸체/1024개 구성 구 입력 제한은 정확도·성능 보증이 아니다. 검증한 실험 규모는 아래에 명시했다.

## 재료·형상 구분

기본 시험의 구 지름은 0.04 m다. 분말 type 0은 단일 구·밀도 2500 kg/m³, 이물질 type 1은 접하는 두 구·밀도 7800 kg/m³이다. 이는 가상 검증값이며 실물 원료를 보정한 값이 아니다. 같은 구성 구 크기에서 이물질 질량은 분말의 6.24배다.

입자 종류 쌍별 MaterialContact 표와 벽 접촉 표를 명시적으로 지정한다. 기본 선형 강성은 분말–분말 10000, 혼합 14000, 이물질–이물질 20000 N/m이며 자동 재료 혼합 법칙으로 해석하지 않는다. Hertz 선택 시 종류별 Young 계수를 접촉 식에 전달한다. 밀도·강성·Hertz 여부·Young 계수·구름 저항·응집 계수는 시험 액터 Details에서 조절하고 R/Reset으로 적용한다. 형상 배열은 코어 API로 지정하며 현재 에디터 시험 액터의 두 형상·개수는 고정 fixture다.

## 언리얼 사용

1. Content의 **L_ClumpTest**를 열고 Play한다. 기존 카메라의 우클릭+WASD 이동을 사용한다.
2. **Space** 실행/일시정지, **N** 고정 dt 한 단계, **R** 초기화, **O** 일시정지 상태 저장.
3. Details의 Clump|Materials에서 값을 변경한 뒤 ResetSimulation으로 반영한다.

기본 dt는 2e-6 s이며 기본 StepsPerFrame=200이다. Tick은 최대 단계 수와 약 4 ms 작업 예산으로 계산량을 제한할 뿐, 렌더 프레임 시간으로 물리 dt를 바꾸지 않는다. 4 ms는 반복 시작/종료 검사 예산이며 한 단계의 실행 시간까지 강제로 중단하는 실시간 보장은 아니다. 전용 소규모 시험은 메인 스레드에서 계산하며 기존 300구 Worker와 분리돼 있다.

에디터에서도 초기 구성 구가 보이며 Play 후 처음에는 일시정지 상태다. 시험장 액터는 위치 이동만 지원한다. 회전·스케일 변경은 계산/표시 형상을 다르게 만들지 않도록 거부한다. 카메라와 조명은 표시용이며 Chaos로 몸체를 계산하지 않는다.

O 저장 경로: `Saved/DEM/Clumps/<GUID>/`. `bodies.csv`는 강체 ID·종류·질량·관성·COM 상태, `pebbles.csv`는 구성 구의 몸체 내 좌표·지름, `configuration.txt`는 적용된 fixture 버전·물성·dt·step·시간, `complete.json`은 완료 표식이다. 위치는 시험장 원점을 기준으로 한 SI 값이다. 저장된 상태는 현재 진단 출력이며 접촉 이력까지 포함한 재시작 체크포인트나 기존 구형 결과 비교 형식이 아니다.

## 검증 결과

- 코어 **16개 × 2회**, Unreal **8개 × 2회**, CLI/결과 검사 4묶음 × 2회 통과.
- 기존 42조건 × 2회 통과. 작업 17 CSV와 측정 시간 외 모든 수치·최종 상태가 정확히 일치했다.
- 각 1 kg·지름 1 m인 두 구에서 M=2 kg, COM 및 Ixx=0.2, Iyy=0.7 kg·m² 검증(허용 1e-12). 기울어진 구 배열의 비대각 Ixy=−0.25도 검증했다.
- 중첩 구 거부, 내부 자기 접촉 제외, 강체 구성 구 간 거리 유지(<1e-12 m), 외력에 따른 COM 가속과 토크에 따른 각속도(<1e-10) 확인.
- 자유 회전 대칭 몸체의 에너지 오차는 dt=0.002/0.001 s 모두 약 1.39e-16 J로 반올림 수준이었다. 이 값으로 오차 차수를 주장하지 않는다. 수렴 검사의 수치 바닥은 1e-12 J로 정의했다.
- 비대칭 3구 몸체의 1초 회전(dt=0.001 s) 최대 에너지 오차 **5.52343e-10 J**, 기준 <1e-7 J 통과. 무토크 세계 좌표 각운동량 보존도 검사했다.
- 단일 구 강체는 기존 구형 계산의 위치·속도와 <1e-14 차이. 한 구성 구의 바닥 접촉이 COM 토크를 만드는지 확인했다.
- 서로 다른 강체 접촉에서 선운동량 <1e-12, 스핀+궤도 각운동량 <1e-10 오차. 종류 간 강성을 2배로 바꾸면 시험 충격량도 2배가 됨을 확인했다.
- 구형/두 구 이물질 2몸체의 0.05초 낙하·상자 바닥 충돌(dt=2e-6 s)에서 총 질량 **0.606537 kg** 보존(<1e-12). 최종 COM z는 약 0.0211297/0.0246900 m, 바닥 관통 없음.
- 큰 dt 거부 시 몸체 상태 불변. Unreal에서는 6몸체/9인스턴스 표시, 한 단계의 실제 시간/낙하, 물성 Reset, 상태 출력, 실행 중 출력 거부, 잘못된 dt 초기화 시 오류를 검사했다.

이번 강체 검증의 외부 충돌 정량 시험은 선형 접촉 중심이다. Hertz·구름·응집의 모든 비구형 조합, 실제 원료 형상, 대규모 장시간 퇴적, 겹친 구성 구 합집합, 파손·유연한 입자는 검증 범위 밖이다.
