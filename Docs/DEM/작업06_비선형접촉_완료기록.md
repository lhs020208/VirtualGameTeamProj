## 모델 정의

SI 단위. 유효 Young 계수는 `1/E*=(1-νa²)/Ea+(1-νb²)/Eb`, 전단계수는 `Gi=Ei/[2(1+νi)]`, `1/G*=(2-νa)/Ga+(2-νb)/Gb`.

유효 반지름은 두 구에 대해 `RaRb/(Ra+Rb)`, 평면에 대해 구의 반지름이다. 평면은 움직이지 않지만 지정한 벽 재료의 유한 탄성을 사용한다.

- Hertz 법선 탄성력: `(4/3)E*√R* δ^(3/2)`.
- 법선 미분 강성: `2E*√(R*δ)`.
- 법선 저장 에너지: `(2/5)Fel δ`.
- 접선 강성: `8G*√(R*δ)`.
- 접선은 작업 05의 변위 이력·쿨롱 한계에 현재 접촉 반경의 강성을 적용한다.
- 법선 감쇠는 압축 시 `cn × 압축속도`, 접선 감쇠는 `ct × 미끄럼속도`. cn·ct는 Ns/m 단위 상수이며 목표 반발계수가 아니다.

접선은 Mindlin no-slip 강성을 이용한 단순화 이력 모델이다. 전체 Mindlin-Deresiewicz 부분 미끄럼·하중 반전 이력 모델을 구현했다고 표현하지 않는다. 모델·물성 변경 시 이력을 초기화해야 한다.

근거: https://docs.lammps.org/stable/pair_granular.html 의 Hertz/material 및 Mindlin 정의. 외부 해석기를 실행하거나 해당 구현 코드를 사용하지 않았다.

## 안정성 및 범위 제한

겹침 상한은 기본적으로 작은 반지름의 1%, 설정 가능한 최대값은 5%다. 이는 모델·수치 범위 보호이며 이 범위의 모든 재료에 Hertz가 정확하다는 의미는 아니다.

현재 및 적분 후 겹침을 검사하고 초과 시 상태·힘·이력을 갱신하지 않는다. 시간 간격은 겹침 상한에서의 최대 미분 강성·접선강성과 회전 관성을 기준으로 제한한다. 자동 시간 간격 조절은 아직 없다.

## 사전 검증 기준

- 유효 E/G 기준값 절대오차 1e-8Pa, 힘·강성 배율 오차 1e-12.
- 힘 및 에너지 수치 미분 상대비 오차 1e-9.
- 무감쇠 반발계수 오차 1e-5, 최대 겹침 오차 1e-8m, 접촉시간 오차 2e-6s.
- 시간 간격 축소 시 무감쇠 반발계수 오차 감소.
- 감쇠 충돌은 더 미세한 계산을 기준으로 수렴 확인. 이를 독립 실험 검증으로 취급하지 않는다.
- 기존 선형 모델 선택이 직접 호출과 일치하고, 물성·겹침 오류를 거부.

최대 겹침 기준은 초기 운동에너지와 Hertz 저장 에너지의 일치로 도출했다. 접촉시간은 에너지식의 시간 적분을 베타 함수로 평가했다.

무감쇠 반발계수 오차: dt=2e-6s에서 4.24376089825e-11, dt=2e-7s에서 1.73998593311e-11. 이미 매우 작은 오차 영역이므로 일반적인 수렴 차수를 이 두 값만으로 주장하지 않는다.

cn=20Ns/m 감쇠 시험 반발계수:

- dt=2e-6s: 0.943358194107
- dt=2e-7s: 0.94335009328
- 기준 dt=5e-8s: 0.943349418313

힘–변형의 3/2승 관계, 에너지 미분, Mindlin 강성의 √δ 관계, 평면·두 구의 실제 힘 연결, 선형 선택, 물성 오류, 큰 겹침의 원자적 거부를 검증했다.

Release 빌드 및 CTest 5개 대상과 기존 Python CLI·운동·평면 회귀 검사를 통과했다.

## 발견한 문제와 수정

첫 검증에서 가장 미세한 dt의 충돌이 종료되지 않았다는 실패가 발생했다. 시험이 100000step으로 고정되어 dt=5e-8s에서는 0.005초만 실행되어 접촉시간보다 짧았다. 최대 실행 범위를 모든 dt에서 동일한 물리 시간 0.05초로 변경하고 재검증했다. 허용 오차와 해석 기준값은 변경하지 않았다.
