## 측정 영역·표본 정의

영역은 액터 원점 기준 SI 좌표 `x,y∈[-0.3,0.3] m`, `z∈[0,0.3] m`이다. 기본 2×2×1로 분할한다. 하한을 포함하며, 내부 경계는 높은 인덱스 격자에 넣고 최상단 경계는 마지막 격자에 포함한다.

강체의 **질량중심(COM)**이 속한 격자에 그 강체의 전체 질량을 한 번 넣는다. 그룹은 고정 body ID에 연결한다. 다중 구 clump를 지표 API에 넣어도 표시 구 수만큼 중복 계수하지 않는다. 다만 이번 레벨의 충전 생성기는 단일 구만 만든다. 격자에 걸친 강체의 실제 부피를 분할하는 방법은 아니다.

각 시각/격자에서 A/B 개수·질량·A 질량분율을 저장한다. 빈 격자도 0개/0질량으로 기록하되 질량분율은 빈 칸이다. 빈 격자를 완전 혼합 표본으로 세지 않는다. 영역 밖 강체 개수와 그룹별 질량을 따로 집계한다. 전체 A/B 개수와 질량은 초기값과 비교하며 변하면 오류로 중지한다.

## 지표 정의

이름: **질량 가중 격자 균일도**, `mass_weighted_cell_uniformity_v1`.

```text
M_A, M_B = 전체 그룹 질량
M = M_A + M_B
c = M_A / M
m_i = 격자 i의 A+B 질량
c_i = 격자 i의 A 질량 / m_i          (점유 격자만)
V = Σ_i (m_i/M) (c_i-c)²
U = 1 - V / [c(1-c)]
```

완전히 분리된 점유 격자들은 U=0, 각 격자의 질량분율이 전체와 같으면 U=1이다. 부동소수점 오차에 대해 [0,1]로 제한한다. 실제 무작위 혼합의 유한 표본 분산을 보정하지 않으므로 **Lacey 지수라고 부르지 않는다**. 임의 난수 배치가 U=1이어야 한다는 뜻도 아니다.

유효 조건은 A/B 질량이 모두 양수, 점유 격자가 2개 이상, 모든 점유 격자에 최소 표본 수 충족, 영역 밖 강체 0개다. 실패 시 `outside_region`, `missing_group`, `insufficient_occupied_cells`, `undersampled_cells` 중 원인을 표시하고 지수 칸을 비워 N/A로 기록한다. 표본 부족 격자를 제거해 점수를 높이지 않는다. 격자 크기·방향·영역·충전량에 의존하는 지표이므로 서로 다른 측정 계약을 같은 숫자로 비교하지 않는다.

문헌의 분산 기반 혼합지표도 표본 구획/표본 크기 의존성을 갖는다. 이번 구현은 위 식을 명시한 자체 균일도이며, 실제 제품 균질성·제정 성능·품질 기준으로 보정하지 않았다. 참고: [DEM investigation of mixing indices in a ribbon mixer](https://www.sciencedirect.com/science/article/pii/S1674200121000614), [분산 기반 지표의 방향별 표본 추출 연구](https://www.sciencedirect.com/science/article/pii/S003259102101069X).
