## 유한 작업 단위 (각 작업은 구현+검증+수정 포함)

1. 요구사항 대응표/가정 확정 및 현재 경로 보존.
2. 기존 ClumpWorld에 외력·토크 입력과 회귀 검증 추가.
3. 3D 등온 가스 유한체적 기준 계산: 유한 공극률·질량·압력/벽 경계·보존·안정성 거부.
4. 입자 부피 매핑/가스 속도 수집/항력·압력 힘/동일 반작용을 기존 접촉 해석기와 연결.
5. 가상 입도/비구형 이물/응집·벽부착 및 공급·배출 장부 연결.
6. 정지/압력 반전/퇴적/개구 차단/부착 이탈/시간간격·격자 민감도 시험. 실패는 수정 후 재검사.
7. Unreal 실시간 관찰 액터: 별도 작업 스레드, SI 설정, 실행/정지/Reset, 결과 내보내기.
8. 새로운 기본형 시험 레벨과 실행 스크립트. 기계 모델을 새로 제작하지 않음.
9. 기존 GPU 5만 개와 CPU 접촉/응집/혼합 회귀, 신규 경로 실제 성능/보존 계측.
10. 요구사항 재대조, 빠진 필수 연결 보완, 완료/검증/미검증/근사와 실행 방법 기록.

## 합격 기준과 제한

- 양방향 연성은 동일 시각 입자 힘과 반대 가스 힘을 사용하고 교환 오차를 기록한다. 가스/입자 질량은 경계 통과 장부와 맞아야 한다.
- 공극률·CFL·접촉 시간간격 또는 비유한값 실패를 숨기거나 잘라내지 않는다. 실패 상태에서 재생을 계속하지 않는다.
- 직교 격자 가상 유로, 구/비중첩 구 묶음, 등온 저속 가스로 시작한다. 압력/온도/마찰/응집 값은 가상값이며 실제 약품 보정이 아니다.
- 새 CPU 연성 경로의 성능은 따로 실측한다. 기존 GPU 5만 개 0.2배속과 같다고 주장하지 않는다. 신규 경로를 기존 기본 해석기로 강제 교체하지 않는다.
- 공기 반응과 전체 보존을 포함하는 최소 모델을 구현하되 모든 실제 설비에 적용되는 정량 정확도나 수십 kg 미세 입자 전수 해석 성능을 보장하지 않는다.

## 2026-10-29 중간 검증 상태

작업 01~05 및 07~08 구현, 06/09 검증 일부 완료. 10은 재대조 결과 미완료 유지. 상세 결과는 [검증 현황](coupled_minimum/README.md). R10: 대량 분말의 물리 초/현실 초는 별도 성능 측정 항목이다. 최신 우선순위에 따라 0.1배속 미달만으로 기능 구현 완료를 막지 않으며, 필요한 물리를 제거하지 않는다. 재부유 후 재부착과 장시간 연쇄 이송도 추가 검증이 필요하다. 따라서 기능 존재만으로 전체 완료를 선언하지 않는다.

## 최신 우선순위 반영

기능 구현, 물리적 일관성, 안정성 및 통합 검증을 우선한다. 최적화는 명백한 병목 제거와 사용 가능한 최소 수준에 한정한다. 비구형 강체, 응집/이탈, 공급/배출 및 경계 현상 검증을 성능 튜닝보다 먼저 진행한다. CPU 기준 경로와 GPU 대량 경로의 지원 기능 차이는 명시하며, 어느 한쪽의 검증으로 다른 쪽을 통과 처리하지 않는다. 실측 속도/FPS/온도는 기록하되 보편적인 속도 보장이나 실험 정확도로 표현하지 않는다.

## 사용자 실행 경로 통합 갱신

별도 CPU 실험 레벨 `L_CoupledPowder_Transport`, `L_CoupledPowder_Filter`를 추가했다. 동일 해석기에서 비구형 강체, 양방향 공기, 접촉 응집/벽부착, 순차 생성과 출구·입구 역류 및 종류별 질량 장부를 연결한다. 추가 개구와 부분 차단 수동 설정도 연결한다. GPU 고급화를 최소 기능의 새 필수 조건으로 삼지 않고 GPU 미지원/대량 성능은 별도 기록한다.

실제 실행과 요구 판정의 최신 근거는 [사용자 통합 실험 검증](coupled_minimum/사용자_통합실험_검증.md). 원문에 언급된 실제 관 굽힘, 이동 날개의 유체 경계, 필터 케이크 정량 폐색, 열전달/반응 등의 고급 물리는 구현/실증했다고 표시하지 않는다. 초기 원문 요구의 모든 산업 운전 조건을 완성했다는 의미가 아니다.
