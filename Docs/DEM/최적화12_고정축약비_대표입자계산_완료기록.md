# 최적화 12 — 고정 축약비 대표 입자 실행과 비교

완료일: 2026-10-22. 브랜치: PowderSimulationOptimization. 자체 ClumpWorld 독립 실행 경로에 연결. 언리얼 레벨/에디터 기본 실행은 변경하지 않았다.

## 구현

- representative_world가 실제 PSD와 단일 정수 q로 질량·크기·접촉계수를 재계산한다. 외부에서 편집한 파생 inventory를 입력받지 않는다. 그룹/입도별 배치 수, 중복 ID, 유한 좌표, 재료표 누락을 거부한다. 기존 안정성 및 용량 제한을 유지한다.
- q>1은 건조·비응집·비구름 선형 접촉 후보만 허용한다. 자동 분할/병합, 항력, 시간 간격 확대, 강성 완화의 자동 결합은 없다. 배치는 호출자가 명시한다.
- powder_rep12 packing|discharge|mixing 1|8 NEW_DIRECTORY: 실제 충돌 해석 수행. 실입자 256개, 직경 10mm, 밀도 2500kg/m³, 두 원료 각 128개. q=8은 계산 입자 32개, 직경 20mm. 총량 약 0.3351kg.
- 시간 간격 2µs, 물리 시간 0.25s, 공통 21시점. 고정 바닥 위 낙하 충전, 넓은 측벽 사이 배출, 양 원료의 ±1.2m/s 대향 초기 속도와 B 원료 y=17.5mm 엇갈림에 의한 혼합. 실제 제정기나 패들 운전 검증은 아니다. 충전은 과도 응답이며 평형 안식각/충전밀도 검증이 아니다.

## 혼합 측정의 비교 조건

동일한 2×2×1 셀, 동일한 시각, 동일한 질량 가중식과 최소 표본 수 4를 사용한다. 기준 실입자는 초기 인접 8개씩 32개의 고정 관측 묶음으로 정의하고 그 질량 중심을 측정한다. q=8도 대응하는 32개 대표 입자를 관측한다. 각 묶음은 같은 원료이며 질량이 같으므로 계산 양쪽의 관측 표본 수와 통계 가중치가 일치한다. 실제 해석은 기준 256개 모두 각각 수행한다.

이는 비교용 관측 해상도를 맞추는 방법이며 8개 입자가 독립 표본 8개라는 뜻이 아니다. 묶음 내부의 퍼짐·분리 및 미세 혼합은 가려질 수 있다. 해당 셀 지표는 제품 품질이나 Lacey 지수가 아니다. 이 실험의 동일 질량 묶음 계산을 일반 다분산/이종밀도 묶음에 그대로 사용해서는 안 된다.

## 결과

| 시험 | 비교 오차 | 사전 선별 한계 | 한계 이내 | 속도비 q1/q8 |
|---|---:|---:|---|---:|
| packing | 0.024031 | 0.1 | True | 8.63 |
| discharge | 0.500000 | 0.1 | False | 7.83 |
| mixing | 0.359871 | 0.1 | False | 8.49 |

충전 오차는 마지막 질량중심 높이 상대차, 배출은 모든 공통 시점의 최대 누적 배출 질량비 차, 혼합은 셀 균일도 최대 절대차다. 0.1 한계는 실행 전 기록한 가상 시험 선별 기준이며 실물 검증 기준이 아니다. 배출 입자는 제거하지 않고 최초 z<0 통과를 집계하므로 초기 질량과 그룹 질량은 전체 world에 보존된다.

실행/질량 검사와 접촉 발생 및 전량 배출을 확인했다. q=1 직접 생성 경로의 100단계 상태 일치와 잘못된 입력 거부 검사를 추가했다. 전체 Core 결과는 Saved/Optimization12_core_tests.log 참조. 새 코드는 에디터 코드에서 참조하지 않으므로 Unreal 재빌드/자동화는 이번에 수행하지 않았다.

작은 시험의 실행 시간은 단일 측정 참고치다. 다른 프로세스 부하를 완전히 통제하지 않았다. mm 반지름·원료별 kg 규모의 0.1s/s 목표 달성 근거가 아니다. 공정에 q=8을 채택하지 않았으며 다음 최적화 13에서 축약비·초기 배치 민감도와 금지 영역을 판정한다.

```powershell
python -B Scripts/run_optimization12_validation.py --output Saved/Optimization12_new
```

CMake Release 빌드 후 실행. 새 출력 폴더만 허용. 유효 결과: Docs/DEM/optimization12/final/{contract.json,acceptance.json,packing_q1,...}. 초기 실패 시도는 상위 폴더와 validated/에 보존하며 유효 결과로 사용하지 않는다. 첫 시도는 기본 Hertz 재료 설정 및 dt 제한으로 중단되었고 선형 모델 명시와 동일 dt 축소로 수정했다.

## 추가 수치 한계

선형 시험 재료의 최대 중첩/반지름은 충전 약 22%, 혼합 약 31~34%로 크다. 안정성 검사 통과는 작은 변형의 실제 분말 정확도 검증이 아니다. 이번 비교는 동일한 유연 접촉 후보 사이의 실행·모델 편차 측정이다. 실제 공정 채택 전 강성/시간 간격 및 축약비 수렴 검증이 필요하다. 배출은 넓은 통로의 자유낙하로 접촉 수 0이며, 출구 접촉/막힘/질량유량 일반 검증으로 확대 해석하지 않는다.

최종 시험에서 혼합도 최대 절대차 0.359871, 배출 질량비 최대차 0.5로 선별 기준 0.1을 초과했다. 공정 적용은 승인하지 않는다. 유효 산출물은 optimization12/final/이고 이전 linear/, comparison/은 혼합도 변화가 없었던 예비 시험이다. observation_audit.json에 셀별 32개 표본·질량 보존과 중첩 비율을 별도로 기록했다. core_tests.log에 최종 35/35 통과 기록을 복사했다.
