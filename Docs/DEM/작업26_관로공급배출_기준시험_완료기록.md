## 1. 구현한 범위

공기 영역 내부에 가상의 입자 공급면과 수집면을 두고, 두 면 바깥에 공기 계산 완충 구간을 확보했다. 입자 체적·항력 반작용의 배분 커널 전체가 공기 계산 영역 내부에 남는다. 기존 커널을 외부 경계에서 잘라내거나 일부 힘을 버리지 않는다.

이 공급·수집면은 실제 CFD 외부 압력 경계를 통과하는 입자 경계가 아니다. 입자는 지정 면에서 생성되고 수집면을 지난 뒤 제거되는 가상 source/sink다. 실제 장비 입구·출구나 벽 접촉 조건으로 확대 해석하지 않는다.

- SI 입력: 공급·수집 x 위치, 커널 반경, 연성 하위 단계 수, 중력, 반작용 여부, 입자별 ID·예약 시각·직경·밀도·y 위치·초기 x 속도.
- 최대 256개 예약, 기존 모델의 활성 입자 상한 32개. 초기 기준은 희박 구형 입자 3개이며 기존 DEM 시험장 입자 수와 별개다.
- 물리 시각 기준 FIFO 투입. 앞선 입자와 간격이 부족하거나 활성 상한에 도달하면 대기한다. 미래 예약과 이미 시각이 도래한 대기를 따로 센다.
- 생성 시 중심 간격 55 × 큰 직경의 여유를 사용한다. 계산 중 50 × 큰 직경 미만 접근은 기존 고립 구형 모델 범위 위반으로 실패한다. 접촉을 임의로 무시하지 않는다.
- 공급 예약 시각과 실제 진입 시각을 별도 기록한다. 체류 시간에는 공급 대기를 포함하지 않는다.
- 배출면 교차 시각은 한 하위 단계의 전후 위치를 선형 보간한다. 실제 제거는 그 하위 단계 끝에서 일어나며, 두 시각을 모두 저장한다. 힘은 해당 하위 단계 전체에 적분한다. 정확한 사건 시각 적분을 구현했다고 주장하지 않는다.
- 단계 실패 시 공기·입자뿐 아니라 공급 대기열, 배출 사건, 누적 공기 질량과 시계를 모두 이전 수락 단계로 복구한다.

## 2. 수지와 측정 정의

입자 중심 기준 질량은 다음 항등식으로 검사한다.

```text
총 예약 질량 = 미투입 질량 + 활성 질량 + 수집 질량
실제 투입 질량 = 활성 질량 + 수집 질량
```

필터된 입자 체적은 압력 셀과 시험 구간의 겹친 길이 비율로 시험 구간/완충 구간에 나눈다. 항력 반작용도 MAC 제어체적의 x 방향 겹침 비율로 나누며, 두 구간의 충격량 합을 공기 운동량 예측 단계에 실제 적용한 값과 비교한다.

입자가 공급면 바로 안에 있더라도 필터 체적 일부는 완충 구간에 있다. 따라서 **중심 기준 활성 질량과 시험 구간 필터 체적은 같은 측정량이 아니다.** 전체 필터 체적과 시험/완충 구간 합의 보존을 별도로 검증한다. 공급·제거 사건 자체는 입자 및 필터 체적의 명시적 source/sink다.

공기 질량은 공기 영역의 외부 입출구 유량을 시간 적분해 비교한다. 현재 희박 모델의 일정한 공기 체적·밀도를 사용하며, 유한 공극률 연속방정식이 아니다. 압력은 입자 공급면/수집면에서 y 평균한 게이지압이다. 이 측정면과 공기 외부 경계는 위치가 다르다.

반작용 충격량 검사는 항력 교환에 대한 검사다. 압력·벽 점성·외부 운동량 유출입까지 포함한 전체 시스템 운동량 수지를 의미하지 않는다.

## 4. 검증 기준과 결과

수치 시험에서 사용한 기준: 미세 격자 통과시간/압력의 독립 기준 대비 상대 오차 각각 0.2% 미만, 격자/시간 세분 시 통과시간 차이 감소, 격자 세분 시 압력 차이 감소, 완료 수집 질량 동일, 입자 질량 잔차 <1e-22 kg, 교환 잔차 <1e-20 N·s. 공기 각 단계 잔차·발산·질량 오차는 기존 계약의 기준으로 수락한다. 적용 범위 밖 입력과 계산 실패는 상태를 보존해야 한다.

독립 통과시간 기준은 반작용이 약해지는 대표 깊이 1 m에서 평행판 Poiseuille 속도에 연속 tent 커널을 적용한 값이다. 중심선에서 `U_filtered = U_peak - U_mean h²/H² = 0.02875 m/s`, 길이 0.002 m 구간의 기준 체류 시간은 약 0.06956521739 s이다. 이는 유한 크기 실제 구의 정확해가 아니라 현재 필터 점입자 모델의 약한 반작용 극한 기준이다. 시험의 물리 커널 크기는 격자 세분에도 고정했다.

## 5. 비교 출력과 재현 자료

- `history.csv`: 물리 시각, 예약/대기/활성/배출 수·질량, 공기 누적 질량, 두 압력 측정값, 시험/완충 필터 체적, 반작용 충격량.
- `transits.csv`: ID별 예약·진입·보간 배출·실제 제거·체류 시각, 질량·직경·밀도·마지막 위치/속도. 미확정 시각은 -1, 상태는 pending/active/exited.
- `input.flow`, `input.channel`: 실행 조건 원본/정규화 저장.
- `result.json`: 버전, 계산 성공 여부, 전량 배출 여부, 마지막 수락 시계, 수지 최대 오차와 오류 메시지.
- `exited_mass_kg`는 수집면에서의 누적 수집량이며 이력 CSV에서는 제거 하위 단계가 포함된 바깥 단계 끝에 표시된다. 체류시간 비교는 더 세밀한 `crossing_time_s`를 사용한다.

실험과 비교할 때는 같은 입자 조건·공급/수집면·물리 시간 원점·게이지압 기준을 맞춘다. 누적 수집 질량을 같은 시간 구간으로 나누어 평균 질량 유량을 계산할 수 있다. 보간된 배출 시각과 실제 제거 시각을 혼용하지 않는다. 실제 실험 데이터는 아직 없어 물성 보정·실물 정확도 판정은 하지 않았다.
