# 최적화 18 — 전체 총량 인수 시험: 미달

상태: 전체 질량의 제한된 GPU 인수 전제 시험 수행, **0.1배속 및 전체 공정 인수는 미완료**.

총량을 줄이지 않았다. 반지름 1mm, 밀도 1,500kg/m³, 실제 구 1,591,550개(q=1), 두 그룹 각각 795,775개/5.0000017878kg, 합계 10.0000035756kg. 이는 기존 가상 목표 입력이며 실제 원료 물성 확정/실측 보정은 아니다. kn=10,000N/m, cn=.01Ns/m, kt=2,500N/m, ct=.0025Ns/m, mu=.4, dt=2e-8s. 촘촘한 입자층, 바닥, 접촉하는 처방 가동 상자로 시험했다.

3회 반복, 각 6스텝, 매 반복 물리시간 1.2e-7s. 시작 스텝과 후속 창을 구분해 기록했다. 4,733,669개 쌍 접촉과 가동 벽 접촉, 질량/ID/물성, 운동량 수지, 겹침, 혼합 셀 지표, 토크, 외부 일, 계산/전송/측정 및 메모리를 수집했다. 수치 정확도 관문은 통과했지만 물리시간이 매우 짧으므로 실제 혼합 진행/체류/배출 완료를 주장하지 않는다.

GPU 버퍼와 프로세스 private는 드라이버 매핑이 중복 집계될 수 있으므로 합산해 물리 RAM 사용량이라고 해석하지 않는다. 프로파일 미사용 초기 시험은 `optimization18/`, 최종 커널별 시험은 `optimization18_profiled/`다. 둘 다 미달했다. 최종 값은 프로파일 overhead를 포함하며 이벤트 시간 합은 host 시간과 같지 않다.

전체 공급→저장→이송→수취→혼합의 시작부터 종료까지 반복 실행은 하지 않았다. 성능의 필요조건부터 약 180만 배 부족해 장시간 공정을 승인할 근거가 없다. `end_to_end_completed=false`, `accepted=false`, `residence_s=null`, `render_included=false`로 기록한다. 전체 공정 체류 시간, 지속 밀집 구간 속도, 완전한 뷰포트 렌더 비용과 목표 공정 정확도는 미측정이다. 시험 코드의 종료 코드 0은 짧은 수치 검증 통과만 의미하며 최종 인수 성공이 아니다.

다음 작업 우선순위:

1. GPU 접촉 배열을 연속 메모리 접근에 맞게 바꾸고 활성 이력만 저장·갱신한다. 현재 32슬롯×양방향 이력 전체를 매 스텝 반영하는 비용을 먼저 줄인다.
2. 통계·토크·질량·혼합 셀을 GPU 내부에서 축약 집계하고 필요한 화면 표본만 읽는다. CPU로 매번 159만 상태를 받는 경로를 분리한다.
3. bitonic 두 번 정렬을 radix/cell 목록 재사용으로 대체하고 dt 안정성/벽 통과 검사를 유지하며 후보와 사후 검사를 재사용한다.
4. 단일 스텝 host 왕복을 줄여 배치를 실행하되 실행/정지 응답과 물리시각 샘플을 보존한다.
5. 속도 차이가 너무 커 메모리·정렬 개선만으로 달성을 약속할 수 없다. 물성 자료로 연화 허용범위와 대표 입자 적용구간을 다시 검증하거나 암시적/준정적 구간 해법 등 별도 모델을 평가해야 한다. 기존 q>1 불승인을 임의로 뒤집지 않는다.
6. 성능 필요조건을 통과한 뒤에만 확정 총량의 전체 공정·장시간·렌더 포함 인수를 재실행한다. 공기 이송이 필요하면 기존 CFD–DEM 선행 미완료 항목도 먼저 충족해야 한다.

검증 환경: 2026-10-22, Windows, RTX 4060 Ti 16GB, OpenCL FP64, MSVC Release /fp:strict, UE 5.8 Development Editor. 브랜치 PowderSimulationOptimization. 이번 요청에서 커밋/푸시는 하지 않았다.

Core 전체 41개 테스트 통과 후 변경된 GPU/인계 테스트를 재검증했다. Unreal 실제 RHI 활성화 환경의 16개 테스트 모두 통과했다. 재현은 프로젝트에서 `python Scripts/run_optimization14_18_validation.py --output Saved/Optimization14_18_new --full-target`. 이 스크립트는 Core/GPU 시험이며 Unreal 실행 결과는 별도다. 원본 로그와 코드 SHA-256은 `optimization14_18/`에 보관한다.
