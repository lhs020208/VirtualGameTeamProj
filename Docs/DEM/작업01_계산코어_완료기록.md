## 모델과 가정

코어 버전 `0.1.0`, 모델 `foundation_no_dynamics`.

이번 작업의 입자는 균질한 구이며 밀도는 양의 유한값이다. 구 질량은 `ρπd³/6`, 중심 관성은 `2mr²/5`로 정의한다. 물성에는 현재 밀도만 포함한다. 탄성·마찰은 해당 접촉 모델 구현 작업에서 추가한다.

위치·속도·회전을 저장하지만 아직 운동방정식을 풀지 않는다. 난수 시드는 기록만 하며 이번 버전에서는 난수를 사용하지 않는다. 따라서 시드에 따른 입자 배치를 검증한 것으로 해석하지 않는다.

## 수정 및 남은 제한

- 컴파일 전 검토에서 시험 코드의 `std::max` 사용에 필요한 `<algorithm>` 헤더를 명시했다. 빌드와 실행 검증에서 추가 실패는 없었다.
- 고정 시계는 끝 시각의 유한성과 분해능을 확인하고 tick은 2^53 이하로 제한한다. 기반 콘솔 실행은 실수로 긴 무의미한 실행을 하지 않도록 최대 천만 step으로 제한한다.
- JSON 설정 가져오기와 사용자 지정 초기 배치는 아직 없다. 입력은 CLI, 출력은 JSON이며 작업 12에서 확장한다.
- 중력·접촉·마찰·입자 운동·Unreal 연결은 이번 범위 밖이다. 현재 Unreal 레벨은 기존 Chaos 시험 그대로다.
- 실제 분말 보정·에너지 보존·물리적 수렴 검증은 운동과 접촉 구현 후 수행한다.
- 기존 관 집계 300/298 차이는 이번 작업에서 고친 것이 아니며 작업 11의 조사 대상으로 유지한다.
- 커밋과 푸시는 하지 않았다.
