# 최적화 27~28 — 축약 공정 시제품 계획 및 검증 계약

2026-10-22 · 기존 상세 DEM은 보존. 작업 1개 = 프롬프트 1개와 해당 문제 수정.

## 27: 목표와 관찰 조건

최종 목표는 수십 kg의 칭량→진공 이송→수취/배출→혼합을 현재 PC에서 실제 1초당 물리시간 0.1초 이상으로 계산하는 것이다. 기본 30kg, 10/50kg 추가 시험. 녹화 재생을 사용하지 않는다.

육안으로 분말 이동이 보여야 한다. 표시 입자는 질량을 소유하지 않는 흐름 표식이며 계산 질량/유량과 연결한다. 지원 통로 벽과 닫힌 밸브를 통과하지 않는다. 항력은 입자-공기 상대속도를 감소시키는 방향이어야 한다. 관성/중력 때문에 일시적으로 공기 흐름 반대로 움직이는 것은 물리적으로 가능하므로 일괄 금지하지 않는다.

최종 초기 정확도 기준안: 원료별 질량 수지 상대오차 0.01% 이하, 도착/잔류량 상대오차 5%, 이송시간 10%, 고정 관측 영역 혼합 지표 절대차 0.05. 영점 부근 절대오차와 실제 재료 적용 범위는 후속 기준시험에서 고정한다. 실측 자료가 없으므로 현재 실물 정확도는 미인증이다.

시간 간격/공간 해상도 수렴 검증과 보정에 사용하지 않은 조건 검증이 필요하다. 표시 개수로 물리 질량이나 계산 결과가 바뀌면 안 된다. 최종 성능은 화면·통계·정기 저장 포함, 초기화 별도, 전 공정 완료 및 가장 느린 구간 검증을 포함한다.

## 28: 최소 성능 시제품 범위

직선 경사 통로를 64/128/512개 셀로 나누고 3개 원료 질량을 보존적으로 이동시킨다. 선형 항력과 통로 방향 중력, 빈 공간 용량, 닫힌 밸브가 전달량을 제한한다. 상태를 유지한 채 공기 속도/밸브를 변경한다. 실제 공기 압력은 계산하지 않는다.

공급·칭량·이송·수취·혼합의 다섯 구간 이름은 연결 골격이다. 칭량 제어/압력 네트워크/혼합 법칙은 아직 구현하지 않는다. 60초 물리시간, dt=0.005초(내부 CFL 분할), 1500개 표시 표식 갱신 포함, 각 조건 3회. 코어 계산 가능성 판단이며 렌더 포함 최종 인수와 구분한다.

Unreal에 별도 L_BulkPrototype 레벨을 만들고 기존 레벨/기본 맵을 변경하지 않는다. 기본 도형으로 바닥·측벽·끝벽·밸브를 구성한다. 정확한 개별 충돌/자연 발생 막힘/응집/분급/임의 메시와의 충돌은 이 시제품 범위 밖이다.
