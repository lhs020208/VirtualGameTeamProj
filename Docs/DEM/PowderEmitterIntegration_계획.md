# 입자 생성기·데이터 에셋 통합 계획

작업 단위: 프롬프트 1회와 해당 작업에서 발생한 문제 수정.
대상 브랜치: PowderEmitterIntegration.
기준: 현재 HEAD 41b0375 (위·아래 배치 포함), 원본 origin/bbangkyu 32b8310.
GPU 해석기와 기존 레벨을 유지하고 필요한 기능만 선별 이식한다.

| 작업 | 범위 | 완료 기준 | 상태 |
|---|---|---|---|
| 01 | 설정·생성기 코드/에셋 이식, CPU 의존 분리 | Editor 빌드 및 에셋 로드·생성 확인 | 완료 |
| 02 | GPU 지원 설정 계약, 질량 집계 | 미지원 입력 구분, 표시/CSV 질량 일치 | 완료 |
| 03 | 생성기 초기 상태 GPU 연결 | 좌표·속도·그룹 변환과 낙하 확인 | 완료 |
| 04 | 미리보기·표시·Reset 수명 | 반복 재생/초기화와 삭제 처리 검증 | 완료 |
| 05 | MX301 두 생성기 적용 | 위 파랑/아래 빨강 각 25,000개, 초기 충돌 검사 | 완료 |
| 06 | 회귀·성능·사용법 | 동일 조건 비교, 0.1배속 목표 확인 | 완료 |

초기 통합은 동일 반지름·동일 물성, Play/Reset 일괄 생성이다. 연속 방출과 서로 다른 물성 혼합은 제외한다.
생성기 좌표는 오른손 SI 월드 좌표이므로 GPU 혼합기 로컬 좌표로 별도 변환한다.
강성·감쇠·회전은 GPU에서 미지원이며 조용히 적용된 것으로 처리하지 않는다.
밀도는 우선 질량 집계에 사용하고 GPU 동역학의 물성 보정으로 간주하지 않는다.
작업 01에서는 생성기는 정지 표시만 하며 GPU에 아직 연결되지 않는다.
원본 검증 로그/이전 솔버 파일은 저장소에서 누락되어 있으므로 새 검증으로 대체한다.

## 작업 01 결과 (2026-10-27)
- 기존 위·아래 배치는 기준 커밋 41b0375에 이미 저장되어 있었으며 시작 작업 트리는 깨끗했다.
- DEMPrototype 런타임 모듈/클래스 경로를 보존해 설정 에셋, 생성기 BP, 구 메시를 이식했다.
- CPU 관리자/솔버 연결과 원본 Editor 모듈은 제외했다. 좌표 변환은 값 타입만 사용한다.
- 기존 GPU 코드·레벨·프로젝트 설정은 변경하지 않았다.
- Development Editor 빌드 성공. 임시 맵에서 에셋/클래스 로드, 2048 미리보기 제한, 3000/50000개 전체 생성, Clear, 비단위 스케일 거부를 검증했다.
- 검증 스크립트: Scripts/verify_emitter_integration01.py. 결과: emitter_integration01/verification.json 및 build.log.
- 아직 GPU 연결, 실행 중 소유권 관리, 사용자 GUI 육안 검증은 하지 않았다. 정지 생성기는 정상이며 기존 혼합기는 계속 자체 초기화를 사용한다.
- 자동 커밋/원격 푸시는 수행하지 않았다.

## 작업 02 결과 (2026-10-27)
- 설정 에셋에 GPU Approximation 명시적 선택을 추가했다. GPU 선택 시 강성/감쇠 편집을 비활성화하며 이 값은 GPU 동역학에 적용되지 않는다.
- GPU 반지름은 float 변환 후 (1mm,30mm), 입자/벽 마찰은 같은 [0,1] 값이어야 한다. GPU 생성기는 초기 각속도를 거부한다.
- 믹서의 Particle Settings에 선택적으로 GPU 에셋을 지정한다. 미지정이면 기존 자동 반지름·마찰과 밀도 1200을 사용한다. 변경은 Reset 시 적용한다.
- DA_DEMParticle_GPU_Default를 추가했다. 5만 개 기준 기존 반지름/밀도/마찰을 재현한다. 기존 맵에는 아직 지정하지 않았다.
- 총질량 N*(4πr³/3)*밀도 및 수취질량을 적용했다. GPU에 전달하는 float 반지름을 기준으로 계산하므로 기존 총질량은 64.7999978727kg이다.
- CSV와 테스트 혼합기 HUD의 고정 64.8 값을 제거했다. 수취질량은 Reset 시 확정된 입자 질량으로 계산한다.
- 밀도는 질량 집계용이다. 같은 질량 구체의 현재 근사 운동법을 변경하거나 실측 물성을 보정한 것이 아니다. 서로 다른 물성 혼합과 강성/감쇠/회전은 지원하지 않는다.
- Editor 빌드 성공. CPU 에셋 오사용, 서로 다른 마찰, 반지름 경계, NaN 밀도, 0개 입력, GPU 회전을 거부하는 시험 통과. 사용자 설정 질량 67.858403kg 검증.
- 기존 MX301 5만 개 짧은 실행 및 CSV 질량 일치 확인. 성능/장기 안정성 인증 시험이 아니다.
- 검증: Scripts/verify_emitter_integration02.py, emitter_integration02/verification.json, runtime_trace.csv, runtime_result.json, build.log.
- 생성기 배치/속도의 GPU 전달은 작업 03에 남아 있다. 커밋/푸시하지 않았다.

## 작업 03~05 결과 (2026-10-27)
- GPU 외부 초기 상태 생성자를 추가해 기존 자동 격자를 만들지 않고 생성기 좌표·선속도를 바로 넣는다. 목록 순서/로컬 순서가 안정적인 ID다. 그룹 0=빨강, 1=파랑이다.
- 우수 SI 월드 좌표의 Y 반사를 되돌리고 혼합기 역변환으로 로컬 미터 좌표를 만든다. 혼합기는 위치/수평 회전만 지원하고 기울기와 비단위 스케일을 거부한다.
- 서로 다른 반지름/밀도/마찰, 중복 생성기, 다른 월드, 범위 초과, 비유한 값, 초기 회전을 거부한다. 여러 생성기가 같은 물리 조건을 사용한다.
- 생성기별 메시·재질과 ISM으로 GPU 결과를 표시한다. 재질이 없으면 그룹별 빨강/파랑을 사용한다. 생성기의 정지 표시와 중복되지 않는다.
- 실행 중 생성기 변경·삭제·Generate/Clear·혼합기 이동은 정지하고 Reset을 요구한다. 시작은 첫 Tick으로 미뤄 BeginPlay 순서에 의존하지 않는다. Worker는 UObject를 읽지 않는다.
- 선택적 명시 좌표 배열을 추가했다. 빈 배열이면 일반 격자, 값이 있으면 해당 위치를 사용한다. MX301은 곡면/날개를 피한 기존 좌표를 사용하며 생성기를 움직이면 같이 변환된다.
- MX301에 두 생성기, 아래 빨강/위 파랑 각 25,000개를 저장했다. 원본 자동 배치와 초기 상태가 바이트 단위로 같다. 기본 배치 비교 레벨은 /Game/DEM/Tests/L_MX301_LegacyBaseline이다.
- 생성 직후 용기 평면, 회전부/축/날개, 입자 간 겹침을 검사한다. 허용 오차 1µm. 연속 충돌이나 물성 정확도 인증은 아니다.
- 자동화 검증: 이동/회전 좌표, 초기 선속도, 중력, 그룹 보존, 정지 초기 상태, 반복 Reset, 소유권, 삭제/변경 정지 통과. 03/04 tests/index.json 참조.
- 첫 자동화 시험의 테스트 코드 배열 자기참조 오류와 소유자 인수 이름 충돌을 수정한 뒤 재검증했다.
- 기존 SM_GrainSphere는 구 외곽 치수 1% 검증을 만족하지 않아 생성기 표시에는 SM_DEMSphere를 사용한다. 물리 반지름은 동일하며 표시 메시 차이는 성능 비교에서 명시한다.

## 작업 06 결과 (2026-10-27)
- Development Editor 최종 빌드 성공. CTest 48/48, Unreal 자동화 19/19 통과. 새 프로세스 레벨 재로드 및 미리보기 색/입자 수/초기 배치 검사 통과.
