# 최적화 19~24 작업 계획

작업 1회 = 프롬프트 1회 + 해당 작업의 문제 수정. 2026-10-22, PowderSimulationOptimization.

19. 기준 입력·허용오차·성능 측정 조건 고정. 기존 실행 파일과 소스 해시, 전체 10kg 3회 기준 결과 보존.
20. GPU 내부 질량/운동량/혼합 셀/토크 통계 집계. CPU 전체 스냅샷 집계와 비교.
21. 접촉 이력 메모리 배치·활성 슬롯 갱신 및 커밋 비용 개선. 실패 시 원자성·clone/생성삭제·마찰 검증.
22. 셀 인덱스 및 정렬 재사용. 셀 이동 시 재생성, 기존 정렬 탐색과 정확한 접촉 집합 비교.
23. GPU 배치 실행과 물리시각 측정·화면 갱신 분리. 일시정지/단일 스텝/reset과 샘플 시각 보존.
24. 동일 총량·물성·dt의 3회 비교 및 추가 연속 배치 시험. 정확도·메모리·계산/전송·배속과 목표 인수 여부 기록.

단순 배속 설정 변경, dt 증가, 입자 수 축소, 검증되지 않은 q>1은 이 범위에서 하지 않는다. 0.1배속 미달은 미달로 기록한다. 에디터는 CPU 기본값을 유지한다.
