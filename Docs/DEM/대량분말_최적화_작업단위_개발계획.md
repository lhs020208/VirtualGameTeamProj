## 1. 목표와 확정 방향

- 목적은 의약품 제조 공정에서 여러 종류의 분말이 공급·이송·수취되어 혼합되는 과정의 디지털 트윈이다.
- 반지름 mm 단위 입자가 원료별 수 kg 규모로 존재하는 조건을 대상으로 한다. 반지름과 직경을 입력·보고서에서 구분한다.
- 목표 속도는 **실제 시간 1초당 물리 시간 최소 0.1초**다. 물리 시간 60초를 실제 600초 이내에 계산하는 수준이다.
- 목표 총량은 공정 전체에 동시에 존재하는 분말의 합으로 평가한다. 원료별 질량과 실제 계산 입자 수를 함께 보고한다.
- 물리적으로 중요한 거동을 검증할 수 있다면 계산 모델의 간략화를 허용한다. 결과를 맞추기 위한 임의 보정이나 시간 건너뛰기는 허용하지 않는다.
- 자체 해석기 개발을 유지한다. 상용 해석기는 사용하지 않는다. 공개 문헌·공개 코드의 알고리즘 설명은 참고할 수 있다.
- 계산은 입력에 따라 실제로 진행하며 녹화 영상 재생으로 대체하지 않는다.
- 실제 장비 에셋이 준비되기 전에는 기본도형 시험장을 사용한다.
- 실제 원료 물성·실험 자료가 부족한 동안은 가상 원료 기준으로 수치 검증한다. 이를 실물 정확도 검증 완료로 표현하지 않는다.

## 2. 작업 한 번의 범위

**작업 한 번 = 프롬프트 하나로 지정한 작업의 구현 + 해당 범위 검증 + 발견된 문제 수정·재검증 + 결과 보고.**

- 아래 번호 하나가 프롬프트 한 번으로 요청할 범위다. 구현 난도가 큰 GPU·대표 입자·공정 연결은 여러 작업으로 분할한다.
- 작업 중 발견된 해당 범위 결함은 같은 작업에서 수정한다. 문제 수정만 별도 작업으로 넘겨 완료 처리하지 않는다.
- 선행 작업 결함이 현재 완료를 막으면 필요한 수정과 회귀 검증을 포함한다. 관련 없는 기능 확장은 포함하지 않는다.
- 범위가 과도해지면 완료를 선언하지 않고 남은 범위를 명시해 계획을 분할한다.
- 검증 기준은 결과를 보기 전에 확정한다. 실패 결과에 맞춰 허용 오차를 완화하지 않는다.
- 각 작업은 변경 파일, 적용 모델, 시험 입력, 정확도·성능 결과, 남은 제한을 완료 기록으로 남긴다.
- 조건부 작업은 착수 조건을 충족할 때 실행한다. 건너뛸 경우 완료가 아닌 ‘미적용’과 사유를 기록한다.
- 계획서 생성은 구현 시작이나 자동 연속 실행 지시가 아니다. 커밋·푸시는 별도 요청 시 수행한다.
- 기존 기능 개발 작업 01~29와 번호를 혼동하지 않도록 ‘최적화 01’ 형식으로 요청한다.

요청 예시:

> 대량 입자 최적화 계획의 최적화 01을 진행해줘. 구현·검증과 문제 발생 시 수정을 포함해줘.

구형, 입자 재질 밀도 1500 kg/m³일 때 `N = M / (ρ × 4πr³/3)`로 추정한 규모다. 벌크 밀도가 아니며 실제 원료 값도 아니다.

## 4. 공통 정확도·성능 계약

### 정확도

두 종류의 변경을 구분한다.

1. 구현 최적화: 동일 물리식의 접촉 누락·중복이 없어야 하며, 단일/병렬 실행의 수치 오차 허용 범위는 별도로 엄격히 정한다. 아래의 넓은 공정 오차를 구현 버그 허용값으로 사용하지 않는다.
2. 모델 간략화: 시간 간격·강성·대표 입자·구간 축약으로 거동이 달라질 수 있으므로 독립 기준과 공정 관측량을 비교한다.

모델 간략화의 초기 허용 기준안이며 최적화 01에서 시험별 정의·허용값을 실행 전에 고정한다.

| 관측량 | 초기 기준안 |
|---|---|
| 원료별 질량 | 미설명 손실·생성 없음, 부동소수점 잔차의 별도 상대/절대 기준 |
| 누적 배출량·평균 배출률 | 정밀 기준 대비 5% 이내, 기준값이 0에 가까울 때 절대 기준 별도 |
| 체류시간 | 평균·중앙값·상위 분위수를 구분하고 대표값 차이 5% 이내 |
| 혼합지수 | 동일 공간 분할·표본 조건에서 절대 차이 0.05 이내 |
| 평균 패들 토크 | 정밀 기준 대비 10% 이내, 순간 최대값은 별도 평가 |
| 막힘·누출·입도 분리 | 중요 현상 발생 여부를 뒤집는 간략화는 해당 용도에서 탈락 |
| 겹침·안정성 | 접촉 모델별 최대 겹침 및 벽 관통 기준을 사전 정의 |

정밀 자체 계산도 무조건 정답으로 취급하지 않는다. 해석해·보존 법칙·시간/공간 수렴과 기존 검증을 통과한 작은 시험을 기준으로 사용한다. 실측이 확보되면 보정 시험과 독립 검증 시험을 나눈다.

### 성능

- 배속 = 수락된 물리 시간 증가량 / 실제 경과 시간. 대기·상태 전달·필요한 센서/결과 저장 비용을 포함한 통합 실행을 최종 기준으로 한다.
- 해석기만의 성능과 Unreal 표시 포함 성능을 별도로 보고한다. 초기화·컴파일 시간은 정상 실행 시간과 분리하되 초기화 비용도 기록한다.
- 초기 시험 규모: 계산 입자 1천 → 1만 → 10만. 실제 총량 목표를 충족하지 못하면 이것만으로 최종 완료 처리하지 않는다.
- 자유낙하, 밀집 충전, 배출, 혼합을 포함한다. 가장 밀집한 구간의 고정 측정 창을 최적화 01에서 정하고 평균·최저 창 배속을 보고한다.
- 반복 시험, CPU/GPU·RAM/VRAM·빌드 종류·스레드 수·입경·총량·접촉 수·시간 간격·축약 비율을 기록한다.
- 최종 합격은 명시한 총량·물성·기하 범위에서 정확도와 지속 0.1배속을 모두 만족하는 것이다. 더 쉬운 조건으로 바꾼 결과를 동일 목표 달성으로 보고하지 않는다.
- 특정 배속 향상이나 GPU 가속 효과를 사전 보장하지 않는다.

- **검증·완료:** 작은 기준 장면 반복 결과와 구간별 비용·메모리·병목 보고서가 나온다. 현재 상한을 넘는 실행은 미지원으로 표시한다.
- **제외:** 이 단계에서 알고리즘이나 물리 계수 변경.

- **제외:** 검증되지 않은 경험 유량을 물리 예측값으로 표시, 복잡한 동적 입자 분할/병합을 이 작업에 숨겨 포함.
- **상태:** 제한된 기준판 완료 (2026-10-22). q=1 접촉 없는 5구간 인계, 단일 장면 상태·질량·조성·체류 보존 검증. 대량 도메인 분해는 미구현. [최적화17_구간별보존인계_완료기록.md](최적화17_구간별보존인계_완료기록.md) 참조.

### 최적화 18 — 전체 총량의 0.1배속 인수 시험
- **선행:** 17 및 목표 공정에 필요한 물리 모델.
- **구현:** 확정한 원료별 수 kg 총량을 대상으로 기본도형 공정 경로와 혼합을 반복 실행한다. 시작부터 완료까지 질량·조성·체류·혼합·토크·속도·메모리를 수집한다.
- **검증·완료:** 정해진 정확도 기준과 밀집 구간을 포함한 지속 0.1배속을 모두 통과한 조건을 명시한다. 미달 시 병목과 남은 작업을 기록하고 목표는 미완료로 유지한다.
- **제외:** 입자 수나 원료량을 줄인 조건으로 원래 목표 달성 주장, 실측 없는 제품 품질 합격 판정.
- **상태:** 시험 수행 / 인수 미완료 (2026-10-22). 159만1,550개 약 10kg 3회 밀집 GPU 전제 시험. 최소 5.57e-8배속으로 0.1 목표 미달. 전체 공정 완료·지속 성능·렌더 포함 인수는 미수행. [최적화18_전체총량_인수시험_미달기록.md](최적화18_전체총량_인수시험_미달기록.md) 참조.

## 10. 현재 공기 모델과 추가 분기

현재 FlowCore 작업 26은 작은 압력차의 희박 평행판 점입자 기준이다. 밀집 분말의 실제 공기 이송에 그대로 사용할 수 없다.

- 기존 22-E1 운영 조건, 22-E2 가변 밀도/압축성, 22-E3 실제 3D 관로 및 필요한 난류, 25-E1 유한 공극률·밀집 항력·자기 교란 보정의 검증 필요성을 유지한다.
- 목표 공정에 공기 이송이 필수라면 해당 모델 개발과 성능 검증을 별도 작업으로 먼저 분할하고 최적화 18의 선행에 추가한다.
- DEM만으로 달성한 0.1배속과 CFD–DEM 전체 공정 0.1배속을 구분한다. 공기 계산 비용을 최종 성능에서 제외하지 않는다.
- 동적 다중 해상도, 대표 입자 분할/병합, 비구형/응집의 GPU 확대, 장비 실측 보정도 필요해질 때 별도 번호로 분할한다.

## 11. 권장 실행 순서와 기존 계획의 관계

1. 우선 최적화 01~10으로 물리 모델을 유지하는 대량 계산 기반과 검증된 간략화 범위를 확보한다.
2. 측정 결과에 따라 11~13(대표 입자), 14~16(GPU)을 선택한다. 둘 다 필요할 수 있다. 불필요한 분기는 근거와 함께 미적용 처리한다.
3. 17~18에서 구간 연결과 전체 목표를 인수한다. 필요한 공기 모델이 없으면 해당 공정의 인수를 완료하지 않는다.
4. 기존 작업 27의 실장비 연결은 에셋과 해석 경로가 준비된 뒤 진행한다. 그 전에는 기본도형으로 최적화를 수행한다.
5. 기존 기능 검증 경로는 소규모 기준판으로 보존한다. 최적화 경로가 기준과 비교 가능해야 한다.

현재 다음 단계: **최적화 18 인수 미달 해소 — GPU 접촉/이력 메모리·GPU 통계·정렬/배치 개선 계획 확정. 0.1배속 목표는 미완료.**
