# 호퍼 밸브 전동 구동 — 2026-11-27

## 적용 범위와 사용법

현재 레벨 `/Game/ProcessPlant_20261111_LowPoly/L_ProcessPlant_LowPoly_1111`에 저장했다. OpenCL 시뮬레이션의 공급 A–F, 공용 칭량 호퍼, 수취 호퍼 배출 밸브 총 8개가 대상이다.

- 기존 GUI의 열기/닫기는 목표 각도 90°/0°를 요청한다. 즉시 사라지는 원판으로 통로를 여는 방식은 사용하지 않는다.
- 회전축은 액터의 로컬 축이 아니라 **월드 X축**이다. 원판 중심은 고정한다. Blender SI 좌표와 Unreal 좌표의 Y 반사를 반영하여 UE 시각 회전은 -X 방향으로 적용한다.
- 원판 접촉 계산과 회전 운동 방정식은 OpenCL에서 수행한다. 액터 트랜스폼은 그 결과의 표시값이다. Unreal Chaos를 추가로 겹쳐 계산하지 않는다.
- GUI에 실제 각도, 동작/완전 열림/완전 닫힘/과부하 상태, 구동·접촉 토크, 소비전력과 누적 에너지를 노출한다. 실제 끝 위치에 도달하기 전에 명령을 완료로 판정하지 않는다.
- 에디터에서 `PowderPlantTest` 계열 공정 시험 액터를 선택하고 **Plant → Valve Drive**를 수정한다. `Powered Valves`, `Valve Power Fraction`, 소형/대형의 `Torque Nm`, `Electrical W`, `Travel Seconds`가 있다. 설정 변경은 `ResetSimulation` 또는 PIE 재시작 시 적용한다.
- `Valve Power Fraction=0`이면 구동 전원 없음, `1`이면 정격 공급이다. 이 값은 전압의 물리적인 비율이나 밸브 개방률이 아니라, 가용 토크/전력의 시험 배율이다. 구동 중 개별 전원 시험은 코어 `set_plant_valve_power()` API로 가능하다.
- 과부하 보호가 작동하면 같은 방향 명령을 반복해 강제로 관통시키지 않는다. 반대 방향 명령으로 부하를 풀거나 초기화한다. 코어 API의 전원 차단/복구도 보호 상태를 초기화한다.
- 물리 시간을 사용한다. 11초 스트로크는 0.01배속 환경에서 약 1,100초의 실제 시간이 필요하다. 시뮬레이션 일시정지 중에는 밸브도 정지한다.
- 입자 입력 CSV는 수정하지 않았다. 현재 HEAD의 파일은 A/B 각 100개(총 200개), 반지름 2 mm다. 저장된 액터의 이전 Particle Count 20,000 표시와 달리 실제 초기화는 CSV를 읽는다. 24개 검증용 데이터를 운영 레벨에 저장하지 않는다.

이는 상용 제품에 근거한 **시험용 선정**이며 모든 설비에 통용되는 표준값은 아니다. 원본 메시의 `PneumaticActuator` 명칭은 실제 공압 부품을 뜻하지만, 이번 계산은 요청한 전동 구동기로 치환한 모델이다. 실제 설치 구동기를 동정하거나 해당 장비에 필요한 토크를 산정한 결과는 아니다. 제조사의 토크 제한·고장 피드백·90° 스토퍼 개념을 참고했으나 보호 지연이나 내부 제어기를 복제한 것은 아니다.

## 계산과 결합

1. 각 입자와 가까운 밸브만 원판의 유한 두께 원통 형상으로 접촉을 검사한다. 현재 각도로 원판을 회전시켜 거리와 접촉 법선을 구한다.
2. 겹침에 대한 스프링/감쇠 법선력과 제한된 접선 마찰력을 계산한다. 입자에 적용한 힘의 반작용을 같은 접촉 위치에서 `-r × F`로 집계하여 축의 X방향 부하 토크로 사용한다. 양면에서 서로 다른 팔을 누르는 힘도 각각 집계한다.
3. `I × 각가속도 = 구동 토크 + 접촉 토크 + 시험 외력 토크`를 적분한다. 구동기는 정격 토크와 기계 출력 제한을 넘을 수 없으며, 목표 각도·각속도에 따른 제어를 사용한다. 부하가 크면 느려지고, 한계를 넘으면 멈출 수 있다.
4. 무전원 시 유한한 감속기 유지 토크가 작용한다. 이를 넘는 힘에 대해 무한 강성 고정으로 취급하지 않는다. 0°/90°에는 기계적 스토퍼를 둔다.
5. 속도가 거의 0이고 구동 토크가 포화한 상태가 2초의 물리 시간 지속되면 과부하 보호로 구동을 끈다.
6. 유동 저항은 요청한 열림/닫힘 값이 아니라 실제 각도로 계산한다. 투영 개구율 `1-cos(theta)`와 시험 오리피스 손실을 기존 압력망에 연결한다. 닫히는 중에도 실제 틈에 맞는 유동이 유지된다.
7. 기존 입자/고정 벽/혼합기 계산은 유지한다. 숨김 렌더 모드도 이 원판의 물리 접촉을 제거하지 않는다. 큰 형상 데이터 전체를 매번 전송하지 않고 제어·유동 값만 갱신한다.

## 실측되지 않은 가정과 한계

- 반영 관성 0.1/1 kg·m², 접촉 강성 5,000 N/m, 감쇠비 0.7, 기계 효율 0.35, 무부하 소비전력 비율 20%, 보호 지연 2초, 오리피스 Cd 0.62는 시험 가정이다. 소비전력/에너지는 이 가정으로 계산한 추정값이다.
- 밸브는 명목 반경 22/139 mm, 두께 6 mm의 밀봉 원판으로 근사한다. 표시 메시의 틈과 공차, 축 허브, 시트의 탄성·마모, 실제 감속기 백래시·발열·듀티 제한은 정밀 해석하지 않는다.
- 접촉은 유한 강성의 부드러운 접촉 모델이다. 현재 입자와 dt에 대한 안정성 조건을 시작 시 검사하며, 원판 관통이 입자 반지름의 80%를 넘으면 오류로 중단한다. 이 중단은 정상적인 기계 과부하 트립과 구분한다.
- 부분 개방 유동은 1D 압력망의 근사 저항이다. 3D 난류, 비대칭 압력에 의한 유체 토크, 실제 펌프 곡선은 이번 작업 범위에서 검증하지 않았다. 수취부 개방에 따른 압력 완화도 조절 경계조건의 근사다.
- 동작 확인은 소수 입자 및 제어 회귀 시험 범위다. 대규모 입자의 전체 공정에서의 끼임 해소, 정량 투입 정확도, 자동 공정의 긴 시간 운전, 실제 장비 성능은 보장하지 않는다. 서서히 닫히는 만큼 추가 배출량이 생기므로 기존 순간 차단을 전제로 한 정량 보정은 다시 교정해야 한다.

- 입자 두 개의 끼임 시험에는 의도적으로 약한 0.001 Nm 모터를 사용한다. 10 Nm 정격 모터가 입자 두 개에 멈춘다는 뜻이 아니다. 정격 모터의 트립은 별도 20 Nm 반대 시험 부하로 확인한다.
- 현재 운영 CSV의 200개 입자로도 초기 구동을 확인했다. dt=10 μs, 반지름 2 mm, 8개 모두 닫힌 상태와 오류 없음을 확인했다. 이는 초기 기동 시험으로, 전체 공정 시험은 아니다. `production_start_validation.json` 참조.
- 에디터 실제 GUI에서 24개 입자로 공급 A 열기 → 중간 각도 확인 → 닫기를 실행한다. 월드 X축만 회전, 중심 고정, 원판 표시 유지, 다른 7개 닫힘, 입자 수 보존을 확인한다. 결과는 `play_validation.json`에 기록한다.
